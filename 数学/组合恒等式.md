### 1. 对称性：C(n, k) = C(n, n - k)
从 n 个元素中选 k 个，等价于决定哪 n - k 个不选

### 2. Pascal 恒等式：C(n, k) = C(n - 1, k) + C(n - 1, k - 1)
考虑第 n 个元素的选或不选

### 3. 吸收恒等式：k * C(n, k) = n * C(n - 1, k - 1)
从 n 个元素中选择大小为 k 的集合并在其中标记一个；LHS = 先选后标记，RHS = 先标记后选

### 4. 连续吸收：C(n, k) * C(k, t) = C(n, t) * C(n - t, k - t)
先从 n 个元素中选出 k 个，再从这 k 个元素中选出 t 个，等价于先选 t 个，再选额外的 k - t 个

### 5. 多段选择：C(n, a) * C(n - a, b) = C(n, a + b) * C(a + b, a)
从 n 个元素中选出 a 个，再从剩下的部分选出 b 个，等价于先把 a + b 选出来，再从其中选择 a 个

### 6. 整行求和：sum C(n, k) = 2 ^ n
统计子集总数，LHS 按照子集大小分类求和，RHS 直接考虑每个元素选或不选

### 7. 奇偶对半：sum C(n, even k) = sum C(n, odd k) = 2^{n - 1}
大小为偶数的子集数等于大小为奇数的子集数
推论：sum (-1)^k * C(n, k) = 0

### 8. Hockey-stick：sum_{i>=k} C(i, k) = C(n + 1, k + 1)
从 0..n 中选择 k+1 个不相同的数，首先固定最大值为 i，再在 [0..i-1] 中选择剩下的 k 个数

### 9. 权重为 k 的求和：sum k * C(n, k) = n * 2^{n - 1}
统计所有子集里元素的出现次数，LHS 按照子集大小分类算贡献，RHS 中，每个元素会出现在 2^{n - 1} 个子集中

### 10. 权重为 k(k-1) 的求和：sum k * (k - 1) * C(n, k) = n * (n - 1) * 2^{n - 2}
统计所有子集中有序对选法，LHS 先选集合再选有序对，RHS 先选有序对，剩下 n - 2 个元素选或不选如这个集合

### 11. 权重为 k^2 的求和：sum k^2 C(n, k) = n * (n + 1) * 2^{n - 2}
分别求和 k^2 = k(k-1) + k

### 12. Vandermonde 恒等式：sum C(a, i) * C(b, k - i) = C(a + b, k)
从 a + b 个元素中选取 k 个，可以先选 i 个，再从剩下部分选 k - i 个

### 13. 平方和恒等式：sum C(n, k)^2 = C(2n, n)
从 Vandermonde 取 a = b = n

### 14. 固定子集的 Vandermonde：sum_k C(n, k) * C(k, t) = C(n, t) * 2^{n - t}
从 n 个元素中选择集合 A，再从 A 中选择一个特殊子集 B，等价于先选择 B，剩下 n - t 个元素自由决定是否加入 A
注：如果是对 t 求和，则为 **sum_t C(n, k) * C(k, t) = C(n, k) * 2^k**

### 14. 三段卷积：sum C(a, i) * C(b, j) * C(c, k - i - j) = C(a + b + c, k)
从 a + b + c 元素中选 k 个，按照三块分别来取

### 15. 二项式定理：(1 + x)^n = sum C(n, k) * x^k

### 16. 负二项式：1 / (1 - x)^m = sum C(n + m - 1, m - 1) * x^n

### 17. 交错前缀和：sum_{k=0..m} (-1)^k * C(n, k) = (-1)^m * C(n - 1, m)

### 18. 点卷积：sum C(i, a) * C(n - i, b) = C(n + 1, a + b + 1)
从 0..n 中选择 a + b + 1 个数，按第 a + 1 小的数 i 分类：左边选 a 个，有 C(i, a) 种；右边选 b 个，有 C(n - i, b) 种

### 19. 广义平方和：sum C(n, k) * C(n, k + r) = C(2n, n + r)
从两组各 n 各元素选择总共 n + r 个；假设第二组选了 k + r 个，第一组要选 n - k 个，贡献为 C(n, n - k) = C(n, k)
注：也可由 Vandermonde，sum C(n, n - k) * C(n, k + r) = C(2n, n + r)

### 20. 子集套子集：sum C(n, k) * 2^k = 3^n
统计有序对 (A, B) 满足 B subset A subset [n]；LHS 先选 A，假设 |A|=k，再从 A 中任意选 B，有 2^k 种；RHS 对于每个元素，要么不在 A，要么在 A 不在 B，要么在 B，总共 3 个情况

### 21. 二项式系数递推：C(n, k + 1) = C(n, k) * (n - k) / (k + 1)
大小为 k + 1 的集合，如果删去其中一个元素，剩下 k 个元素集合；从大小为 k 的集合扩展为大小 k + 1 的，有 n - k 种加法；从大小为 k + 1 的集合缩小为大小 k 的，有 k + 1 种减法；
因此有 C(n, k) * (k + 1) = C(n, k + 1) * (k + 1)

### 22. 调和级数加权和：sum C(n, i) / (i + 1) = (2^{n + 1} - 1) / (n + 1)

### 23. 调和级数加权交错和：sum (-1)^{i - 1} * C(n, i) / i = H_n

### 24. 单位根反演：sum_{k = r (mod m)} C(n, k) = 1/m * sum_{j=0..m-1} w^{-jr} (1 + w^j)^n
其中 w 为 m 次单位根 e^(2πi / m)
化为实数形式：sum_{k = r mod m} C(n, k) = 1/m * (2^n + 2 * sum_{j=1..floor((m-1)/2)} (2cos(πj/m))^n * cos(πj(n - 2r)/m))

推论：Σ_{m|k} C(n, k) = 2^n/m [1 + 2 Σ_{j=1}^{floor((m-1)/2)} cos^n(πj/m) * cos(πjn/m)]
