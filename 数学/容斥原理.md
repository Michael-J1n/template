## 容斥原理

问题：对于 n 个对象，计算：一个分配方式使得每个对象都**没有对应的特殊条件成立**的方案数

容斥原理，此答案即为（注意钦定代表剩下的元素好特殊条件无限制）：

钦定 0 个特殊条件成立 - 钦定 1 个特殊条件成立 + 钦定 2 个特殊条件成立 - ...

**定义 f(S) 为：钦定集合 S 中对象的特殊条件全部成立，其他对象不作任何限制的分配方式方案数**，则：

`ans = sum_{S ⊆ [n]} (-1)^|S| * f(S)`

如果具有对称性，钦定任意 i 个特殊条件的方案数都相同，即为 f(i)，可简化为：

`ans = sum_{i=0}^n (-1)^i * C(n, i) * f(i)`

f(i) 如何计算：考虑已经固定 i 个被选为特殊条件，剩下 n-i 个无限制，求这样的方案数。

对应模板：
```CPP
long long res = 0;
for (int i = 0; i <= n; ++i) {
    long long p = f(i);  // 钦定 i 个特殊条件成立，其他条件不限制
    long long c = C[n][i], sgn = (i & 1) ? -1LL : 1LL;
    (res += sgn * c % mod * p % mod) % mod; if (res < 0) res += mod;
}
```

注意：钦定 i 个，不是恰好 i 个。剩余条件可以成立，也可以不成立。

## 广义容斥原理

记 F[k] 为钦定 k 个特殊条件成立（其余条件不限制），对所有选法求和，即 `F[k] = sum_{T ⊆ [n], |T| = k} f(T)`；那么：

恰好 0 个特殊条件：`F[0] - F[1] + F[2] - F[3] + ...` = `sum_{S ⊆ [n]} (-1)^|S| * f(S)`

至少 1 个特殊条件：`F[1] - F[2] + F[3] - F[4] + ...`

恰好 1 个特殊条件：`F[1] - 2F[2] + 3F[3] - 4F[4] - ...` = `sum_{S ⊆ [n], |S| >= 1} (-1)^(|S| - 1) * |S| * f(S)`

恰好 r 个特殊条件：`sum_{i=r..n} (-1)^{i-r} * C(i,r) * F[i]`

= `sum_{S ⊆ [n], |S| >= r} (-1)^(|S| - r) * C(|S|, r) * f(S)`，其中 f(S) 代表钦定集合 S 中对象的特殊条件全部成立，其余条件不限的方案数

= `sum_{S ⊆ [n], |S| = r} sum_{T ⊆ [n]\S} (-1)^|T| * f(S U T)`
