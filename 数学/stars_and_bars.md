# 隔板法

给 k 个变量分配 n 个不可分配的东西

### 1.
求 x1 + x2 + ... + xk = n 的非负整数解数（xi>=0）

或：将 n 个数划分为 k 段，允许空段的方案数

或：在 k 种元素的多重集中选出 n 个的方案数

分成 k 组需要 k - 1 个隔板，隔板 + 星星共有 n + k - 1，因此答案为 C(n + k - 1, k - 1)

### 2.
求 x1 + x2 + ... + xk = n 的正整数解数（xi>=1）

或：将 n 个数划分为 k 段，k 段都非空的方案数

n 个数之间的 n - 1 个空隙选择 k - 1 个放隔板，因此答案为 C(n - 1, k - 1)

注：也可用 yi = xi - 1 转化为 1 的情况求解

### 3.
求 x1 + x2 + ... + xk = n 的有不同下界的正整数解数（xi>=li）

令 yi = xi - li，有 y1 + y2 + ... + yk = n - sum(li)，转化为 1，答案为 C(n - sum(li) + k - 1, k - 1)

### 4.
求 x1 + x2 + ... + xk <= n 的非负整数解数（xi>=0）

引入松弛变量 x_{k+1}，变为 x1 + x2 + ... + xk + x_{k+1} = n 的非负整数解，转化为 1，答案为 C(n + k, k)

注：若为 < n，则改为 <= n - 1 并划归到这个解法

### 5.
求 x1 + x2 + ... + xk = n 的有统一上界的正整数解数（0<=xi<=u）

容斥。不考虑上界，解数为 (n + k - 1, k - 1)

若有 j 个元素超过上界，则某些 xi>=u+1，令它们的 yi = xi-u-1，则剩余和为 n - j * (u + 1)

故答案为 sum_{0<=j<=k} (-1)^j * C(k,j) * C(n - j * (u + 1) + k - 1, k - 1)

### 6.
在 [1, n] 之间选 k 个数，使得 1 <= a1 <= a2 <= ... <= ak <= n 的方案数

这等价于在 n 种元素的多重集中选出 k 个，允许重复且顺序不重要，因此答案为 C(k + n - 1, n - 1)

注：若改为严格小于的偏序，那么即为 C(n, k) 种方案

### 7.
长度为 n 的二进制字符串，放 k 个 1，要求任意两个 1 之间至少间隔 t 个 0 的方案数

对于 k 个 1，(k-1) 个空隙中每个先预留 t 个 0，剩下 n - k - t(k - 1) 个 0 可以选择包含首尾的 k + 1 个空隙插入

因此答案为 C(n - k - t(k - 1), k + 1)
