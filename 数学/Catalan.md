Catalan Numbers

约定 G(n) = C(2n, n) / (n + 1)

G = 1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796, ...

### 1. 通项公式：G(n) = C(2n, n) / (n + 1) = C(2n, n) - C(2n, n - 1)

### 2. 递推公式：G(n + 1) = G(0) * G(n) + G(1) * G(n - 1) + ... + G(n) * G(0)

### 3. 相邻递推：G(n + 1) = G(n) * (4n + 2) / (n + 2)

### 4. 等价模型：n 对括号组成的合法括号序列数量 = 长度 2n，恰好 n 个 0 n 个 1，前缀中 cnt(0) >= cnt(1) 的序列的个数 = 从 (0,0) 开始走到 (n,n) 只能右上前进并始终不能越过 y=x 的路径数 = G(n)

### 5. 广义 Catalan：给定 a 个左括号与 b 个右括号，a>=b>=0，要求前缀中 cnt('(')>cnt(')') 的路径条数 = C(a + b, b) - C(a + b, b - 1)

### 6. 经典 Catalan 计数模型：以下问题的答案均为 G(n)
- n 对合法括号序列
- n 个节点的不同有序二叉树形态
- n 个不同元素组成的 BST 形态
- 1..n 按顺序入栈时，不同合法出栈排列
- 凸 (n + 2) 边形划分为三角形的方案数
- 圆周上 2n 个点两两配对，连线互不相交的方案数
- n 条边的有序有根树形态
本质通常是「合法前缀限制」或「选择一个根，将结构拆分为独立的左右两部分
