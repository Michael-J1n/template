## 记忆化搜索与寻找重叠子问题

1. 动态规划的核心在于重叠子问题。例如，把字符串 s 变成回文的最小插入字符数量：定义 f(l,r) 为把 s[l..r] 变回文的最小插入数
如果 s[l]=s[r]，子问题是 f(l+1,r-1)；否则，插入一个，有两个插入位置，从而两种子问题求最小值：min(f(l+1,r),f(l,r-1))
记忆化搜索时记得用**memo值**以及basecase的处理

2. **双序列问题** 看到这样一类题：给定两个字符串，求之间的前缀/匹配/距离等量，可以直接无脑定义状态为：**f(i,j) 代表考虑 s 的前 i 个字符和 t 的前 j 个字符**之间的量，e.g.某距离，匹配长度..一般转移有这么三种情况：cost+f(i-1,j), cost+f(i,j-1), cost+f(i-1,j-1)

3. 有一类题类似**双端队列，每次可以在最左侧操作或在最右侧操作，这会产生重叠子问题，直接考虑 dfs(0,n-1)** 即可

有时候这类题还**需要记录最后操作的是左侧还是右侧**。例如关路灯的问题【P1220】或套牛【P3080】或序列【P10326】；
以关路灯为例：初始在点 c，每个点有离源点的距离和单位耗能，求从起点开始到关掉所有灯为止的最少耗能。
这个过程，思考一下可以发现，从 c 开始每次向左扩展或向右扩展，且永远不会跳过一个灯去关更远的。因此是一个**不断左右扩展的区间**，可以枚举最后一个被关掉的灯。
考虑一个类似 dfs(l,r) 的记忆化，但在转移时发现不仅需要 dfs(l+1,r),dfs(l,r-1) 的信息，还需要知道在这个子区间最后停留在了哪里。因此再加一维状态：
定义 dfs(l,r,0/1) 为从 c 开始扩展，只关掉了灯 [l..r]，且最后停在灯 l/r 时的当前全局最小累计能耗。
那么按照两个区间信息再加上额外的路程时间乘以所有还没关掉灯的单位耗能总和作为额外代价。这个用前缀和维护即可。

另一个以此为母题的类似问题是排队求原序列问题【P3205】；也就是**给定一个序列，每次讨论最后一个放进来的是最左侧元素还是最右侧元素**。
对于一个身高各不相同的队列，从前往后把人取出来，如果比前面的人矮就放到新序列最左侧，否则放到最右侧。
现在给定结果队列，求原序列有多少种可能性。对于一个序列，考虑最后一个人是加入了左侧还是右侧，然后就变为这种双端队列类似的母题
可以定义 dfs(l,r,0/1) 为对于序列 [l..r] 且最后一个入队的是 l/r 所对应原序列方案数。那么通过讨论 a[id],a[L],a[R] 的大小关系进行加法原理的转移。
这里唯一要注意的是 base case，dfs(l,l,0) 和 dfs(l,l,1) 如果都选 1，那么会产生 double counting 的问题，因此要修改为 if(l==r)return p==0;

这类母题的模板：
```CPP
vector memo(n + 1, vector(n + 1, vll(2, -1)));
// dfs(l,r,p): 考虑区间 [l..r]，最后在 l/r 的当前总花费最小值
auto dfs = [&](this auto&& dfs, int l, int r, int p) -> ll {
    if (l == r) {
        if (l == pos) return 0;
        else return LINF;
    }
    if (memo[l][r][p] != -1) return memo[l][r][p];
    auto& res = memo[l][r][p];
    int L = l + (p == 0), R = r - (p == 1), id = p == 0 ? l : r;
    int rem = n - (R - L);
    res = min(
        dfs(L, R, 0) + abs(a[L] - a[id]) * rem,
        dfs(L, R, 1) + abs(a[R] - a[id]) * rem);
    return res;
};
```

4. **拿数博弈**【P1430】一个序列，一个操作可以任选左端或右端然后拿任意数，可以拿光但不能两端都拿。求先手能获得的最大值。
一个暴力的想法是定义 dfs(l,r) 为先手在 (l,r) 上能拿的最大值，那么再枚举拿到的点，剩下的和再减去后手局面的最大值即为后续还能拿到的分数。但这是 n^3 的，太慢了
不妨设就拿左端点，那么实际上自己能得到的分数就是区间和减去后手局面能获得分数里的最大值：
dfs(l,r) = max_{i=l+1,..,r+1}(sum(l..r) - dfs(i,r)) = sum(l,r) - min(dfs(l+1,r),...,dfs(r,r),0)
同理如果拿右边的，有 dfs(l,r) = sum(l,r) - min(dfs(l,r-1),...,dfs(l,l),0)

因此只需要在计算的时候提前把最小值算出来即可。因此换成 dp[l][r]，定义一个 mn[l] = min(dp[l][l],dp[l][l+1],..,dp[l][r])
将 r 从小到大枚举，l 从大到小枚举，先计算 dp[l][r] = sum[l][r] - min(mn[l],cur)，
再更新：cur=min(cur,dp[l][r]), mn[l]=min(mn[l],dp[l][r])
考虑这个的意义：cur 维护了拿左边给后手留下的局面，mn[l] 维护了拿右手边的给后手留下的局面
在计算到 [l,r] 时，cur 已经计算了所有 dp[l+1][r],dp[l+2][r],...,dp[r][r] 的最小值（l从大到小枚举保证）；而 mn[l] 已经计算了所有 dp[l][l],dp[l][l+1],...,dp[l][r-1] 的最小值（r从小到大枚举保证）
有时候这样的更新如果太绕，可以画nxn的二维表并在表上看最小值的维护路径

5. **回文串相关** 有一类题目与字符串和回文串有关。
例如 【P3847】给序列，经过编辑后变为回文的最小操作次数。套路的定义 dfs(l,r) 为把 [l..r] 变为回文的最小次数
base为l>=r时为0；如果a[l]==a[r]，那么就 dfs(l+1,r-1)，否则要取 min(dfs(l+1,r),dfs(l,r-1),dfs(l+1,r-1))+1（编辑距离的经典转移）

## 区间 DP 相关

对于一个问题，考虑**第一次决策后，左右会形成两个更小区间的子问题**，这时候就应该使用区间 DP。这个决策的位置就是内层循环中枚举的 k。
转移时分两部分考虑：**左右两个区间子问题的值，和当前这次决策的代价**（eg合并两堆的代价等）
或者有些题目，有关**区间合并/合成/消消乐的过程**，通常都是区间dp，内层循环枚举最后一次合并/合成的位置

1. 有时候考虑小区间是如何生成的很有用；例如【P1622】的释放囚犯，观察到 Q<=100 对于位置使用区间dp：因为选择第一个释放的人后，左右两边就被分开了，各自进行子问题。因此可以定义 f[l][r] 为释放 a[l]..a[r] 的囚犯的最小代价。决策是第一个释放的囚犯 a[k]，把原区间分割成了两个区间。但是选择 k 带来的代价是什么？如果是全局的第一次决策，那么就是总个数减去1。否则是一个分裂过来的区间，那么一定会保证 a[l-1],a[r+1] 已经被释放掉了之后才会递归来考虑这个区间（-1和n是哨兵）。因此可以有代价 a[r+1]-a[l-1]-2。

2. 区间 DP 的决策点含义很多，并且不只是对于区间的划分，例如加分二叉树这一题的 k 就是在枚举当前中序 [l..r] 中让谁当根。分下来的两个子区间刚好对应左右两个子树。对于区间划分，也有两种不同的决策：一个是类似释放囚犯那样，问题被第一次决策后划分成了两个独立的区间，再分别在区间中继续操作形成子问题，这需要枚举第一个决策点是谁。另一个是类似石子合并的，从很多元素不断merge后变为一个整体，这需要枚举最后一个分界点，即为最后一次操作之前它左右两边是分别独立操作的。

3. **环上的区间 DP**：对于环上的问题，处理办法就是把原数组**复制在后**形成两倍数组，然后 len 只枚举到原数组长度，但是左端点可以一直从0到2n-1。在 len=n 的时候用 f[l][r] 更新答案即可，答案就是环上任意选起点的最优值

4. **填写符号，括号自由组合**这类母题：枚举最后一个填写的符号【P1388】。有时候记忆化搜索会更好写，dfs(l,r) 的内部枚举 k

5. 区间 DP 确定 [l,r] 后，内部的**决策点可以根据具体性质简化枚举**。例如合并饭团【P4677】，如果两个相邻饭团大小相同，或者两个相邻大小饭团中间隔了一个饭团，那么就可以合并。
类似合并石子但是没有了中间的多余能量贡献，因此可以看出如果 [l,r] 可以合并，得到的结果一定是 sum(l..r)
因此考虑状态定义，注意到一段 [l,r] 要么可以合并成一个，结果为sum，要么不行，所以可以直接定义 dp[l][r] 为**是否可以合并 [l..r]**（价值固定时的可行性 dp）
在固定 [l,r] 后考虑中间决策点，如果 [l,r] 可以合并，那么一定是类似这样的情况：[l..i][i+1..j-1][j..r]，其中 sum[l..i]=sum[j..r] 且 dp[l][i] 且 dp[j][r]，中间段没有要求（甚至可以 i+1=j，代表相邻合并中间没有别的饭团）。
而所有值是正数，所以不用双重循环枚举 i,j，可以直接双指针移动 ，在 sum 相等且都可行时更新答案：
```CPP
vector can(n, vector<char>(n));  // can[l][r] = l 到 r 是否可以合并；如果可以，合并后大小即为 sum(l..r)
for (int i = 0; i < n; ++i) can[i][i] = 1;
for (int len = 2; len <= n; ++len) {
    for (int l = 0; l + len - 1 < n; ++l) {
        int r = l + len - 1;
        int pl = l, pr = r; 
        long long sl = a[l], sr = a[r];
        while (pl < pr) {
            if (sl < sr) ++pl, sl += a[pl];
            if (sr < sl) --pr, sr += a[pr];
            if (pl < pr && sl == sr) {
                can[l][r] = can[l][pl] && can[pr][r] && (pl + 1 == pr || can[pl + 1][pr - 1]);
                if (can[l][r]) break;
                else ++pl, --pr, sl += a[pl], sr += a[pr];
            }
        }
    }
}
```

6. **折叠字符串**类型的【P4302】，给定一个长度<=100的字符串，AA 可以折叠为 2(A)，ABABAB 可以折叠为 3(AB)，以此类推，求这个字符串的折叠字符串中表达式最短的长度是多少。
套路的定义 dfs(l,r) 为将 s[l..r] 折叠出的最短长度。考虑对于这个区间，要么是通过多个折叠式拼接，要么自己是一个折叠式；
对于情况1，首先可以枚举最后一次分割点然后拼接左右两个的dfs值
对于情况2，那么枚举这个目标串，然后用周期性检查是否成立。如果可以，计算这个目标串的dfs，再加上它的cnt的位数以及括号带来的长度2 来更新答案


## 状压 DP 相关

1. 糖果问题：给定 n 个组合（n<=20），每个组合里有一些糖果口味，求凑齐所有口味使用的最少组合数
思考如何定义状态。一般来说，**要求什么，状态的值就设置为什么**，因此记 f[mask] 为凑齐口味 mask 使用的最少组合数；
转移时，nmask=mask|a[i]，其中 a[i] 是组合i中的口味集合，因此 f[nmask]<-f[mask]+1 即可。

2. **关灯问题（重要）**【P4906,2622】
给一个长为 n(<=20) 的数组 a，a[i] 代表按下开关 i 后实际会 toggle 的开关集合。求关掉所有开关的最小开开关次数
由于 n 很小，考虑状压。求什么设什么，定义 f[mask] 为使开关 mask 全部被关掉的最小开开关次数
转移时当前已经关掉了 mask，现在开开关 a[i]，那么 nmask = mask ^ a[i]，f[nmask] <- f[mask] + 1。初始值 f[0]=0.
然而，注意到这个 nmask 可能比 mask 小，因此不是 DAG，所以不能 DP 更新！但是注意到这实际上是从 0 开始，在一个边权为 1 的可能有环的路上走，走到节点 (1<< n)-1 的最短路，**直接 BFS 更新即可，节点代表 mask，距离代表 dp 值**（如果正边权不一定是1，改成dijkstra）
```CPP
int N = 1 << n;
vi f(N, INF); f[0] = 0;  // f[mask] = 关掉灯集合为 mask 时最少需要的灯数
queue<int> q; q.emplace(0);
while (!q.empty()) {
    int mask = q.front(); q.pop();
    for (int i = 0; i < n; ++i) {
        int nmask = mask ^ a[i];
        if (f[nmask] > f[mask] + 1) {
            f[nmask] = f[mask] + 1;
            q.emplace(nmask);
        }
    }
}
```
如果是相邻关的话，可以利用特殊性质：【P10449】网格图，给定初始开关局面，每次开关灯只影响有邻边的格子的状态。求全开的最小次数。
如果用正常 BFS，在多测下会超时。思考特殊性质，可以只枚举第一行的开关法（1 << n 种），那么对于下面的行中的数，如果它正上方没有被开，这个格子一定要被按（否则上面的格子永远不会被开）
因此只用枚举第一行的按压状态，后面几行的操作是完全确定的，只需要对应的模拟即可。最后判断全局是否都开来更新答案。

3. **枚举排列转化成状压 DP**【P2210】给牛位置和对应边两端点，求一个排列使边长总和最小。n<=12。
如果直接枚举全排列，再去看每条边的贡献，会得到 n*n! 的复杂度，无法接受。思考如何把排列的信息压缩到状压中
关键观察在于，每条边的长度为这条边跨越的分界数量。
对于暴力做法，是固定排列后，对于每个边，计算跨过的边界数。横看成岭侧成峰的，也可以对于每一个分界，统计有多少边跨过了这条分界线。
因此可以定义状态 f[mask] 代表 **mask 中的牛以某种排列在前 |mask| 个位置的前缀最小代价**，那么转移即为计算经过这个分界线的边数。
这可以额外定义一个 cut[mask] 代表 mask 中的牛在左半部分（前 |mask| 个位置），剩下牛在右半部分，有多少边的两端点落在不同的部分即可。有 f[nmask] <- f[mask]+cut[nmask]

在希望使用状压 DP 优化全排列时，关键是找到一个量使得只和前 |mask| 排的和后 |mask| 排的代价贡献能够在分界线处统计，并和两边的具体顺序无关。

4. 选择状压的维度：对于 nxm 棋盘题，枚举较大的边长，状压较小的边长

5. **装箱问题（重要）** 给定一个重量数组 c，和单次最大载重 W；求最少需要几次可以运送这些物品。
这是 NPC 问题，但可以通过状压解决：首先可以想到一个类似 f[mask]=运送mask物品需要的最少次数，但发现不好转移：转移需要知道上一次运送的载重
因此把状态值改成一个二元组：f[mask] 代表运送 mask 中的物品，第一维是运送需要的最少次数，第二维是在最少次数下最后一次运送的最小总重
那么加入一个新的物品，如果能放下就放，否则单开一次。
```CPP
// c 是长为 n 的物品重量数组
int N = 1 << n;
vector<pair<int, ll>> f(N, {INF, INF});  // f[mask] = 装 mask 中的奶牛需要的最小电梯数，以及此方案下最后一班电梯的最小总重
for (int i = 0; i < n; ++i) f[1 << i] = {1, c[i]};
for (int mask = 0; mask < N; ++mask) {
    for (int i = 0; i < n; ++i) {
        if (mask >> i & 1) continue;
        auto& [cnt, sum] = f[mask];
        int nmask = mask | (1 << i);
        pair<int, ll> cand;
        if (sum + c[i] > W) cand = {cnt + 1, c[i]};
        else cand = {cnt, sum + c[i]};
        f[nmask] = min(f[nmask], cand);
    }
}
cout << f[N - 1].first << endl;
```
考虑一个变式【P5911】，给定 n 个人，每个人有重量以及自己的过桥时间。给定桥的最大载重，求所有人过桥的最少总时间（分批过桥，一批过桥的时间是之中所有人时间的最大值）。
这个题不能像上文那样再定义一个三元组比较，因为最后一组最大时间最小和最后一组重量最小两个状态不是互相等价的。
换一个思路，还是求什么定义什么，定义 f[mask] 为 mask 中的人过河的最短时间。但是改变转移策略：
首先预处理出 sum[mask]=mask中人总重，mxt[mask]=mask中人最大时间
**对于每个 mask，枚举它的最后一组子集 s**，从 pmask=mask\s 的集合加上 s 的贡献进行转移。时间复杂度 O(3^n).
```CPP
int N = 1 << n;
vi sum(N), mxt(N);
for (int mask = 1; mask < N; ++mask) {
    int i = __builtin_ctz(mask);
    int pmask = mask ^ (1 << i);
    sum[mask] = sum[pmask] + w[i];
    mxt[mask] = max(mxt[pmask], t[i]);
}
vi f(N, INF); f[0] = 0;  // f[mask] = 运走 mask 中的人的最小时间
for (int mask = 0; mask < N; ++mask) {
    for (int s = mask; s; s = (s - 1) & mask) {  // 枚举运走的最后一组
        if (sum[s] > W) continue;
        int pmask = mask ^ s;
        f[mask] = min(f[mask], f[pmask] + mxt[s]);
    }
}
cout << f[N - 1] << endl;
```

6. **维度优化**【P4329】给定 n 行 n 列，行代表人，列代表任务，值代表这个人完成这个任务的成功概率。给每个人分配恰好一个任务，求所有人都完成任务的最大概率
套路的定义 f[i][mask] 为考虑了行 0..i，完成的任务集合为 mask 的最大概率。然而，注意到 i=popcount(mask)，因此可以省去第一个维度：
```CPP
vector<double> f(N, 0);
for (int j = 0; j < n; ++j) f[1 << j] = p[0][j];
for (int mask = 0; mask < N; ++mask) {
    int i = __builtin_popcount(mask);
    for (int j = 0; j < n; ++j) {
        if (mask >> j & 1) continue;
        int nmask = mask | (1 << j);
        f[nmask] = max(f[nmask], f[mask] * p[i][j] / 100.0);
    }
}
```

7. **Hamilton 问题**：定义 f[mask][i] 为经过点为 mask，最后一个到达的点是 i 的状态值（代码参考 图论-搜索-哈密顿路）

考虑一个变式【P8733】：给定 n 个平面点，每次只能走不超过 D 的距离，求从 0 开始，经过所有点（可以重复经过一个点），最后回到 0 的最短总距离。
首先考虑平面点对的距离。计算出 dis 数组，dis(i,j) 代表 i-j 之间有边时的边长（否则为 INF）（这是因为显然 >D 的边是没有任何用处的）。
由于这个问题比较像哈密顿回路并且数据范围很小，套路的定义 f[mask][i] 为经过了 mask 中的点，最后停在点 i 的最小总距离。
在转移中，枚举下一个可能点 j。那么就需要知道 i 到 j 之间的最短距离。由于允许重复经过点，因此可以直接使用 dis 数组上进行 **Floyd 更新，将 dis[i][j] 松弛**为 i 到 j 的最短路
那么转移枚举下一个不在 mask 中的点 j（**在 mask 没必要再去，除非是作为中转点，这在 Floyd 松弛中已经被考虑**），有 f[nmask][j] <- f[mask][i] + dis[i][j]
最后取 f[N - 1][i] + dis[i][0] 的最小值即可。

## 背包 DP 相关

背包 DP 最重要的思想：考虑一个物品**选或不选**。
经典问题类型：一个维度给最大/小限制，最大/小化另一个维度。状态设计：**以限制为维度，希望最大化的值为dp值**，例如 dp[v] 表示体积为 v 时的最大值，v 自然从 0 到限制
如果求恰好问题，把所有状态除了0设置成不可达。如果求至多，所有状态都设置成可达初态；如果求至少，用上限截断
在使用 nf 和 f 时的初始化，nf=f 代表可以继承当前不选的状态；否则如果新建一个初态的 nf，代表当前这个必须选一种操作执行

1. **多个维度限制**【P1507】
例如：同时给定体积与质量限制，求最大价值：定义 f[x][y] 为体积最多 x，质量最多 y 的最大价值，转移有 f[x][y]<-f[x-v[i]][y-m[i]]+v[i]

2. 分次转移【P1802】
给定药水总量，打败一个人需要使用的药水，获胜获得的经验值，失败获得的经验值，求可获得的最大经验值
对于每个人，打或不打，打了消耗 u[i] 的药水获得 w[i] 经验，否则不消耗药水获得 l[i] 经验
先枚举每个人，遍历所有药水总量 j，j 从 T 到 u[i]，可以打或不打，有 f[j] = max(f[j]+l[i], f[j-u[i]]+w[i])
但是注意，j 从 u[i]-1 到 0，总还是可以不打并获得 l[i]，有 f[j]=max(f[j],f[j]+l[i])

3. 凑数问题【P1679】
给定一个数，求最少用多少个符合某性质的数凑出。
这一类题，先预处理打表所有在值域范围内的符合性质的数，然后做完全背包，f[i]代表凑出恰好i需要的最少数，转移为 f[i]=min(f[i],f[i-x]+1)（想象成容量恰好型，单位代价为1，求最小代价））

变式：限制选数的个数【P1586】最多选四个平方数，凑出 m 的方案数。多开一个维度记录现在选了几个数：f[i][j] 代表选了 i 个数，凑出 j 的方案数
那么转移即为 f[k][j]+=f[k-1][j-v[i]]

4. 有关值域，想可行性【P1877】
给定初始音量 st，和序列 c，每次必须调整 c[i] 的音量，可以升高也可以降低。但是给定最大值 mx 和最小值 0，不能调到这个范围之外。求最后操作好后最大可能音量
注意到有限制且有重叠子问题，想线性dp，但发现需要记录值域可达性，因此用背包类似的方法进行值域可达性转移：
假设当前 c[i]，那么对于每个值 j，如果 j 可达，那么 j+c[i], j-c[i] 如果在范围内就可达。进行转移即可
但要注意，不能继承之前的所有状态，因此没做一轮要新开一个 nf 来记录新值域可达性，再 f=move(nf) 换回去

5. **顺序有关**【P2840】
给定 n 个面值的钱，每个可以用无限张，求凑出给定的总额 W 的方法数，但是顺序不同算不同方法
只需要**调换二重循环顺序**（第一重枚举体积，第二重枚举物品）即可，更新还是按照背包的更新方法

6. 砝码称重问题【P8742】
给定砝码重量列表 w，求可以称出的最多重量（天平两边都可以放砝码）
对于可行性问题，可以在值域上建立一个 bitset 后进行背包转移。然而注意这道题的转移：对于之前的重量 d 和当前重量 w，会有三种情况：d, d+w, d-w；对应不懂，左移，和右移。
然而，bitset 会截断右移到负数的位置，而这部分未来可能会被补回来，所以可以建立一个大小 MX*2+1 的 bitset，其中 f[MX+d] 代表 d 这个重量可行。初始有 f[MX]=1
注意答案要 -1 再除以 2（减去重量0，剩下的正负对称出现）
```CPP
bitset<MX << 1 | 1> f; f[MX] = 1;
for (int i = 0; i < n; ++i) {
    f |= (f << w[i]) | (f >> w[i]);
}
cout << ((f.count() - 1) >> 1) << endl;
```
（注：另外的做法是先把所有左移操作做掉，再循环每个 i 进行右移操作，这样 bitset 就只用开 MX 了）

7. **上限截断【P11377】**
给定 n 个物品的体积和价值，以及 P，求体积不小于 P 时的最小价值。对于所有大于 P 的状态，都和 P 是等价的，因此截断后可以合并。
定义 f[i] 为体积为 min(P,i) 时的最小价值，做带截断的转移即可：
```CPP
vll f(P + 1, LINF); f[0] = 0;
for (int i = 0; i < n; ++i) {
    for (int j = P; ~j; --j) {  // 如果是完全背包，改成正序枚举【P2918】
        if (f[j] == LINF) continue;
        int nxt = min(P, j + p[i]);
        f[nxt] = min(f[nxt], f[j] + c[i]);
    }
}
```

8. **值域偏移**
例1【P2340】
给定 n 个物品，有两个值 {a[i],b[i]}（可能是负数）。选择任意件不同物品，在 suma 和 sumb 均为正时，求 max(suma+sumb)
定义 f[v] 为 suma=v 时，最大的 sumb。但有个问题：当前的 suma 可能是 <0 的。因此可以定义 f[MX + d] 为 suma=d 时最大的 sumb
那么考虑一个物品 {a,b} 选或不选，不选继承老状态，选了的话 suma'=d+a，此时 suma'=d+a 的最大 sumb 由 suma=d 时最大的 sumb 加上当前的 b 转移而来
而由于 suma' 会变小，如果原地更新会导致串联，因此需要开一个 nf 来记录
```CPP
vll f(MX << 1 | 1, -LINF); f[MX] = 0;  // f[MX+d1] = 智商和为 d1 时最大的情商和
for (int i = 0; i < n; ++i) {
    auto nf = f;
    for (int d = -MX; d <= MX; ++d) {
        if (f[MX + d] == -LINF) continue;
        int nd = d + a[i];
        if (!(-MX <= nd && nd <= MX)) continue;
        nf[MX + nd] = max(nf[MX + nd], f[MX + d] + b[i]);
    }
    f = move(nf);
}
ll res = 0;
for (int d = 0; d <= MX; ++d) {
    if (f[MX + d] < 0) continue;
    res = max(res, f[MX + d] + d);
}
```

例2【P13018】
给 n 个物品，有两个值 {a[i],b[i]}。选择任意个物品，求选出的 suma==sumb 时最大的 suma+sumb
首先值域较大，直接开两个维度无法接受。考虑把一个值放在状态中，另一个值设为状态值。但发现如果记 f[j] 表示 suma=j 时最大的 sumb，这样会忽略掉很多有用的状态，导致无法更新答案
但是思考求什么设什么，可以定义它们的差：定义 f[d] 为 suma-sumb=d 时，最大的 suma+sumb；这样转移很方便，且不会忽略掉有用的状态。最后 f[0] 是答案
然而，由于 d 可能<0，要使用 MX 偏移 + nf 转移。

还有一个值域偏移加上**状态-值反演trick**（见后文） 的题目【P2080】
给定两个人和 n 个事件，每个事件会给两人值带来增益（可能为负）。求两人最终值总和不低于给定数 W 时，最小的绝对差是多少
n 个事件可以选或不选，因此是个类似0-1背包的问题。根据求什么设什么，设 f[v] = 最终值为 v 的最小绝对差
然而考虑转移，v+a[i]+b[i] 为最终值，但是新的状态绝对差不能从之前的和中推出，无法转移。
但是，如果把状态和值相反：记 f[d] 为绝对差 d 时的最大和呢？转移计算新和可以很方便的把 a[i]+b[i] 加上，但是绝对差无法转移到新的绝对差！
这时候要再利用一个偏移量的 trick，记 f[MX+d] 为差为 d 时的最大和
这时候对于事件 (a[i],b[i])，新的差为 d+a[i]-b[i]，新的和为 f+a[i]+b[i]，可以转移。

9. 值域的反问题：凑面值问题【P2725】
给定 n 个不同值以及 k，求最大 m 使得面值 1~m 都可以用不超过 k 个元素凑出来
定义 f[i] 为值 i 需要的最小凑出元素，那么有背包 f[i]=min{f[i-a[j]]+1}，只需要扫描到第一个 f 值 >k 的元素即可。注意到值域范围最大到 k*max(a)

这启发我们，对于值域问题，**如果给定数值求值域，用可行性dp（可能bitset优化）；如果给定值域和元素值，求凑出来的方案数/最大/小元素数量凑出，定义 f[i] 为凑出相关的量的需要元素/方案数**
例2【P2214】，给定值和总和，求需要多少个元素能凑出这个总和。定义 f[i]为凑出i的最少元素数量，然后转移即可

13. **有激活代价的**背包【P11430】
给定 n 个游戏，学习一个游戏需要 p[i] 的时间，学习后才能玩（可以无限次），玩一次时间 t[i] 收益 o[i]。求在给定时间 m 内安排学习游玩获得的最大收益
朴素的定义 f[j] 为使用了 j 的时间获得的收益，转移中可以一次01背包来模拟第一次学习+玩，再用一个完全背包在学习后的状态上进行转移。然而问题是，第二次完全背包时不知道之前的状态是否是学习过的状态（可能之前取max没取到，这样会导致答案偏大）。
解法是每一层都额外定义一个数组 g，其中 g[j] 代表使用了 j 的时间，并且对于当前游戏学习过且至少玩过一次的最大价值
第一次转移是01背包：使用 p[i]+t[i] 的代价收获 o[i]，且之前是没有学习过的，因此从 f 上转移。
第二次转移是完全背包：每次可以用 t[i] 的代价收获 o[i]，直接在 g 上原地转移。
做完后 f 与 g 取最大值即可：
```CPP
vll f(m + 1, -LINF); f[0] = 0;  // f[j]=用了时间j的最大得分
for (int i = 0; i < n; ++i) {
    vll g(m + 1, -LINF);  // g[j]=用了时间j且至少玩过一次当前游戏的最大得分
    for (int j = m; j >= p[i] + t[i]; --j) g[j] = max(g[j], f[j - p[i] - t[i]] + o[i]);
    for (int j = t[i]; j <= m; ++j) g[j] = max(g[j], g[j - t[i]] + o[i]);
    for (int j = 0; j <= m; ++j) f[j] = max(f[j], g[j]);
}
cout << ranges::max(f) << endl;
```

14. **状态-值反演**【P14920】
给定 n 个物品，每个价值 a[i]，代价 c[i]，给定总钱数求最大价值；a<=500, c<=1e9
对于普通的背包，定义 f[j]=花费j的最大价值，有 f[j]<-f[j-c[i]]+a[i]，但是注意 c 是 1e9 的，直接TLE
因此可以将**状态的维度值和状态的值调换**：定义 f[j]=得到价值j 的最小代价，那么有 f[j]<-f[j-a[i]]+c[i] 即可
```CPP
// W<=1e5, v<=1e9
vll f(W + 1);  // f[j]=容量为j的最大价值
for (int i = 0; i < n; ++i) {
    for (int j = W; j >= w[i]; --j) {
        f[j] = max(f[j], f[j - w[i]] + v[i]);
    }
}
cout << f[W] << endl;

// w<=1e9, v*n<=1e5
vll f(MX, LINF); f[0] = 0;  // f[j]=价值为j时最小容量
for (int i = 0; i < n; ++i) {
    for (int j = MX - 1; j >= v[i]; --j) {
        f[j] = min(f[j], f[j - v[i]] + w[i]);
    }
}
for (int j = MX - 1; ~j; --j) {
    if (f[j] <= W) {
        cout << j << endl;
        return;
    }
}
```

15. **完全背包使用 bitset** 优化可达性【P15353】

```CPP
bitset<MX> f; f[0] = 1;
for (int i = 0; i < n; ++i) {
```

16. 不同的操作选择【P1156】
不同于普通背包的选或不选，还有一类是选择做a，或者选择做b。例如这题，可以吃或可以搭建
先按照时间顺序排序后，做如下背包：定义 f[j]=高度j的最晚存活时间（如果定义f[d]=时间d的最大高度，不好转移）
那么每个元素可以选择搭建或者吃。这种可以不同选择的题，最好不要原地更新，**开一个新数组nf**然后从f进行层间转移。这样可以**避免不同选择之间的串联更新**。
注意细节，这里 nf 开的是初始态而不是继承 f，这是为了避免每个元素不能不做任何操作的情况。
第二个细节是这里由于会出现上限截断的情况，用 nxt 式的转移（nf[j+h]=max(nf[j+h],f[j])；方便有截断发生时候直接输出）
```CPP
vi f(D, -INF); f[0] = 10;  // f[j]=高度j时最晚存活时间
for (int i = 0; i < n; ++i) {
    int t = a[i].t, v = a[i].v, h = a[i].h;
    if (f[0] < t) {
        cout << f[0] << endl;
        return;
    }
    vi nf(D, -INF);
    // 搭建
    for (int j = D - 1; ~j; --j) {
        if (f[j] < t) continue;
        if (j + h >= D) {
            cout << t << endl;
            return;
        }
        nf[j + h] = max(nf[j + h], f[j]);
    }
    // 吃
    for (int j = D - 1; ~j; --j) {
        if (f[j] < t) continue;
        nf[j] = max(nf[j], f[j] + v);
    }
    f = move(nf);
}
cout << f[0] << endl;
```

17. **流水线加工问题**（job scheduling）
- 题型1：最大化收益【P16300】
给定 n 个任务，有加工时间，截至时间，以及加工的收益。每个都可以选择不加工或在a加工或在b加工，但前提是在截止时间前。求最大收益。
定义 f[j][k] 为机器a在j结束，机器b在k结束的最大收益。
对于一个机器，假设他在机器a加工，那么 f[j][k]<-f[j-t][k]+r，前提是 j 在截止时间前。在机器b加工同理。
```CPP
struct Event {
	int p, d, r;  // 加工时间，结束时间，收益
};
ranges::sort(a, [&](const auto& a1, const auto& a2) {
    return a1.d < a2.d;
});
vector f(MX + 1, vll(MX + 1, -LINF)); f[0][0] = 0;  // f[j][k]=一号线在恰好时间j结束，二号线在恰好时间k结束的最大收益
for (int i = 0; i < n; ++i) {
    int p = a[i].p, d = a[i].d, r = a[i].r;
    for (int j = MX; ~j; --j) {
        for (int k = MX; ~k; --k) {
            if (p <= j && j <= d) f[j][k] = max(f[j][k], f[j - p][k] + r);
            if (p <= k && k <= d) f[j][k] = max(f[j][k], f[j][k - p] + r);
        }
    }
}
ll res = 0;
for (int j = 0; j <= MX; ++j) {
    for (int k = 0; k <= MX; ++k) {
        res = max(res, f[j][k]);
    }
}
```

- 题型2：最小化时间【P2224】
给定 n 个任务，以及任务在机器a的加工时间，机器b的加工时间，以及一起的加工时间。求加工完所有零件的最小的总时间（max(a时间，b时间)）
每个任务要么在a加工，要么在b加工，要么一起，是《16不同操作选择问题》；框架可以使用 f/nf 类型的。这题值域大，如果类似上文题型1那样开两个下标就超时了
但是考虑定义 f[j] 为考虑到当前所有机器都加工过了，a 机器用时 j 时 b 机器的最少总时间。
对于转移，如果用机器a，那么 nf[j]<-f[j-t1]；如果用机器b，那么 nf[j]<-f[j]+t2；否则，nf[j]<-f[j-t3]+t3；**这三种转移也很重要！！**
注意 nf 要开初态，因为每个机器一定要选一种方案
```CPP
vi f(MX + 1, INF); f[0] = 0;  // f[j]=A时间为j时B的最小时间
for (int i = 0; i < n; ++i) {
    int t1 = a[i].t1, t2 = a[i].t2, t3 = a[i].t3;
    vi nf(MX + 1, INF);
    // 选择a做
    if (t1) {
        for (int j = MX; j >= t1; --j) nf[j] = min(nf[j], f[j - t1]);
    }
    // 选择b做
    if (t2) {
        for (int j = MX; ~j; --j) nf[j] = min(nf[j], f[j] + t2);
    }
    // 选择一起做
    if (t3) {
        for (int j = MX; j >= t3; --j) nf[j] = min(nf[j], f[j - t3] + t3);
    }
    f = move(nf);
}
int res = INF;
for (int j = MX; ~j; --j) {
    res = min(res, max(j, f[j]));
}
```

18. **可变收益问题**【P1417】
在传统背包中，选择一个物体的代价是固定的 v；那么体积最大的代价即为 f[j]=max(f[j-c]+v)
在P1417类似的题目中，**代价是一个变量，要通过邻项交换贪心排序后再做背包**
题意：给定 n 个物品，每个有 a,b,c 三个量，最多只能用一次。完成这个物品需要 c 的时间，而在时间 t 完成会获得 a-t*b 的收益。求给定总时间 T 可以获得的最大收益
考虑如果物品的收益是定值，那么假设 f[j]=时间j取得的最大收益，有 f[j]=max(f[j-c]+val)，做一个 n*T 的零一背包即可。

然而，传统背包规定了物品被装入的顺序，因此不同顺序进行背包的收益不一样。而这道题的收益和结束的时间有关，所以要先确定最大收益的顺序，再做背包。
假设先做 i 再做 j 比先做 j 再做 i 收益大，那么有 ai-cibi+aj-(ci+cj)bj - (aj-cjbj+ai-(ci+cj)bi) > 0，得到 cjbi>cibj
因此按照这个来排序，再进行一次零一背包，即为最大答案。
一般的，这类可变收益使用邻项交换，排序的返回值填写**先1再2的收益-先2再1的收益>0**这条不等式即可
```CPP
ranges::sort(v, [&](const auto& v1, const auto& v2) {
    int b1 = v1.b, c1 = v1.c, b2 = v2.b, c2 = v2.c;
    return 1LL * c2 * b1 > 1LL * c1 * b2;
});
vll f(T + 1, -LINF); f[0] = 0;  // f[j]=时间j的最大价值
for (int i = 0; i < n; ++i) {
    int a = v[i].a, b = v[i].b, c = v[i].c;
    for (int j = T; j >= c; --j) {
        f[j] = max(f[j], f[j - c] + a - 1LL * j * b);
    }
}
cout << ranges::max(f) << endl;
```

19. **动态01背包** 给定 Q 个操作，每次要么加入一个值为 x 的物品，要么减去一个值为 x 的物品，并且询问能恰好凑出值 k 的方案数。
为了推导清楚，对于新一层用 ndp 表示，之前的用 dp 表示；dp[v] 代表凑出值 v 的方案数。
对于加入，ndp[v] = dp[v] + dp[v-x]：每个凑出 v-x 的方案，加上这个 x，都能得到 v；再加上之前本来就能得到 v 的方案数即可。
更新的时候，由于 ndp[v] 依赖 dp[v-x]，因此需要倒序更新防止串联。
对于减少，ndp[v] = dp[v] - ndp[v-x]：ndp[v] 为去掉这一个 x 后得到 v 的方案数；原本得到 v 有 dp[v] 种方式，需要减去的方案为带上了这个 x 的方案；剩余重量为 v-x，但是考虑得到这 v-x 重量的方案也不能有这个 x 的出现，因此方案数是 ndp[v-x] 而不是 dp[v-x]。
更新的时候，由于 ndp[v] 依赖之前的 ndp，因此这里需要顺序更新来更新答案。
```CPP
if(op=='+'){
    //ndp[v]=dp[v]+dp[v-x]
    for(int v=k;v>=x;--v)(dp[v]+=dp[v-x])%=mod;
}else{
    //ndp[v]=dp[v]-ndp[v-x]
    for(int v=x;v<=k;++v){(dp[v]-=dp[v-x])%=mod;if(dp[v]<0)dp[v]+=mod;}
}
```
如果值域非常大，但是询问的最大值 k 不大呢：背包只需要开 k 大小即可。这是因为，观察两种情况更新时，dp[v] 只会依赖小于等于自己重量的状态（v以及v-x），因此保存更大的值域是没有必要的。

2. 【P4933】等差数列：给定一个数组，求**等差数列子数组个数**
由于这里的差会是负数，所以要加值域偏移量。下文省去值域维度的 MX+。定义 dp[i][x] 为以 a[i] 结尾，公差为 x，且长度至少为 2 的数列个数。固定 a[i] 时，枚举所有前序 a[j]；记 d=a[i]-a[j]，那么有：dp[i][d]+=dp[j][d]+1。第一项是由于 j 结尾差为 d 的数列后面加一个 a[i] 都会形成一个新的合法数列，再+1 是因为 (a[j],a[i]) 单独成为一个长度为2的数列。

3. 【P4310】结合位运算按位考虑：给定数列，求最长子数组使得任意相邻两项的与和都非0

4. 【P3147】相邻两项若都是x，可以合并为x+1。给定初始数组，求可以合并出的最大数值；n<=2^18,x<=40
首先有一个结论：如果一个区间可以合并，那么得到的结果是唯一的。
证明：注意 (x,x)->x+1 类似 2^x+2^x=2^{x+1}，这个区间有不变量 sum 2^{a[i]}：无论如何合并，这个量是不变的。因此，如果可以合并为一个数 y，那么 2^y=sum 2^{a[i]}，y一定是唯一的。
这一形式很像区间dp：定义 dp[l][r] 为 l..r 可以合并出的唯一数，那么枚举分界点 k，如果 dp[l][k]=dp[k+1][r]=x，那么 dp[l][r]=x+1. 然而，注意到 n 太大，这种情况肯定超时
由一开始的结论，并且注意到值域范围很小，考虑把值域加到状态上来：定义 dp[i][x]=以a[i]作为左端点，合并出值x的右端点（由于结论，这个右端点一定是唯一的）
初始化 dp[i][a[i]]，答案即为所有合法 dp[i][x] 对应的x的最大值。对于转移，考虑i到右端点r的值是 x，那么一定是由i-r'-r'+1-r 这样形式组成的，其中i-r'和r'+1-r 都合并出了 x-1。有：r'=dp[i][x-1]，r=dp[r'+1][x-1]，因此 dp[i][x]=dp[dp[i][x-1]+1][x-1]。
注意到这个形式和倍增很类似，因此直接外层循环枚举x，内层循环枚举i 来更新即可。
注意一个细节：所有数最大为40，长度为2^18，易知可以合并出的最大值即为40+log(2^18)=58，因此第二维度开这么大即可。

5. 【P1439】**两个排列的 LCS** nlogn 做法
传统的 LCS 问题需要花费 n^2 时间。现在给定两个 1~n 的排列，求他们的 LCS，有 nlogn 时间的做法：
首先先求出第一个排列 p1 的 pos 数组：pos[p1[i]]=i；再**把第二个排列改写为对应值在 p1 中的位置**：p2[i]=pos[p2[i]]
考虑 p2 的一个子数组，他单调递增当且仅当在 p1 中是一个从左到右的子数组。因此这个 p2 的 LIS 即为 p1 与原来的 p2 的 LCS 长度。

6. 如何设计状态？319c，1=a[1] < a[2] < ..< a[n], b[1] > b[2] >.. > b[n]=0。
假设当前满足 a[i]=0 的最大i为x，那么可以用 b[x]*a[j] 代价把一个不是 0 的 a[j] 变成 0。把a[1]变成0可以是免费的。求所有数变成0的最小代价
注意到当前数变成0的代价只会和最后一个为0的a中下标有关，并且，在将 a[n] 变成0之前一定不会走回头路，因为这对代价减少没有任何贡献；考虑用dp记录这个：
令 dp[i]=把a[i]变成0，并且i是最大的满足a[j]=0的下标的最小代价。那么dp[1]=0。
对于整个数列来说，如果 a[n] 变成0，那么 b[n]=0，后续都可以用 0代价满足，因此把 a[n]变成0的最小值等价于把所有数变成0的最小代价。答案即为 dp[n].
转移可以直接枚举所有 1<=j< i，用 dp[j]+b[j]*a[i] 更新即可，这可以用 CHT 优化到 nlogn 时间。

换句话解释这个题：考虑第一次一定将 a[1] 变成 0，最后一次一定将 a[n] 变成 0.
先变 a[1] 因为他免费；最后一次变 a[n]，由于获得 b[n] 后可以免费变剩下的
现在考虑这个claim：变化下标序列一定是一个从1开始n结束的递增链：
假设不是，那么其中有一个往回走的（例如 i->i+k->i+s, k>s），那么下一步的代价没有变化（还是 b[k]），但是对于 a[s]，明明是可以等到 b[n]=0 得到后免费变成0的
换句话说如果往回走，额外多花费了不该花的功夫，还没有把之后价格降下来，平白无故多了这份代价。
因此，这个题就清晰了，找到这一条链使得 f[n] 最小也就是很显然的线性 dp 了。
这启发我们对于题目还是要有感性理解和直觉处理以及贪心思想.

7. 【**重要经典模型**】给定一个长 n<5000 的序列，值 a[i]<=1e9; **一次操作可以对一个数+1或-1，求将序列变为非严格递增的最小操作次数**。
如果朴素的定义 f[i][j]=对于a[0..i]，将a[i]变为j的最小操作次数，需要 O(nV) 的时间，显然不行，考虑找特殊性质优化：
考虑最终序列为 b；对于 b 中的任意一个连续段 b[l]=b[l+1]=..=b[r]=x (l<=r)，它的代价为：sum_{i=l..r} |a[i]-x|。
注意到这是一个绝对值函数形如 sum |a[i]-x| 的求和，**达到最小值的 x 一定出现在将 a[l]..a[r] 排列后的中位数位置**。
因此，如果b中任意一个连续段的值x不是某个a[i]，一定可以将x调整到这一段原值的中位数使得需要的操作次数更小。
因此，这个调整法意味着，所有最终值一定是a中的某个值。而a中的值最多只有n个，因此可以将 O(nV) 的朴素做法优化为 O(n^2).

具体做法为，定义 f[i][j] 为将 a[0..i] 变为非递减且 a[i] 变为第 j 个数组原值的最小操作次数。有 f[i][j]=min_{k<=j}{f[i-1][k]}+|a[i]-vals[j]|；
具体实现中可以使用滚动数组优化，并额外记录一个 mn 值来更新前缀前一层最小值。

对于这个背景，还有一个额外的观察：至少存在一个 i，使得最终序列b中 b[i]=a[i]，是一个不用被操作的数。
证明：假设有最优解 b'，考虑把整体平移 t：b'[i]=b[i]+t，由于同时增加仍然合法。令 d[i]=a[i]-b[i]，平移后代价为 F(t) = sum_i |a[i]-(b[i]+t)|=sum_i |d[i]-t|.
由于 b 是最优解，t=0 时 F(0) 必然是最小值；但这是一个形如 sum_i |a[i]-x| 的绝对值函数求和，最小值出现在 x=a 的中位数；因此某个 d[i] 必须为0，即 a[i]=b[i]；

变式：同样背景，**求将序列变为严格递增的最小操作次数**
对于数组 a，将其最优的变为递增数组记为 b。对于任意 i，需要：
b[i] < b[i+1] <==> b[i] <= b[i+1]-1 <==> b[i]-i <= b[i+1]-(i+1)
定义 c[i]=b[i]-i，即对于所有 i 需要 c[i]<=c[i+1]. 代价 sum_i |a[i]-b[i]| = sum_i |a[i]-(c[i]+i)| = sum_i |(a[i]-i)-c[i]|
因此问题转化为：给定数组 a', a'[i]=a[i]-i，将 a 变为 b 使得严格递增的最小操作次数等价于将 a' 变为 c 使得非严格递增的最小操作次数。对 a' 执行上面的 DP 即可。
这样**同构**的思想在对于严格不等号转化可以等于的不等号上很有用（尤其是 **a[i] < a[i+1] <==> a[i]-i <= a[i+1]-(i+1)**）

## 子串/子序列 DP 相关

一些数组上的子串/子序列问题适合用动态规划解决（尤其是计数）。需要积累状态定义方法，通常 f[i] 代表考虑了序列前缀 a[0..i] 的信息（或右端点为 a[i] 的信息），第二维度按照题目要求设计对应状态。

对于子串 DP，考虑 dp[i-1] 转移到 dp[i]，a[i] 对其接入以 a[i-1] 结尾的子串形成的新的子串的贡献；
除此自外，可能有些子串题允许最多一次修改，这时要用前后缀分解来计算答案

对于子序列 DP，考虑前序合法下标 j，从 dp[j] 转移到 dp[i]；有时需要记录额外信息，需要定义成 dp[i][v]（子序列最后一个下标i，序列相关值v）或 dp[i][j]（子序列最后两项为 nums[i],nums[j]）
在设计状态时，一定要注意 n 和 V 的范围（是否可以 n^2 枚举前序，是否可以把值域放到状态中，etc，对解法有启发作用）
如果涉及到子序列总和，需要同时定义子序列个数和总和，这样转移的时候接入值 x 的贡献即为 x+x*cnt，cnt为前序元素的合法个数，x代表自己单个形成子数组的贡献
一般转移为 dp1[x]=dp1[y]+1, dp2[x]=dp2[y]+x*(dp1[y]+1)

1. 【2144E】定义序列 a 的 L(a) 为从左到右从小到大的单调栈数组，R(a) 为从右到左从小到大的单调栈数组。求 a 有多少子序列 a' 使得 L(a)=L(a'),R(a)=R(a')；
发现 R 即为 a 反转后的 L,思考只有 L 怎么做:先可以预处理出 L(a),记其有tot个元素.
首先定义 f[i][j] 为在前缀 a[0..i] 上计数，现在匹配到了 L 的第 j 个元素的子序列方案数；
考虑转移，若 a[i] < L[j]，那么 a[i] 在所有之前已经匹配到 L[j] 的子序列的后面选或不选，有 f[i][j] = 2*f[i-1][j]
若 a[i] = L[j]，那么 a[i] 既可以在之前以及匹配到 L[j] 的子序列后选或不选，也可以强制在匹配到 L[j-1] 的序列后接上去来匹配到 L[j]，即 f[i][j] = 2*f[i-1][j] + f[i-1][j-1]
若 a[i] > L[j]，不能选，有 f[i][j] = f[i-1][j].
观察到 i 只与上一层相关，可以滚动优化。初始化时（即还没开始滚动），匹配到 L 的前 0 个数组是基础情况，值为 1.

这个转移是 O(n^2) 的，可以过 Easyver；但对于 Hardver，数据范围来到了 1e5，思考如何优化。
观察这个转移：对于所有的 j，按照 L[j] 与 x=a[i] 的大小关系，有三个区间：
L[j] < x：nf[j] = f[j]
L[j] = x: nf[j] = f[j-1]+2f[j]
L[j] > x: nf[j] = 2f[j]
那么考虑把 f **维护在一颗线段树上**（注意下标有 1 的偏移，f[0] 代表匹配了 j 中 0 个数，f[k],k>0 代表匹配了 L[0..k-1].）
具体来说，每次将前缀扩展一个，二分出 id=lb(L,x)（注意这个 id 在树上对应的下标是 id+1）；那么在 [0,id] 上，f 是不变的；在 [id+1,tot] 上，f 整体 x2；若还有 L[id]=x，那么对于 id+1 上还要再加上之前树上 id 处的值
由于涉及到了区间乘法，用懒标记线段树维护即可。

最后考虑答案如何维护；如果单纯的对于每个 i 来前后缀统计，会重复统计，必须要钦定一个 a[i] 去重。考虑 a 中最大值为 mx，注意到一个合法的 a' 一定有存在最大值；
若 a[i]==mx，考虑**钦定 a[i] 强制选入并作为 a' 的最后一个最大值位置**；那么它的左侧选法为：f[i][tot] - f[i-1][tot]（减去前缀完整子序列中不含 a[i] 的个数）；
对应的右侧，应该计算的是：在后缀 a[i+1..n-1] 中匹配到 R 的前 tot-1 个的子序列个数（不能有最大值了），即为 f'old[tot’-1]（这里f'代表第二次reverse时做的dp,tot'代表R数组大小）。
实现时可以传入参数代表正反做的dp，然后维护 l[i] 与 r[i] 代表这两个量；
在更新 DP 之前，先更新 r[n-1-i]<-tr.query(tot-1,tot-1)，这是因为 r[i] 需要的是后缀从 i+1 开始的信息，在反做时 i 对应正着的 n-1-i.
更新 DP 结束后，对应更新 l[i]<-tr.query(tot,tot)-prv；最后答案为在所有 a[i]==mx 的位置的 l[i]*r[i] 的求和。

2.**重要**（子串DP）【LC2262】定义一个子串的值为其字符种类数（例如"ABA"为2），给定字符串 s 求所有子串值之和。长度 n<=1e5
考虑种类数的问题，联想到 HH 项链；维护 last 数组是自然的；直接对于单个字符算贡献是困难的，因此考虑进行 DP。
定义 dp[i] 为以 s[i] 为右端点的所有子串的对应值之和；那么 dp[0]=1.
考虑如何求 dp[i]：对于一个以 i 为右端点的子串 s[l..i]，它可以分为两块：[l..i-1][i]。对于这样的子串贡献求和，是在 dp[i-1] 的基础上加上 s[i] 对于所有子串的贡献总和
考虑 s[i] 什么时候有贡献：记 pos=last[s[i]]，那么对于所有包含了 pos 的子串，它的字符 s[i] 的贡献被算过了，而对于所有没有包含的子串（左端点从 pos+1 到 i），s[i] 都会对于每个子串贡献 1. 因此有：dp[i] = dp[i-1]+i-last[s[i]]
最后答案即为所有 dp[i] 之和。
```CPP
long long appealSum(string s) {
    int n = s.size();
    vector<int> last(26, -1); last[s[0] - 'a'] = 0;
    vector<long long> f(n); f[0]=1;
    for (int i = 1; i < n; ++i) {
        int x = s[i] - 'a';
        f[i] = f[i-1] + i - last[x];
        last[x] = i;
    }
    long long res=0;
    for (int i = 0; i < n; ++i) res += f[i];
    return res;
}
```
与此类似的问题【LC828】定义一个字串的值为其出现次数唯一的字符串种类数（例如“ABA”为1），给定字符串 s 求所有子串值之和。长度 n<=1e5

3. **重要**（子序列DP）【LC446】经典子序列 DP，求数组中等差子数组的总数。等差子数组定义为长度>=3且满足子数组中任意相邻两项之差相等；n<=1000,|V|<=1e9.
定义 dp[i][x] 为以 nums[i] 结尾并且公差为 x 的等差子数组个数。从左到右循环右端点 i，枚举左端点 j，当前差为 x=nums[i]-nums[j]；
那么有： dp[i][x] += 1 + dp[j][x]（除了之前每个合法子序列后面接入一个 nums[i] 仍然是等差序列，贡献 dp[j][x] 之外，还有 nums[j]-nums[i] 这一长为 2 的等差子数组。虽然不满足要求，但是可能参与后续转移，所以还是要更新进去）
并且同时更新答案：res += dp[j][x]（j-i 对产生了 1+dp[j][x] 个，但是要把最后那对长为2的减去）
实现上，第二维肯定不能开数组，考虑每个 i 最多只有 i 个可能值，因此用哈希表存储
```CPP
int numberOfArithmeticSlices(vector<int>& nums) {
    int n = nums.size(); 
    vector<unordered_map<long long, int>> dp(n);  // dp[i][x] = 最后一项arr[i]，公差为x的子序列个数
    int res = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            long long x = 1LL * nums[i] - nums[j];
            dp[i][x] += 1 + dp[j][x];
            res += dp[j][x];
        }
    }
    return res;
}
```

## 划分 DP 相关

划分 DP 的关键点在于枚举上一个分割点。在求 dp[i] 时，**枚举这一段分割是 j..i，那么代价就是 dp[j-1] 加上 j..i 这段的代价**。因此，使用 1-based 的数组会更加方便

1. **后效代价预支付【重要！！】**【P5785】
给定 n 个物品，每个物品有单独时间 t[i] 和单独代价 f[i]。若干连续物品可以组成一组任务：每个任务要花费额外 s 分钟启动，任务过程中的花费是 T*所有任务中f的和，其中 T 为这组任务的完成时间（等于上一组任务的完成时间加上这组的启动时间加上任务中所有t的和）

下文中定义 F 为 f 的前缀和，T 为 t 的前缀和数组。使用 1-based 的任务编号与 dp。
由于每组任务连续，因此是一个划分dp。定义 dp[i] 为完成任务 1..i 的最小代价，那么枚举这段的起点 j (1<=j<=i)，有：
dp[i] = min_{1<=j<=i} {dp[j-1] + (F[i]-F[j-1])*(time_prv+s+T[i]-T[j-1])}.
考虑化简关于时间的表达式：可以发现，这组任务完成的时间是 t[1]+..+t[i]=T[i] 的总时间加上 cnt*s，其中 cnt 是分段的总数量(包含j..i这段)。
然而，这样一维的DP并不能知道之前的分段个数，换句话说，引入了后效性。

为了消除后效性，要使用**后效代价预支付**的trick：换个角度，将这个 s 看作：对于当前排队还没被做到的任务所需支付的罚款。每次重启，都会导致当前段以及后面所有元素的时间计算中多出一个 s；这就类似一个惩罚项。那么对于这个“罚款”，在计算 dp[i] 中提前考虑，让程序选择是否即使支付等待罚款还是会更优。
将这样的**惩罚项所带来的后效罚款在做决策时提前支付**，就能消除后效性。
**（请回想并复习第一节记忆化搜索中的关路灯/套牛问题！）**：在区间扩张时（从 dfs(l+1,r) 或 dfs(l,r-1) 到 dfs(l,r)，经过的 deltaT 的时间累加的贡献是所有剩余牛所需要支付的，和本题几乎一样（区间扩张的 deltaT 会造成所有剩下元素都要支付一份惩罚）；本质就是这个后效代价预支付问题，即交换了贡献的统计顺序）

因此，DP 可以改写为：dp[i] = min_{1<=j<=i} {dp[j-1] + T[i]*(F[i]-F[j-1]) + s * (F[n]-F[j-1])}
其中当前任务在时间 T[i] 结束，所有的任务 f 和为 F[i]-F[j-1]，是基本的代价
而j之前所有分段带来的对于当前段的罚款已经提前交过（dp[j-1]），不用考虑。对于当前段以及之后所有元素排队的罚款，等待的时间是 s，元素和为 F[n]-F[j-1]，对应最后一项

此外，注意到可以写成 `dp[i]=min{(-F[j-1])*T[i]+(dp[j-1]-s*F[j-1])}+T[i]*F[i]+s*F[n]` 的形式，是直线取 min，可以用 CHT 做到 nlogn 的复杂度。

【总结】：什么时候想到这种 trick？
1. 当前决策会让一批尚未处理的对象受到**统一影响**。例如：所有剩余任务都延迟 delta/所有未关闭的灯都多耗电 delta 时间/所有尚未收集的物品都损失 delta 时间的价值
2. 这个影响是**可加**的。假设对象 x 的权重是 w[x]，统一增加 delta 后，总费用增加：delta * sum(w[x])
3. **受影响对象的集合现在就能确定，而且未来决策不会改变这次影响**。例如 P2365 中一旦新开一批，从 j 开始的所有任务必然都要经过这次 S，后面怎么分批都不会改变这一事实。

练习：【1903C】划分数组，代价为：sum_{i=1..k} i*sum[i]，其中 i 是被划分的段的标号，sum[i] 是第i段的和。
感性理解，就是每段元素和乘以算上自己及之前一共被划分了多少段。可以发现，每次多划分一段，就会把自己这段以及后面所有元素的和都给加一遍。因此可以使用后效代价预支付的trick：
定义 dp[i]=对a[1..i]划分得到的最大代价。枚举 1<=j<=i 作为这一段开头，有 dp[i]=max{dp[j]+sum[j..n]}，化简为 pre[n]+max{dp[j]-pre[j]}，维护一个前缀最大值mx即可


## 数位 DP 相关

一些关键观察：
涉及到数位和，**数位和的可能性很少，可以固定枚举**（只有 lgV * 9 种，最多在 500 左右）或直接加入状态维度
涉及到数位积，**数位积结果的素因子很少**，只有 2,3,5,7，因此可以只记录 v2(n),v3(n),v5(n),v7(n) 或者一些余数，例如 mod9,mod8,mod7（用这三个量加上末尾是否为5 可以检验出所有整除数位积的个位数）；并且如果数位中有 0，积一定是 0

1. 给定 k，求 [lo,hi] 间有多少数的数位乘积为 k 的倍数；k,lo,hi<=1e18。
由于 k 也很大，不能直接存储数位积modk 的余数。关键观察：**k 有 >9 的素因子时，只有数位中有 0 时才可能满足**，否则只需要比较 2,3,5,7 的幂次
因此做法是：首先在路径上记录 2,3,5,7 的幂次，以及是否有数位 0。如果有数位0或者k是1，直接满足
否则没有数位0，因此对于所有 k 的素因子，如果不是2,3,5,7，那不符合，否则检查它们需要的幂次是否 <=路径上统计的幂次。
然而这个做法会在几个点上 TLE。一个优化的方法是，对于2357的幂次，用k的对应**幂次值做上限截断**。这是因为如果幂次已经达到需求，具体值是多少对于答案没有影响，因此可以把这些状态都给合并从而减少状态数

2. 求 [lo,hi] 之间有多少数的数位之和整除数位之积。
由于数位和的可能范围很小，**固定数位和，判断数位之积是否是和的倍数**：状态需要记录 cur_sum, cur_prod % targ_sum，最后判断余数为 0 且 cur_sum=targ_sum。
和的范围是 1 到 lgV * 9，约 150，状态需要两维 150。复杂度能够通过。

然而对于【P16872】有多测，还要加上额外的优化：注意到这个 DP 的记忆化可以全局复用，因此把 memo 做成 global 的，并且加上一个维度 targ_sum，用空间换时间防止每次枚举不同的和要重新清空备份数组。注意做成全局后，n 在不同测试数据后不一定一样，但是记忆化可以保证后缀长一样时复用状态，因此 memo 的第一维要从 i 改成 n-i。
还有个优化是：要判断倍数，不一定要记录mod数，可以记录 gcd(cur_prod, targ_sum)；那么 cur_prod 是 targ_sum 倍数当且仅当这个 gcd 是 targ_sum。由于 gcd 只会是 targ_sum 的因数，因此这个维度就从 targ_sum 的大小降低为因子个数大小了。更新状态时可以直接 gcd(cur_prod * d, targ_sum)


## 树形 DP 相关

1. 【P2700】复杂的状态转移**至少一个形**
给定 k 个点，求删边使得这 k 个点两两不连通的最小代价。
思考一个朴素的 dp[u] 代表 u 子树中删边使得不连通的最小代价，但这不全面：如果 tag[u] 但是子树中我即使删了不连通但可能顶上一个集合还是有敌军，这时候无法判断
因此定义：
dp[u][0]=以u为根子树都隔开，且u所在连通块没有敌军的最小代价；dp[u][1]=以u为根子树都隔开，且u所在连通块有一个敌军的最小代价
思考转移：
如果 tag[u]=1，那么 dp[u][0]=LINF 不可达，dp[u][1]=sum min(dp[v][0], dp[v][1]+w)：要么没有，要么有但是删这个边
否则，tag[u]=0. dp[u][0]=sum min(dp[v][0], dp[v][1]+w) 是相同的逻辑；
思考 dp[u][1]：要强制至少一个部分的 dp[v][1] 进入；首先考虑如果全部隔断，代价是 sum = sum min(dp[v][0], dp[v][1]+w)；
再选一个子树把他的 dp[v][1] 加进来，那么在这个sum上的变化量即为 dp[v][1]-min(dp[v][0],dp[v][1]+w)，因此还需要维护 mn = min(dp[v][1]-min(dp[v][0],dp[v][1]+w))
最后，dp[u][1] = sum + mn.
**一般的，如果求一个性质是：至少一个子树满足；那么求两个值：sm = sum min(dp[v][满足],dp[v][不满足])，mn = min{dp[v][满足] - min(dp[v][满足],dp[v][不满足])}，即有 dp[u][至少一个v满足] = sm + mn；即为：把没有限制的最小值都加上，然后强制选一个满足的，再把原来的贡献扣掉之中最小的代价**（注意和恰好一个的区别：恰好一个先累加所有不满足的，然后找到最小的满足-不满足的值作为delta）
```CPP
vector dp(n, vll(2));
auto dfs = [&](this auto&& dfs, int u, int fa) -> void {
    if (tag[u]) dp[u][0] = LINF;
    ll sum = 0, mn = LINF;
    for (auto& [v, w] : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        if (!tag[u]) {
            dp[u][0] += min(dp[v][0], dp[v][1] + w);
            sum += min(dp[v][0], dp[v][1] + w);
            mn = min(mn, dp[v][1] - min(dp[v][0], dp[v][1] + w));
        } else {
            dp[u][1] += min(dp[v][0], dp[v][1] + w);
        }
    }
    if (!tag[u]) dp[u][1] = sum + mn;
}; dfs(0, -1);
cout << min(dp[0][0], dp[0][1]) << endl;
```

类似的转移设计还有**树上最小支配集**问题：
求最少选中多少个点使得每个点要么自己被选中，要么有邻点被选中。
思考树上 dp，显然的两个状态是：
dp[u][0] = u 子树被支配，但 u 没有被选中
dp[u][1] = u 子树被支配，但 u 被选中
在转移时发现，这样的定义会漏掉一种情况：u 的孩子 v 没有被选中，且没有被它的任何儿子支配，而是等到 u 选中了以后才合法。因此补充定义一个状态：
dp[u][2] = u 子树中除了 u 被支配，u 没选中且等父亲支配

思考状态转移：
显然有的是 dp[u][1] = 1 + sum min(dp[v][0],dp[v][1],dp[v][2])，dp[u][2] = sum dp[v][0]
对于 dp[u][0]，需要**至少一个儿子被选中**，那么根据至少型的转移技巧，有 dp[u][0] = sum min(dp[v][0],dp[v][1]) + min{dp[v][1] - min(dp[v][0],dp[v][1])}

2. 根据性质分析值域：【P4395】给定一棵树，给节点赋正整数权值，求最小总权值
考虑只用 1.2 赋值是错的（u-v是中心，各连三个叶子；应该使用 2.3 赋值中心，叶子都给1）。
直观上来看，虽然只用 1.2 是错的，但是直觉上这个最大值肯定不大（甚至可以直接猜到是 log 量级的），因此可以做 dp：
定义 dp[u][x] 为 u 节点子树，u 赋值为 x，子树最小值。那么转移为：
dp[u][x] = sum_v min_{y!=x} (dp[v][y])，复杂度 O(nlog^2n)
这里不需要考虑调整到最优，因为**最优解肯定会被枚举到，转移时可以暴力计算**（这也是个很重要的思想！）。

对于 logn 值域的严格证明：
假设最优解中，一个点的值为 k。那么他的邻居一定有 1~k-1 中的所有值；否则，哪里没有补哪里即可。定义一个点想要取到值 k，至少需要 S(k) 个点。
那么将 k 点删除，1~k-1 一定互不连通（因为是树）。因此，S(k)>=1+S(1)+S(2)+..+S(k-1), S(1)=1。故 S(k)>=2^{k-1}
因此一颗 n 个点的树出现了值 k，有 n>=2^{k-1} ==> k<=floor(log2(n))+1 ~ O(logn)

3. DP 与答案分开统计【P3174】给定一棵树，求最大毛毛虫大小
启发：许多题目中，**DP 状态是作为一种“中间状态”的，而统计答案时往往要使用 DP 值并结合其他统计量**。
对于这道题，自然可以定义 dp[u] 为 u 作为开头的毛毛虫最大大小，因此有：
dp[u] = max(dp[v]) + cnt-1 + 1 = max(dp[v]) + cnt，其中 cnt 为 u 的子节点个数
然而，毛毛虫还可能是趴在u上的，因此还需要记录一个长度第二长的链：mx = max(dp[v]), se = second max(dp[v])
那么若 se=0（没有更新过），不管，否则可以加上 se-1（这里-1是要把在cnt中的贡献减去）
另外的，考虑u如果有父节点，那么这条边可以作为一个毛加入进去。
因此 dp[u] <- mx + cnt, res <- mx + cnt + max(0,se-1) + (father[u]!=-1)

另一个例子是给定树，点权为正，边权为负，求最长链长。由于点权是正的，因此只需要考虑链两端都是端点的链。对于长为1的链，即为点权的最大值。
否则对于长度至少为2的链，考虑树形dp：由于关键性质，任意路径可以在两端点的LCA处进行统计。考虑在u时统计所有挂在u上的链。
为了避免复杂的最大/次大的讨论，采用逐步合并式的DP（类似卷积的处理）
在递归子儿子的同时维护一个量 mx = 已经考虑过子树的 dp[v] 加上 v-u 边权 w 的最大值。初始化 mx=0，这样可以考虑其中一个链不伸出去，端点就在u的情况。
递归v后，v伸下去的最大值为 dp[v]（注意dp[v]至少也是a[v]）那么更新答案 res<-dp[v]+w+a[u]+mx，以及 mx<-dp[v]+w.
最后，dp[u]=a[u]+mx. 由于mx一开始被设为0了，所以就算所有链贡献都是负数，这里也可以正确得到 dp[u]=a[u].
（或者，这部分也可以写成：dp[u]=a[u]初始化，对于每个儿子做更新 res<-dp[u]+w+dp[v], dp[u]<-a[u]+w+dp[v]；注意还是答案与dp分别更新来避免维护最大次大，以及**链转化到LCA的思路，以及对应这种情况下树形dp的逐渐合并式转移**）

4. 给定树，节点 i 的值是 i；求所有满足如下条件的集合的所有集合中元素值之和的总和：任意两个集合中元素，不存在互相的祖先/后代关系【P5007】；
**自底向上+自顶向下 DP**
可以发现，用贡献法，即为计数选择节点 u 会出现在多少个符合要求的集合中。感性的理解，把 u 选择后，u 子树都无所谓了，但 u 子树外面都是无所谓的，这就牵扯到一个子问题：固定根子树的方案数
首先定义 dp[u] = 在子树u中，可以选出多少个可能集合。要么选择 u，一种，子树不能选择；要么不选择 u，子树每个独立，因此：dp[u] = 1 + prod dp[v]；这部分做一次自底向上 DP 计算。
现在考虑如何计算 f[v] = 固定选择v，可以出现在多少个集合中。记 v 的父亲为 u。
由于 v 选择了，这颗子树确定，但是它的同层兄弟可以不受限制，同层兄弟的可能方法就是 (dp[u]-1)/dp[v] = dp[v2]*dp[v3]...。
此外，u 子树之外也都不受限制，这部分的方案数是 f[u]. 因此：f[v] = f[u] * (dp[u]-1) * inv(dp[v])，这部分做第二次自顶向下 DP 计算。

### 状态卷积

1. 【P2634】**先统计答案，再更新状态**
求树上有序点对 (a,b) 数量，其中 a 到 b 简单路径上权值和是 3 的倍数（允许 a=b，此时权值和为 0）
这题可以直接用跨子树的DSUonTree来做，但是考虑一个更简单的做法--树上状态卷积dp。
定义 dp[u][x] 为以 u 为根的，路径权值和为 x 的链的个数。初始化有 dp[u][0]=1（u-u这条链）；
那么在做子树卷积时，考虑 dp[v][x]，u-w 权值为 w，新链权重 (x+w)%3，和已经有的状态卷积，需要的目标权值和为 (3-nw)%3，对答案贡献 dp[v][x]*dp[u][targ_w] * 2（有序对要x2）
要注意**一边统计答案一边更新状态时，要先统计答案再更新状态**：x=0,1,2全部统计好后，再开一个循环做 dp[u][nw] += dp[v][x] 来合并状态

2. 经典问题【P3698】给定有根树和 S，求**从根开始走 S 步，可以经过的最多不同节点数**。边和点可以重复经过，但不重复计数。
识别到额外状态，想到定义类似 dp[u][i]=从u开始走i步最多到达点数的状态。这显然应该使用卷积来合并。然而，在转移途中，由于要走到子树 v，但不知道一开始在 u 时的状态，所以增加一个维度记录这个信息：
dp[u][i][0]=子树u中，从u开始走i步的最大经过点数
dp[u][i][1]=子树u中，从u开始走i步且回到了u的最大经过点数
考虑状态卷积来合并一个子树 dp[v] 的信息，有三种情况（注意第三种容易漏掉）：
- u 走了 i 步回到 u，再走到 v 中（额外u-v有一步），走了 j 步，不强制折返：ndp[u][i+j+1][0] <-max-- dp[u][i][1] + dp[v][j][0]
- u 走了 i 步回到 u，再走到 v 中，走了 j 步，且回到 v（u-v贡献两次）：   ndp[u][i+j+2][1] <-max-- dp[u][i][1] + dp[v][j][1]
- u 走到 v 子树走了 j 步且回到 v，再到之前的子树中走了 i 步但不强制折返:  ndp[u][i+j+2][0] <-max-- dp[u][i][0] + dp[v][j][1]
```CPP
vector dp(n, vector(S + 1, vi(2, -INF)));
auto dfs = [&](this auto&& dfs, int u, int fa) -> void {
    dp[u][0][0] = dp[u][0][1] = 1;
    for (auto& v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        auto ndp = dp[u];
        for (int i = 0; i <= S; ++i) {
            for (int j = 0; j <= S; ++j) {
                if (i + j + 1 <= S) ndp[i + j + 1][0] = max(ndp[i + j + 1][0], dp[u][i][1] + dp[v][j][0]);
                if (i + j + 2 <= S) {
                    ndp[i + j + 2][1] = max(ndp[i + j + 2][1], dp[u][i][1] + dp[v][j][1]);
                    ndp[i + j + 2][0] = max(ndp[i + j + 2][0], dp[u][i][0] + dp[v][j][1]);
                }
            }
        }
        dp[u] = ndp;
    }
}; dfs(0, -1);
int res = 0;
for (int x = 0; x <= S; ++x) res = max(res, dp[0][x][0]);
cout << res << endl;
```
注意答案要统计所有的 dp[root][s][0], s<=S，由于可以在某些边多走一次（原dp只考虑了有效步数）

3. 【P12136】**树上背包的位运算优化**：
对于复杂度 O(nW^2) 的树上01背包，用bitset可以将复杂度优化为 O(nW^2/w)，省去大常数，使得n=W=1000的题可过。
题意：每个点有点权 w；叶子节点代表它可以产生 w[u] 重量，而非叶子节点代表可以接受最多 w[u] 容量的儿子产生的总和。问通过删除一些点使得每个点都能在自己范围内接受所有儿子重量和，根节点接受的最大值。
显然是树上背包问题，一个子树上可以接受此子树叶子所能有的所有组合（但要对自己的w做截断），合并子树的过程是个01背包；
定义 f[u]:bitset = u子树中的可达重量集合
按照树上卷积式合并，这里由于是01背包，每次合并前要开一个 nf=f（注意这里是可以继承f的状态，代表子树v什么都不选）
转移时，对于所有 f[v] 上为1的位i，做 nf|=f[u] << i. 合并好所有儿子后，对于超过 w[u] 的做截断。
```CPP
vector<bitset<MX>> f(n);  // f[u]=节点u能凑出的重量值
auto dfs = [&](this auto&& dfs, int u, int fa) -> void {
    f[u][0] = 1;
    if (g[u].size() == 1 && u) {
        f[u][w[u]] = 1;
        return;
    }
    for (auto& v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        auto nf = f[u];
        for (int i = 1; i < MX; ++i) {
            if (f[v][i] == 1) nf |= f[u] << i;
        }
        f[u] = nf;
    }
    for (int i = w[u] + 1; i < MX; ++i) f[u][i] = 0;
}; dfs(0, -1);
for (int i = MX - 1; ~i; --i) {
    if (f[0][i] == 1) {
        cout << i << endl;
        return;
    }
}
```


### 换根 DP

1. 【P11378】对于一类统计类似一个点按**性质开始扩散，可以扩散最多的点/最大权值和**，想换根 DP。
这样的题目无法通过普通树形 DP 的原因是树形dp只能统计这个点和子树的信息，而还需要父亲那一侧的信息时，就需要换根来处理。
例如这道题目求从任一个点开始，可以扩散的最大点数，扩散的条件是点权比自己小。
那么一次 dp 求出 dp[u]=u子树中可以扩散的最大点数，再用换根处理父亲那侧可以增加的点数.

换根 DP 复习：**在 reroot 之前，先求出 tmp=res[u]扣掉v子树的贡献，再计算 res[v]=dp[v]加上tmp的贡献；对于v子树的贡献，是和第一次 dfs 中的过程一模一样的过程，只不过把加号换成了减号。对于tmp的贡献，也要同时考虑是否满足添加这个子树的性质条件**。
```CPP
vi dp(n);  // dp[u]=在u子树中扩散的最多节点数
auto dfs = [&](this auto&& dfs, int u, int fa) -> void {
    dp[u] = 1;
    for (auto& v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        if (a[v] < a[u]) dp[u] += dp[v];
    }
}; dfs(0, -1);
vi res(n); res[0] = dp[0];  // res[i]=从i开始扩散的最多节点数
auto reroot = [&](this auto&& reroot, int u, int fa) -> void {
    for (auto& v : g[u]) {
        if (v == fa) continue;
        int tmp = res[u];
        if (a[v] < a[u]) tmp -= dp[v];  // 和 dfs 过程中完全相同（包括判断）
        res[v] = dp[v];
        if (a[u] < a[v]) res[v] += tmp;  // 注意父亲那侧什么时候能扩散到
        reroot(v, u);
    }
}; reroot(0, -1);
cout << ranges::max(res) << endl;
```

2. 【P6419】融合了恰好一次的 sum+mn 技巧，以及前后缀分解换根 DP；代码较长（见洛谷）但思路明朗
主要在于处理（dp以及up两边的）所有相邻子树上的求和：走到所有关键点再回来: sum val[i][1]+2w
由于可以停在最后一个点，那么就是恰好选一块使得不用走回来了，那么求所有的 min val[i][0]-w-val[i][1]（之前走了个 2w+val[i][1]，新的允许走 w+val[i][0]，因此要最小的 delta，即为最小的 val[i][0]-w-val[i][1]）
但注意这个 mn 的基本元是 LINF，要求的是 sum + max(0,mn)，由于不存在走一半停的情况下（没法变小了），那么就保持原状即可

3. 求**树上 DFN 序个数**（任意起点）【启发：换根时慎用第一次dfs对u的统计信息；v的可以用】：
首先假设根为 0，定义 dp[u]=子树u中不同dfn序个数。第一个一定选u，对于儿子，每个儿子内部有 dp[v] 个方案，有 cnt[u] 个儿子，定顺序有 (cnt[u])! 种
因此：dp[u] = cnt[u]! * prod(dp[v])
现在换根：从 u 换到 v，先求 tmp=res[u]w/odp[v]，再求res[v]=dp[v]w/tmp:
在计算 res[u] 时，v 中内部贡献了 dp[v]，而顺序从 g[u].size()! 变成了 (g[u].size()-1)!，因此减去了 g[u].size() 倍（注意这里不能用cnt[u]!!）. 下简写 g[u]=g[u].size()
因此 tmp = res[u] / (dp[v] * g[u])；
再考虑 res[v]，u 带来的内部顺序有 tmp 种，定顺序从 (gv-1)! 变成了 (gv)!，因此 res[v] = dp[v] * tmp * g[v] = g[v]/g[u] * res[u]
因此有：res[v] = g[v]/g[u] * res[u]
对于不同根的 DFN 序总数，为 sum_i res[i] = sum_i g[i]/g[0]*res[0] = res[0]/g[0] * sum_i g[i] = res[0]/g[0] * sum_v deg(v) = res[0]/g[0] * 2(n-1)
注意细节上：首先特判n=1时为1；其次为了避免逆元，在计算res[0]时阶乘不要乘最后一项即可。


## 博弈 DP 相关

1. 经典题：LC 石子游戏系列；博弈 DP 用**记忆化搜索**的写法最方便；定义 `dfs(l)` 为现在能操作的最左边是第 l 堆（或者再加一个表示状态的参数）。
枚举先手可以做的所有操作，加上代价后把剩下局面丢给后手，先手有必胜策略当且仅当存在一个情况下交给后手的局面，后手必败。
如果是代价类型，可以写：`res=max(res, sum(l,n-1)-dfs(l'))`：当前假设拿了一些代价，给后手的局面是从l'开始的。那么后手能拿的最多代价是dfs(l')，因此先手一共能拿的就是总代价减去这部分。
如果是判断输赢，可以写：`res|=(!(dfs(l')))`：如果后手局面dfs(l')存在一个必败，那么先手必胜
做题时观察数据范围，如果是 O(n) 的，先手可能只有常数个操作可能；如果允许 n^2，就增加一个额外状态，或者区间信息可以直接得出。如果允许 n^3，想区间dp的形式

在分析局面时，要注意先手后手**都用最佳策略**，因此先手想要最大化收益，用的是枚举所有可能的第一步情况，之后局面**后手也是最优操作**后剩下的价值。
最大化分数时：A最大化得分SA，B最小化SA=tot-SB<=>最大化得分SB；dfsmax(A)=max{gain(A)+rem-dfsmax(B)}
最大化分数差时：A最大化分数差SA-SB，B最小化SA-SB<=>最大化分差SB-SA；dfsmax(A-B)=max{gain(A)-dfsmax(B-A)}

例如：先手可以在左或右一端拿石子，收益是拿掉后剩下的价值总和。游戏继续在剩下的石子中进行，求最大分数差
定义 dfs(l,r) 为在 [l,r] 操作，先手能拿到的最多收益。先手一开始只有两个选择，拿左或拿右，收益是 sum(l+1,r) 或 sum(l,r-1).
考虑后手拿到的局面，这时为了最小化A-B的分数差，B必须要最大化B-A的分数差，因此还是同样的 dfs 局面，最后 A 取 max(sum-dfs) 即可
（SA' = sum-(SB-SA), A 要最大化这个式子，但 B 最优操作是同时最大化 SB-SA）
```CPP
vector memo(n, vi(n, -INF));
// dfs(l,r)=在区间[l,r]中先手-后手分数最大分差
auto dfs = [&](this auto&& dfs, int l, int r) -> int {
    if (l == r) return 0;
    if (memo[l][r] != -INF) return memo[l][r];
    auto& res = memo[l][r];
    res = max(sum(l + 1, r) - dfs(l + 1, r), sum(l, r - 1) - dfs(l, r - 1));
    return res;
};
return dfs(0, n - 1);
```

## 优化相关

### 数学优化

1. 【1696e】有些特殊的二维DP可以考虑到**网格图路径计数**
二维递推 f(i,j)=1+f(i+1,j)+f(i,j+1), 给定一些边界值，求 f(0,0)，直接按照递推的算法要 O(n^2) 的时间
但是换个角度来说，把题目放到二维网格中，假设任一点只能通过向左或向上移动， 那么 f(i,j) 在计算的就是网格中任一点作为起点到达 (i,j) 的路径总数，那么 f(0,0) = sum_{i,j} C(i+j,i) = sum_{i=0,..,max_row} sum_{j=0,..,max_col[i]} C(i+j,i) 然后用 Hockystick，= sum_{i=0,..,max_row} C(i+max_col[i]+1,i+1)，可以把时间直接变成 O(n)

2. 给定转移：f[i] = min_{j|i} {f[j]+i/j}，求 f[n]；
注意i的因子j可以有配对j<->i/j，可以写 f[i] = min_{j|i} {f[i/j]+j}；考虑这个 f 的生成过程，假设 i 可以分解为 i=a1a2..ak，那么这个过程求出的 f[i]=a1+a2+..+ak
由于积一定，和需要最小化，当然是把每个数能分解就分解掉；因此 f[n] 即为 n 的所有素数因子（考虑重数）之和。


### 矩阵快速幂优化

两个关键信号：
- 只需要第 n 项，但 **n 非常大** (1e9,1e18..) 等线性无法求出的时间
- 转移是线性的。尝试将**递推写成矩阵形式**（一维递推直接套线性递推板子，二维递推尝试把一个维度的信息压缩为向量）

1. 【CF1970】定义 f[i][j] 为第 i 天后在第 j 个城市的方案数，那么枚举前序城市，有 `f[i][j] = sum_k f[i-1][k]*((s[j]+l[j])*(s[k]+l[k])-l[j]*l[k])`
需要求所有 f[n][j] 的和。范围 n<=1e9,m<=1e5，显然前缀和优化也只能到 O(nm)；注意识别，这里要求极远项，且转移是线性的，考虑使用矩阵快速幂优化。
由于第一维度是需要快速幂乘的，不能压缩，考虑将第二维度所有信息压缩为一个向量，可以写出：
`[f[i][0],f[i][1],..,f[i][m-1]]^T = [[s[0](s[0]+l[0])+l[0]s[0],..,s[0](s[m-1]+l[m-1])+l[0]s[m-1]],..,[s[m-1](s[0]+l[0])+l[m-1]s[0],..,s[m-1](s[m-1]+l[m-1]+l[m-1]s[m-1])]] * [f[i-1][0],f[i-1][1],..,f[i-1][m-1]]`
将第 i 个维度的压缩信息向量记为 V[i]，中间的矩阵记为 M，有 V[i] = M * V[i-1]，初值 V[0]=[1,0,0..,0], 那么 V[n] = M^n V[0]，快速幂计算即可，复杂度 m^3logn；
到这里可以过medium，但hard的m<=1e5，还需要继续优化。
对于矩阵快速幂的优化，考虑对于大矩阵做**低秩分解**：
对于 M，观察到可以写为：`M=[[s[0],l[0]],..,[s[m-1],l[m-1]]] * [[s[0]+l[0],..,s[m-1]+l[m-1]],[s[0],..,s[m-1]]]=A*B`
因此：M = (AB)^n = A * (BA)^{n-1} * B；而 B*A 是 2xm 与 mx2 矩阵相乘，是 2x2 的，将 m^3 的复杂度降低为常数。最后复杂度 O(m + logn)，其中 m 是计算几次普通矩阵乘法（矩阵内元素总数不超过 2m），logn 来自 2x2 矩阵的 n 次快速幂。

### min-plus 矩阵优化

min-plus 矩阵优化最典型的应用为恰好经过 k 条边的最短路。一般的，当发现 DP 中一个维度的值域太大，要么是状态设计不对（此时应尝试状态-值互换），要么就是需要使用倍增/(+,*)/(min,+)矩阵快速幂/合并查询来优化

1. 【ABC456F】给定 n 个位置，每个位置有代价 a[i]。每次可以选择一个位置变为被选择，如果 i-1 与 i+1 都被选择，那么 i 可以免费被选择。现在要求选择若干位置，使得有连续 k 个位置全被选择了。
首先考虑一段 [l,r] 最后被选上，其中 r-l+1>=k. 假设 r-l+1>=k+2，那么如果 l+2 没有选择，删去 l，否则删除 l 与 l+1；这样操作后，还是满足要求且代价更小。因此只需要考虑长为 k 或长为 k+1 作为最终连续段即可。
由于前缀0和尾缀0不应该被考虑，因此 l 和 r 一定在一开始都被选上，然后中间选了一些位置（使得位置差不>=2）。这类似打家劫舍，可以做二状态 DP：
定义 dp0 为当前位置不选的最小代价，dp1 为当前位置选择的最小代价，那么 ndp0=dp1, ndp1=min(dp0,dp1)+a[i].
初始状态在 l 时 dp0=inf, dp1=a[l]；要求最终状态在 r 时转移结束的 dp1. 直接转移枚举左端点做 DP 是 O(nk) 的，会超时。考虑这组 dp 转移可以写为 min-plus 矩阵乘：
col(ndp0,ndp1) = [[inf,0],[a[i],a[i]]] * col(dp0,dp1)
因此最终 r 处的 col(dpr0,dpr1) = [[inf,0],[a[r],a[r]]] * [[inf,0],[a[r-1],a[r-1]]] * ... * [[inf,0],[a[l+1],a[l+1]]] * col(dpl0,dpl1)
这里需要多次询问 l+1 到 r 对应的矩阵的连乘，是符合结合律的，可以使用线段树维护。注意这里是从右乘到左，因此 pushup(u) 时是右半边mul左半边。
最终复杂度 O(nlogk).


## 其他（观察类）

1. 给定数组 a 与 b。要求修改 a 使得对于任何 i，a[i]!=a[i-1]；对于 a[i]，可以将他增加或减少。增加1或减少1的代价均为 b[i]。求将 a 修改为符合要求的最小代价。

观察到，a[i] 只受到 a[i-1] 与 a[i+1] 的影响，因此最多有两个值被禁用。因此，a[i] 在最优情况下要么不变，要么-1，要么+1。
因此可以定义 dp[i][0] 为将 [0..i] 修改，且 a[i] 不变的最小代价，同理 dp[i][1],dp[i][2] 是 +1/-1 的最小代价。状态机转移即可。

如果限制操作只能是增加呢？同理，最多只有两个位置会被禁用，因此每个 a[i] 要么不变，要么 +1，要么 +2，一定能够覆盖最优情况。状态机转移即可。
