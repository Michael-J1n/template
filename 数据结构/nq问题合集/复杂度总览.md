记值域不同值个数为 V，块长为 B，查询区间长度为 len。

## 可离线额外模板

1. `单点修改-区间mex-可离线`：带修莫队，明显优于在线逐 mex 检查。
2. `静态-区间逆序对-可离线`：静态逆序对本身推荐莫队离线处理。
3. `单点修改-区间众数`：使用带修莫队，属于离线模板。

## 取舍

1. 单点修改 + 众数使用带修莫队；如果题目强制在线，exact range mode 通常没有像 sum/max 那样干净的通用 polylog 模板。
2. 动态 kth 如果能提前读完所有操作，可以用整体二分等离线做法优化；当前 `PointRangeOrder` 保留在线接口。
3. 区间赋值/区间加 + mex/逆序对没有短小统一的懒标记最优模板；当前分块版本优先保证正确、稳定、方便改题。
4. 极限题建议根据具体限制手调 B，尤其是 `RangeAddMaxSubarray` 和分块 order-statistics 类模板。

## 卡常策略

1. 不使用 PBDS，单点 order-statistics 默认手写 Treap。
2. 不使用 ODT 作为推荐实现，区间赋值复杂查询默认确定性分块。
3. 所有 `unordered_map<long long,...>` 使用 splitmix64 hash。
4. 热路径中清掉 `std::function` 和运行期 `pow`。
5. 分块 mex 使用时间戳数组复用，避免每次查询分配临时数组。
6. 莫队块长按询问规模调参，静态莫队使用 `n/sqrt(q)`，带修莫队使用整数 `n^(2/3)`。
