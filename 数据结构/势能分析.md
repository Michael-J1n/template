## 常见的势能操作

设 `A` 为元素最大值，`B = ceil(log2(A + 1))` 为二进制位数。

| 操作 | 有效变化次数（单个元素） | 稳定状态 / 性质 |
|---|---|---|
| `x = floor(sqrt(x))` | `O(log log A)` | 最终为 `0/1` |
| `x %= k` | `O(log A)` | 每次有效取模至少减半 |
| `x /= k`，`k >= 2` | `O(log A)` | 最终为 `0` |
| `x = digitSum(x)` | `O(log* A)` | 最终为一位数 |
| `x = divisorCount(x)` | `O(log log A)` | 最终为 `1/2` |
| `x = popcount(x)` | `O(log* A)` | 最终为 `0/1` |
| `x = phi(x)` | `O(log A)` | 最终为 `1`（正整数） |
| `x &= k` | `O(B)` | 每一位最多从 `1` 变 `0` 一次 |
| `x \|= k` | `O(B)` | 每一位最多从 `0` 变 `1` 一次 |
| `x = gcd(x, k)` | `O(log A)` | 每次有效变化至少减半 |

## 势能复杂度分析

假设单个元素的势能为 `K`，共有 `Q` 次区间操作，`s` 次单点赋值，那么最终复杂度为 `O((Q + (n+s)K) log n)`.
