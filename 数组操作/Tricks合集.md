## LIS 建模相关

1. **【重要！！！】LIS / Dilworth定理相关**
**LIS：可以 nlogn 的贪心求出**：
```CPP
vi g;
for (auto& x : h) {
    auto it = ranges::lower_bound(g, x);
    if (it == g.end()) g.eb(x);
    else *it = x;
}
cout << g.size() << endl;
```

Dilworth 定理告诉我们，**最小链覆盖等于最长反链长度**。有关反链，即为链上元素两两不可比。
例如，考虑二维数组 (a,b)，定义链为 a1>=a2,b1>=b2 <=> (a1,b1)在(a2,b2)之前；那么反链即为不可比的两个元素：不能同时两个维度都更小或更大（需要一个更大，一个更小）。
对于导弹拦截这道经典题，不降子序列的反链最小覆盖，只需要直接求出 LIS 长度即为答案。

一个稍难的例子是【P1233】给定一批材料（可以进行任意排序），(l,w) 两个维度，加工第一个需要消耗1，此后如果加工一个 (l',w') 且 l'<=l 且 w'<=w，那么可以连续加工。否则必须要新开一个，求最小消耗。
注意到这是一个**二维偏序关系**，且 a>=b 当且仅当 la>=lb,wa>=wb。需要求出一个满足这样偏序的最小链覆盖，即为答案。
根据 Dilworth，只需要找到这个偏序关系的反链的最长长度即可。但是这个反链不好刻画（这种情况下的**不可比较不具有传递性**），并且不同的排序顺序还可能导致不同结果。所以考虑以下做法：
**固定一个维度，考虑另一个维度（对于二维偏序的题，都要有这个意识）**：对于 (l,w) 按照 l 从大到小，平局时按照 w 从大到小的顺序来排序。这个排序也有贪心的思想在，按这个顺序一次尽量处理最多；一定比不是这样的排序更优（直觉上考虑也是需要从大到小处理）
那么对于一个链，第一维度的限制一定满足不再考虑，第二维度只需要满足 wi>=wj 即可。因此，就转化成了，需要最少不升链覆盖第二维度，因此答案即为第二维度上的 LIS。
