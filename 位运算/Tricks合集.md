1. 给定数组 a，求（可重复的）ai^aj^ak 的不同值个数；n<=1500,v<=1500
注意到值域小，最大可能值只有 2048，因此可以先预处理 st 为两个元素的异或可以组成的不同值
对于值域中每个值 v，查询是否有 a 满足 v^a 在集合中；若有，说明这个值可以达到。复杂度 O(n^2+Vn)
若需要更快速的做法，见 FWT

2. 给定值域范围 [l,r]，l,r<=2^30，求三个不同的数 a,b,c 满足 a,b,c互不相同且 (a^b)+(a^c)+(b^c) 最大【2057c】
一个很重要的处理：**记 `k=__lg(l^r)`，所有 [l,r] 之内的数在 k 以上的位完全相同；并且 l[k]=0, r[k]=1，k 代表 l 和 r 的最高不同位**。

回到原题，显然每个位独立，求出k后可以把 k 以上的高位全都忽略（只能固定）；对于下面的位，考虑每个位对应的三个数的异或，如果三个数都相同，那么贡献为0。否则三个数不全相同。
不管是 (1,1,0) 还是 (0,0,1) 的组合，可以发现贡献都是 2*(1<< i). 因此，只需要每一位都不全相同就可以最大化总和。
构造（忽略固定的高位）：**令 a 的第k位为0，剩下的低位都是1；令 b 的第k位为1，剩下的低位都是0. 这样，由于 a 是最大的第k位为0的数，l[k]=0，且 b 是最小的第k位为1的数，r[k]=1，所以 a 和 b 都一定在范围内，并且每一个能变化的位上都不相同**。
那么 c 的每一位选什么都已经无所谓（a和b已经满足了不全相同的要求），只要选一个[l,r]之间和a,b不相同的数即可。

3. 【**重要**性质2245C】给定长度 n 和整数 k。构造一个排列 p，定义 f[i]=MEX(p[0],..,p[i])，使得 XOR_{i=0..n-1} f[i] = k
首先注意到，f[n-1]=n 是固定的，问题转化为对于前 n-1 个前缀 MEX 的异或和为 x:=k^n.
考虑对于排列中 0 的位置之前的 MEX 都是 0，不影响答案。考虑对于后面的关键位置如何构造；
对于排列的 MEX，显然前缀 MEX 的范围是 0 到 n-1 之间。如果 x < n，显然可以构造一个排列，最后两个数是0与x，使得前面的 MEX 都是 0，最后两个 MEX 是 x 与 n，异或和为 k。

否则，就是需要一些 0~n-1 中的数异或出 x。计算 m=__lg(n-1)，那么 0~n-1 中所有数的最高可行位为 m，因此任意取数的异或最高位也不会超过 m. 
如果 x>=(1<<(m+1))，说明超过，无解。否则，考虑 a=n-1,b=x^a. 由于此时 x>=n>n-1>=2^m，因此 x 的第 m 位一定为 1. 而 a=n-1 的第 x 位也是 1，因此 x^a 一定在范围内。
因此构造一个排列使得最后三个数是 0,x^(n-1),n-1 即可。

结论：如果一个数 x 可以由 [0,y] 中的任意数异或出来，一定有：x < 1<<(__lg(y)+1)，即 x 的最高位最高只能到 y 的最高位 1（即为 __lg(y) 的位置）
并且如果可以被异或出来，最多只需要两个数：要么 x <= y，只需要 x，否则取 y-1 与 x^(y-1)，两数异或为 x 且都在范围内。

4. 【**重要**2146D1】给定 n，求一个 0~n 的排列最大化 sum_{i=0,..,n} OR(p[i],i)
分析：由于 OR(a,b)<=a+b，当所有的 1 位都没有被浪费时，即 a&b==0 时有上界，因此尝试构造一个排列使得所有1都不被浪费；此时答案即为 sum (p[i]+i)=n*(n+1)/2*2 = n *(n+1)/2
感性的来说，对于每个数，对应匹配一个自己的取反即可，即：
从大到小枚举，记当前数为 x，如果之前没有数和 x 匹配过，就计算：**m=__lg(x), mask=(1<<(m+1))-1, y=mask^x**. 考虑这个 mask 是最高可行位与 x 相同的全 1 数，和 x 做异或实际上是做差，得到的 y 就是在每个可行位和 x 取反的数。然后记 p[x]=y,p[y]=x（注意两对都要这样标记！！），并继续枚举。

这样的构造不重不漏，关键在于从大到小枚举，实际上是在执行这个过程：
对于当前最大数 x，考虑 m=__lg(x)，那么区间 [2^m,x] 的所有数最大可行位都是 m。对于区间中的任意数 i，将其与 (2^{m+1}-1)^i 匹配。注意到这个异或等价于减法，所以是把 i 与 2^{m+1}-i-1 来匹配。那么整个区间 [2^m,x] 会与 [2^{m+1}-x-1,2^m-1] 的数两两匹配，这两个区间没有重合且没有空隙。接下来 x'=2^{m+1}-x-2，继续执行这个过程即可。所有数都会得到一个指派，且不会有重复。

5. 【**重要**2179D】构造一个 0~2^n-1 的排列，使得 sum_i popcount(p[0]&p[1]&..&p[i]) 最大，且字典序是所有满足最大值中最小的。
感性理解，先考虑最大值是什么样子的：要让前缀与和的 popcount 最大，每个前缀应该尽可能地保持 1 不被与掉。
第一个数一定要放最大的 2^n-1，这样有 n 个 1. 第二个数为了要让这一步有 n-1 个 1 且字典序最小，放 011..1=2^{n-1}-1. 接下来，有两个选择使得这一步前缀有 n-2 个1：001..1 或 1011..1；为了字典序最小，按照这个方向放，这样前缀与和的popcount仍然是 n,n-1,n-2,n-2..
按照这个规律：要使固定前缀的与和有 k 个 0，必定这前面的数这 k 位都是0.为了字典序最小，将最后 k 位固定为 0，前面的选择有 2^{n-k} 种。每一层能放的选择即有 2^{n-k}-2^{n-k-1} 种。按照层输出保证值最大，层内部再按照字典序输出保证最小。
```CPP
for(int i=n;~i;--i){
    int mx=(1<<i)-1;
    for(int j=mx;j<(1<<n);j+=((mx+1)<<1))cout<<j<<" ";
}
```

6. **重要不变量** 
考虑一种操作：数组中选两个数 x,y，将他们替换为 x&y, x|y. 这一操作有许多不变量性质：
首先，由于 **x+y = (x&y)+(x|y)**，因此所有数之和是不变量。
其次，拆位分析，固定第 b 位，考虑 (x,y)->(x|y,x&y) 在第 b 位操作前后：00->00, 11->11, 10->10, 01->10，因此可以发现 1 的个数是不变的，这个操作本质上就是**把不相同的位swap且执行 OR 的位置拿到 1**了。因此，如果记 cnt[b] 为数组中所有数第 b 位的和（即所有数第 b 位是 1 的个数），那么对于所有 b，**cnt[b] 在操作前后都是不变**的。
最后，是一个很重要的推论：由于第二点的分析，这样的操作只是把 01 或 10 对调，因此两个数的二进制下 1 个数之和是不变的：
**popcount(x)+popcount(y)=popcount(x&y)+popcount(x|y)**.（注：后文记popcount为函数f）

例1【LC2354】给定数组 a 与整数 k，称 (a[i],a[j]) 是好数对 <=> a[i]|a[j] 与 a[i]&a[j] 的二进制中 1 位之和 >=k；求好数对个数。
由于 f(x)+f(y)=f(x&y)+f(x|y)，因此等价于 f(x)+f(y)>=k；固定一个 f，等价于找 popcount>=k-f 的个数，哈希表统计即可。

例2【LC2897】给定数组 a 与整数 k，可以执行操作 (a[i],a[j])->(a[i]&a[j],a[i]|a[j]) 任意次。需要最终选择 k 个元素，并计算他们的平方和。
首先这题有两个母题：其一是**给定数组无限次操作，那么大概率是要分析不变量**的。其二是关于元素的平方和：由于平方函数的性质，感性上考虑，所有数字越接近并且最大值越小，平方和越小；所有数字离得越开并且最大值最大的平方和越大。这里由于第一个不变量，所有数字和相同，所以一定是要贪心的把数变的极差大。
这里，要用到第二个不变量：所有数计算出来的 cnt 数组，对于每一位 b 都有 cnt[b] 操作前后不变。因此，可以先把 cnt 统计出来，然后循环 k 次，每次贪心的，当前位置能有1选就选上，然后--cnt[b]，最后得到当前轮能凑出来的最大数。每一轮平方和贡献给答案即可。
如何构造出符合这个的解？其实很简单，假设对于 a[0]，循环 a[1]..a[n-1]，做 a[0]<-a[0]|a[i],a[i]<-a[0]&a[i]，那么操作之后就有：只要当前位有 1，就会被换到 a[0] 上；最终只要有 1 的位就会出现在 a[0]，这等价于把所有 cnt 不为 0 的加上去。后续 a[0] 确定后就是相同的子问题了，一直这样构造的结果和贪心按照 cnt 来做是一样的。

7. **位运算恒等式**
对于 x > y 定义 f(x,y) = (x + y) ^ (x - y). 给定数组 a，求所有满足 a[i] > a[j] 的数对的 f(a[i], a[j]) 结果的最大值。
使用位运算推式子：f(x, y) = (x + y) ^ (x - y) = (x + y) + (x - y) - 2((x + y) & (x - y)) = 2x - 2((x + y) & (x - y));
由于与运算越与越小，0 <= (x+y)&(x-y) <= min(x+y,x-y) = x-y;
因此 2x - 2(x-y) <= f(x, y) <= 2x ==> 2y <= f(x,y) <= 2x.
假设 x,y 均不是数组最大值，那么 2y <= f(x,y) <= 2x, 2x <= f(mxa,x) <= 2mxa，因此一定可以调整成包含最大值的解。
因此，固定 x 为 mxa，遍历数组，O(n) 更新 f 最大值即可。
