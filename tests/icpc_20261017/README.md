## 结论与分类

| 模板 | 分类 | 证据与处理 |
|---|---|---|
| Fibonacci | 已知版本差异 / 组合使用风险 | 旧文件为递归 `fib(n, mod)`，宏 `#define int long long` 会污染后续 ST2D 的 `max(x1, 0)` 并导致编译失败。改为全局 `const int mod`、迭代 `int fib(long long n)`，默认 `1e9+7`。旧递归公式在 int 范围正模数下不是已证实的数值错误。 |
| Fibonacci 大模数 | 新实现必须避免的溢出 | 不照抄 `int b = c + d`：mod 接近 INT_MAX 时可能溢出。使用先比较 `mod-d` 的加法；乘法/平方和用 long long。验证 mod=1,2,998244353,1000000007,1073741825,2147483647。 |
| ST2D | 纯包装差异 / 注释不符 | 已删除两个 `at()`，直接访问 `st[id(...)]`。原代码已经有越界裁剪和空矩形单位元返回，原样保留；旧注释却要求非空且不越界，现已澄清。未发现有效输入内的矩形计算错误。 |
| KMP | 边界正确性错误 | 空模式串 `find("")` 原返回 -1，`find_all("a")`、`period()` 有无效访问。明确空串匹配全部 n+1 个间隙，空串 period=0。 |
| Fail Tree | 正确性错误 | `KMP("a")` 连续两次构建，原 `g[0]` 为 `{1,1}`。`resize` 改 `assign`，清空旧邻接边和父数组。 |
| KMP 周期与 DP 注释 | 文档错误，不改变非空 period 行为 | `period("aba")` 仍为完整循环节 3，一般周期为 `m-pi[m-1]=2`。修正 cnt 的长度/末尾下标混用为 `cnt[len]=1+cnt[pi[len-1]]`，并明确合法 border 要继续跳 fail 链直到符合条件。 |
| 置换环 | 溢出错误 | `{1,0}` 的 `jump(1,LLONG_MAX)` 原先计算 `1+LLONG_MAX`，UBSan 复现。先 `t%L` 再加位置。距离表达式也提升为 long long；超大环距离溢出为算术证明，未分配十亿节点实测。 |
| 带修 Wavelet | 编译错误 | 类成员 `count` 遮蔽 `std::count`，具体实例化即失败。只限定该调用为 `std::count`。 |
| 两份 Wavelet | 空区间正确性错误 | `{0}` 的 `range_freq(0,0,1,-1)` 原为 -1；`{0,1,2}` 的 `count_leq(2,0,2)` 原为 -1。空值域与空下标区间均返回 0，rank 返回 1。 |
| 两份 HLD | 已测范围内未发现逻辑错误 | 保持源文件不变；所有路径、子树、DFS 序映射对拍通过。递归深链栈风险见下文。 |

除明确要求的 Fibonacci 接口变更外，保留已有公共方法名与非空输入语义，不统一重命名全库。原有通用模板的 `numeric_limits<T>` 保留，避免把泛型哨兵错误替换为 int 极值；未新增 `numeric_limits<int>`、整数宏或 `__int128`。

## 可复现测试

在仓库根目录：

```sh
python3 tests/icpc_20261017/run.py
python3 tests/icpc_20261017/run.py --sanitize
```

使用 GCC 13.3.0、C++17；可通过 CXX 指定编译器。构建产物只放临时目录。测试直接包含实际模板，不复制另一份待测实现。Fibonacci 多模数测试只替换全局常量声明，不改函数体；预期值来自独立线性递推及 2×2 矩阵快速幂。

|---|---|
| Fibonacci | 六个模数；每个验证 n=0..100000，另外 2,130 个大下标样例，含 2 的幂附近、LLONG_MAX 和固定种子随机数；静态检查返回 int。 |
| ST2D | 672,672 个矩形；1..7 行、1..8 列的随机矩阵逐格暴力扫描；min/max、gcd，负数、INT_MIN/MAX，单格、单行、单列、越界裁剪、反向/不相交空矩形。 |
| KMP / Fail Tree | 65,025 组二元字母表穷举文本/模式，2,000 组随机、嵌入 NUL；暴力匹配、pi、border、完整循环节、重复构建；另测 fail 链 DP、出现次数反传、父节点 LCA 对应公共真 border。 |

随机种子固定为 20261017。优化版与 ASan+UBSan 版统一测试均通过。优化版仍有 KMP 原有三处 `int` 与 `size()` 比较的 signedness 编译警告；这是既有风格差异，在声明的长度范围内不是失败用例，本次不为消警告批量改写。

环境限制：默认 LeakSanitizer 在退出时无法访问 `/proc/.../task`，报告 ptrace 限制；runner 仅禁用 leak detection，地址越界和未定义行为检查仍启用。没有在用户 Windows / MinGW 15.2 或比赛机上运行；本次结果不等于那两个环境的实测。

## 未改写的资源风险与调用前提

- **HLD 深链栈溢出已复现。** 本环境 8 MiB 栈，-O2 下两版 10,000 节点链通过，50,000/100,000/200,000 节点链 SIGSEGV；ASan 对 50,000 明确报告 stack-overflow。具体阈值依赖平台。赛前如要覆盖 2e5 深链，应另用显式栈构建版本或确认评测栈容量；当前 PR 不声称解决此风险。命令在 [hld_findings.md](hld_findings.md)。
- HLD 接受非空合法树；边权存儿子节点，叶子 `subtree` 返回 l>r，交给线段树前判空；路径不保证有向合并顺序。`toSeq` 实为 O(n)，`subtree` O(1)，原“其余查询 O(logn)”注释不精确。
- ST2D 构造仍要求非空、等长矩阵，查询允许裁剪。运算需结合、交换、幂等并提供正确单位元；不能直接换成求和。1000×1000 的 int 表约 400,000,000 字节（381.5 MiB，仅 st），应按题目内存限制选用。
- Wavelet 非空端点必须有效；空区间端点在数组边界内（0<=l<=n、-1<=r<n），不承诺像 ST2D 一样裁剪任意 INT_MIN/MAX 坐标。kth 无空区间结果，必须 1<=k<=长度；动态更新值必须已加入 candidates。前驱严格 `<x`，后继为 `>=x`；极值哨兵可能与实际极值元素相同，这是保留的 API。
- 带修 Wavelet 的随机 Treap 时间界为期望界；未进行比赛规模或对抗优先级性能基准。Node 当前 6 个 4 字节字段，每层约 24(n+1) 字节，n=2e5、18 层仅节点约 82.4 MiB，另有其他数组。
- 置换环要求合法排列、有效点、非负步数；空排列只测构建/环数。Fibonacci 要求 n>=0、1<=mod<=INT_MAX。KMP 长度小于 INT_MAX；默认构造的其他模板须完成构建或赋值后使用。

细分证据：[KMP/置换环](kmp_perm_findings.md)、[Wavelet](wavelet_findings.md)、[HLD](hld_findings.md)。修复前的反例与诊断均记录，未把越出输入契约的调用列为算法错误。
