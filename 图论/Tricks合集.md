## 做题注意！！！

1. 一定要注意是否给定起点终点（s 与 e），还是设置为 0 和 n - 1

2. 注意题目描述是否为有向图 / 无向图，不要建错图！

3. 注意 dis 有时候需要开 ll 并用 LINF

4. 注意最后不可达状态，res 为 LINF 的时候特殊输出 -1 之类

5. **注意数据范围**，如果 n 小可以枚举每个点搜索，如果 m 小可以枚举边，固定其边上信息，然后只走满足限制的边来判断，如果 w 小想分层图，把值域放进维度；若有额外点且数据小，想状压枚举他们并在原来的基础上增量构建

6. SCC 缩点后记得用 `for (auto& v : dag[u])` 而不是 g[u]！

7. 有时候数据给 (u,v)=(0,0) 在转化 0-based 造成 RE，注意

8. 循环看清楚读入 n 次还是 n-1 次还是 m 次！！！

## BFS 相关

1. 有时可以借鉴分层图的思路，最常用的就是 dis[u][0] 与 dis[u][1] 分别代表经过偶数 / 奇数条边的最短从起点到 u 的 walk 长度

2. 给定一些特殊点，求每个点到最近特殊点的距离：用**多源 BFS**；这个多源 BFS 形成的值一定是连续的离散值范围扩展，因此有些还可以融入 **DSU** 来进行第一次联通查询（注意值域连续，记录一个 vec[i] = {(x,y): dis[x][y]==i}，按 vec 的外层维度枚举，每次每个 vec[i] 中的点只需要查询是否有比他值>=的，有了就联通）

3. 边权只有 0 或 1，可以用 0-1 BFS 将 dij 优化成线性的

4. **网格图与特殊操作【重要！！】**
对于网格图问题，常见的变式即为加上一些特殊要求。
- 对于**特殊要求**（例如要求步数mod某个数的值，或奇偶性，或要求不经过超过k个特殊点）或**特殊操作**（例如可以使用k次免费/半价/传送门）的题目，直接考虑**分层图**来做
- 对于**特殊点集**（例如给定一些点是关键点，或机关点），要考虑**多源BFS**或**分层图**。如果题目包含类似离最近的特殊点距离这样的子问题，那先考虑做一次多源BFS。
其他情况，也可以考虑对于特殊点集上的**状压分层图**【P3869】：
给定 k 个机关点(k<=10)，踩上去会使这个机关控制的一些点从可以通过变成障碍，从障碍变成可以通过。
由于 k 较小，可以把层定义为经过奇数次的机关点点集合（如果偶数次相当于没有操作）。那么每次向四周转移时，对于新点，计算他被这些机关改变了几次状态。新的状压集合用异或即可得到。

例2：【P5096】正边权图，有 k 个特殊点(k<=12)，特殊点上有一个资源，每次经过可以收集或不收集。每次走边边权不能小于已经采集的资源，求从 0 开始回到 0，能够采集最多的资源数
一方面 k 很小，另一方面在转移过程中需要知道走过了哪些特殊点，这些都启发了对于特殊点维度做状压进行分层图最短路
```CPP
// 分层图 BFS；注意到 k 较小，对吃过的洞状压
void solve() {
    int n, m, k; cin >> n >> m >> k;
    vector<char> has(n);
    vi id(n);
    for (int i = 0; i < k; ++i) {
    	int x; cin >> x; --x;
    	has[x] = 1;
    	id[x] = i;
    }
    vector<vector<pii>> g(n);
    for (int i = 0; i < m; ++i) {
    	int u, v, w; cin >> u >> v >> w; --u, --v;
    	g[u].eb(v, w), g[v].eb(u, w);
    }
    int K = 1 << k;
    vector dis(n, vi(K, INF)); dis[0][0] = 0;  // 到达点 u，吃了 mask 中的干草（还没有考虑 u）
    queue<pii> q; q.emplace(0, 0);
    while (!q.empty()) {
    	auto [u, mask] = q.front(); q.pop();
    	int cur_w = __builtin_popcount(mask);
    	// 不吃 u 的草
    	for (auto& [v, w] : g[u]) {
    		if (cur_w <= w && dis[v][mask] > dis[u][mask] + 1) {
    			dis[v][mask] = dis[u][mask] + 1;
    			q.emplace(v, mask);
    		}
    	}
    	if (!has[u] || mask >> id[u] & 1) continue;
    	// 吃 u 的草
    	++cur_w;
    	int nmask = mask | (1 << id[u]);
    	for (auto& [v, w] : g[u]) {
    		if (cur_w <= w && dis[v][nmask] > dis[u][mask] + 1) {
    			dis[v][nmask] = dis[u][mask] + 1;
    			q.emplace(v, nmask);
    		}
    	}
    }
    int res = 0;
    for (int mask = K - 1; ~mask; --mask) {
    	if (dis[0][mask] != INF) {
    		int d = has[0] && !(mask >> id[0] & 1);
    		res = max(res, __builtin_popcount(mask) + d);
    	}
    }
    cout << res << endl;
}
```


## 单源最短路相关

1. 由于堆的性质，可以很方别的进行 tie-break 比大小；例如，在最小化 cost 时最小化经过的点数，可以建立 dis 与 cnt 数组，更新的时候检查 dis[v] > nd || dis[v] == nd && cnt[v] > nc

2. 【!P5201】最短路树是个很重要的性质。在题目中规定了tie时取字典序等break的办法，那么此时最短路树是唯一的。只需要在 dijk 中维护前驱数组 pre 即可，pre[u] 即为最短路树上 u 的父节点。P5201 是在图中每个点有奶牛，要走到 0，但是可以在 0 和任一点之间连一条边权固定为 t，求最多可以省多少权和。首先以 0 为源点进行 dij 求出每个点到 0 的最短距离，那么考虑从 0 到这个点修一条边，不仅有当前 c[u] 只奶牛会从 dis[u] 变成 t 的时间，所有 sum_{v 在 u 的最短路树子树上} c[v] 也都会走到这里以后后半段距离从 dis[u] 变成 t。因此从 0 到 u 修一条快捷路，有 sum[u] 只牛可以优惠 dis[u] - t，其中 sum[u] 是在最短路上子树 u 中 c[u] 之和，再做一次树形 dp 即可。

3. 图上前后缀分解（eg 正图从起点一次dij，反图从终点一次dij）有时会很有用。例如判断一条边是否在最短路里，dis0[u] + w[u][v] + dis1[v] == dis0[v]

4. 有与时间代价相关的题（下面时间代表经过边的数量）：
    - 例1. 边权图，如果走了时间 t，就要扣掉 P*t 的价值，求最后可以获得的最大边权和。由于是线性的，可以把代价分开，给每个边扣抵 P，这样加起来总共还是 sum w[i] - P * t.
    - 例2. 【P6005】点权图，如果走了时间 t，就要扣掉 C*t^2 的价值，求最后可以获得的最大利润。给定点权 <=1000。分析：最后价值为 sum w[i] - C * t^2，由于每个 w[i]<=1000，因此为了 0 <= 盈利价值 <= 1000t - Ct^2，有 Ct <= 1000，说明 t 不能超过 1000/c。这个维度很小，额外开一个进行分层图最短路。这启发我们，在没有明显分层图维度时，要通过分析另一个信息的界来获得可以建立维度的值。这题的分层图最短路还有优化写法，见下：

5. 分层图最短路的优化：有些分层图并不是特殊操作限制，例如第二个维度开一个经过的边数，那么更新只有一种：dis[v][t+1] <-- dis[u][t] + w，在第二维度是满足 DAG 性质的，所以可以直接双重循环来枚举转移

6. **【重要】**！求从 s 到 t 的最短路路径，并且在 tie 的时候需要字典序最小：从 t 开始在反图上 dij，更新的条件为 
```CPP
dis[v] > dis[u] + w || dis[v] == dis[u] + w && pre[v] > u;
```
这样每次贪心选择前驱字典序最小。求出后从 s 到 t 的最短路树即为求出来的最短路树的反树

7. **【重要】** 对于有向图，要求任意点到终点的最短路，等价于以终点作为起点在反图上跑单源最短路的结果

8. 有类似负权的操作时（eg，可以时间旅行的航线）会把一个点反复变小多次入堆，导致一组边被重复扫多次，复杂度退化为 O(nm)。这时要想优化的办法，使得每个边扫一次确定（P9126，每个点出边排序+双指针）

9. 【P9650】怪物封锁的最短路：边权无向图，每个点 i 有 d[i] 个怪物，每次到达 i 后会封锁 d[i] 条邻出边，求最坏情况下 0 到给定一组出口中任意一个的最短路。首先考虑没有怪物限制，那么从所有终点出发，在反图上做一个多源 Dij 得到的 vis[i] 即表示 i 到最近一个出口的最短距离。考虑这样更新时，每次取出堆顶是在确定 u 的距离并更新邻点，这也就说明了发现了 u 到任意一个出口的一个最短路。那么按照这个思路只需要记录一个 cnt 数组，对于一个点第一次取出是确定了第一短出路，第二次取出第二短出路... 直到 cnt[u]==d[u]+1 时说明找到了一个被封锁前 d 小出路后剩下的那个最优选择。在这次取出堆顶时才进行正式确定，并用这个 dis 值来更新邻点。细节在代码中补充：
```CPP
vi cnt(n);  // 第几次被作为堆顶取出；即为找到了第几短的出路
vector<char> done(n);  // 是否被确定了
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (done[u]) continue;  // 之前被确定过的话，不重复更新邻点
    ++cnt[u];
    if (cnt[u] <= need[u]) continue;  // 前 need[u] 次发现都会被封锁
    dis[u] = d;  // 可以确定他为第 need+1 短路，距离最近出口 d
    done[u] = 1;
    for (auto& [v, w] : g[u]) {  // 这里 g 是反图
        if (done[v]) continue;  // 已经确定过，更新后不可能变得更优秀
        pq.emplace(dis[u] + w, v);  // 注意这里不能先算 dis[v]，由于 v 不一定够次数
    }
}
```

10. 在数据规模 m~5e3 并可以有个对于边的特殊操作（eg 选一个某个特殊边并把他对应的权重扣掉）时，考虑**枚举这条边**并以对应的限制执行 dij 得到结果。例【P15803】，可以选一个 b 最大的边并把对应的 w 减去。可以枚举每一个边作为最大的 b 并且不计入 w，那么对于正反图分别 dij 且 dij 中不能使用超过 b 的边，最后用 min(dis1[u]+dis2[v],dis1[v]+dis2[u]) 更新答案。这类题复杂度在 O(m^2logn)

更一般的，若是要求除了单纯的边权和最短路外还有要求，eg：最小化代价和+经过边权最小值/+边权最大值/经过点权最大值等，直接考虑**枚举这一维度的信息，把他们从变量变为一个定值，在最短路的时候再考虑满足这个确定的代价限制**

11. 一般的，对于每个点到达时有特殊限制的，在松弛之前检查条件：if (dis[v] > dis[u]+w && u到v这个节点满足需要的条件)，再进行松弛

12. **重要：虚拟源点**【abc463e】给定一个边权有向图，边 uv 的距离为 w。以及额外从一个点i到任意一个点j的传送门，需要的时间是 x[i]+x[j]+y. 求0到所有点的最短路长度。
对于传送门操作，由于两两之间都有，因此有 O(n^2) 级别条边，建边就超时了。考虑建立虚拟点 n 与 n+1，其中所有 i 到 n 有边长为 x[i]，n 到 n+1 有边长为 y，n+1 到所有 i 有边长为 x[i].
那么，通过走虚拟源点，i 到 j 就相当于被新增了一条路径长为 w[i]+w[j]+y，正好是题目的要求。这样就把 O(n^2) 条边压缩到了 O(n) 条。之后跑正常的 dijk 即可。
**启发：对于一种两两之间的关系，有 O(n^2) 对，要考虑找一个“中介”进行优化，从而降低到只用添加 O(n) 个边到虚拟点从而达到原来的效果**。

另一个很重要的虚拟源点建模是有关**多终点最短路**的：
考虑这样一个母题：无向图上有多个终点 t，对于每个 i，求 i 到最近的终点的距离：min_t {dis(i,t)}。建立虚拟源点 T，其中 T 到所有 t 有边权为 0 的边。
从 T 开始做 dijk，考虑其到每个 i 的最短路 dis(T,i)：其必须先经过一条边到某个 t，再从 t 走正常边到 i。由于 T-t 边权为 0，因此 T 到 i 的最短路就是所有 t 到 i 的最短路中最小的，即为所求。

练习：【938D】给定无向有权图，以及每个点有边权；对于每个 i，求 min_j {dis(i,j)+a[j]+dis(j,i)}，其中 dis 代表最短路长度。
由于无向，dis(i,j)=dis(j,i)，因此对于每条边边权都翻倍，即为对于每个 i 求 min_j {dis(i,j)+a[j]}。这与母题唯一的差别是多了一项 a[j]，因此尝试：
建立虚拟源点 T，其中 T 对于所有 i 都有边，边权为 a[i]. 那么从 T 开始做 dijk，到每个 i 的最短路 dis(T,i) 即为：
对于所有 T 先到某个 j，权为 a[j]，再从 j 到 i，权为 dis(i,j) 的路径中取最小值，即为 min_j {dis(i,j)+a[j]}。
这也是建立虚拟源点最短路的模板题。

另一个经典建模是与最小生成树相关的，见最小生成树-1.


## 多源最短路相关

1. 牢记 Floyd 算法中第一层循环 k 表示当前只能用编号 <=k 的点进行松弛，这里的 k 是链接 i-j 的中间节点。还需要注意的是，外层即使枚举到 k，内层上限一定要拉满到 n，而不是 k。这是因为不变量要保证：
**处理完中转点 k 后，所有 (0<=i,j<n) 的 f[i][j] 都已经被且仅被 [0,k] 的点松弛过**
    - 例：【P1119】，每个点有重建时间，保证 t0<=...<=tn-1；给定时间递增的询问求最短路。由于 t 数组递增，外层还是顺序枚举 k，但是代表当前只用时间 <=t[k] 的节点进行松弛。询问可以单指针顺序处理。注意：1. 询问处理的条件是直到 qrs[t] >= t[k+1]，而不是 t[k]；2. 在用 k 松弛时，无论 t[i], t[j] 是否被重建完成了，都要进行更新，否则永远缺失 k 当中间点的路径。在询问时特判两节点时间是否满足条件即可

2. 特殊操作：无权图每次可以走 2 的幂次边，n<=50，求最少走几次。这就是说每个 2 的幂的边数可以一起走，定义 can[p][i][j] 为是否有一条从 i 到 j，经过 2^p 条边的路，floyd 式的枚举中间点进行转移 can[p][i][j] |= can[p-1][i][k] && can[p-1][k][j] 即可

3. Floyd 的循环可以变化上下界，前提是要保证 1 中所说的不变量。例：【P15805】子图最短路，对所有 [l,r]，0 <=l<=r< n，求 d(l,r,u,v) 的和，其中 d(l,r,u,v) 代表在只能使用编号 [l,r] 中的点时 uv 之间的最短路长度。考虑先固定左端点 l，枚举右端点 r，这一重循环作为 Floyd 的外层循环：当枚举到 r 时，不变量保证所有 f[i][j] 都被编号 [l,r] 之内的点更新了。细节见代码
```CPP
ll res = 0;
for (int l = 0; l < n; ++l) {  // 固定左端点 l，所有 [0,l-1] 内的点都不用考虑
    auto f = F;
    for (int r = l; r < n; ++r) {  // 循环到 r 结束后，代表 f[i][j] 都被 [l,r] 内的点松弛了
        for (int i = l; i < n; ++i) { // 内层两循环上限一定要到 n，否则会漏掉用 r 作为中转点时，对一些 i,j 编号较大的 f[i][j] 的更新
            if (f[i][r] == LINF || i == r) continue;
            for (int j = l; j < n; ++j) {
                if (f[r][j] == LINF || j == r) continue;
                f[i][j] = min(f[i][j], f[i][r] + f[r][j]);
            }
        }
        for (int i = l; i <= r; ++i) {  // 此时所有 f[i][j], l<=i,j<=r 都只被 [l,r] 内的点松弛了，代表 [l,r] 子图
            for (int j = i; j <= r; ++j) {
                if (f[i][j] != LINF) (res += f[i][j]) %= mod;
            }
        }
    }
}
```

4. Floyd 的一层循环不仅能限制编号的范围，还可以限制例如**点权的范围**：
【P2966】给定一个图，n小m大，给定q个查询st之间的最小距离，距离定义为：路径上边权和加上路径上点权的最大值。由于 n 小，可以用这种题目的管用套路，来枚举认为固定一个上限并在转移时使用这个限制。
由于多次查询，因此需要是思考如何在 Floyd 算法中体现。注意到第一层循环可以限制中转点，因此对于点权排序，按照这个顺序作为第一维。那么第一维循环第 id 次后，其中第 id 次对应的是第 id 小点权 val 和对应的点编号 k，的不变量 f[i][j] 就变成了：只考虑点权 <=val 的点**作为中转点**，从 i 到 j 的最短路长度。此时可以对答案 res[i][j] 更新：f[i][j] + val（由于不变量，当前路径上点权最大的点就是 val；这样的更新不会把答案变坏：如果当前路径真实最大值比 val 小，在枚举到那个点时，就会更新正确的答案）。
有两个需要注意的细节：1. 做 Floyd 时，不能写 k==i || k==j 的剪枝：这个剪枝只能省去 f[i][j] 的更新（由于 [i][i]=0），但是对于 res[i][j] 的更新是利用到了这个 k 点的权 val 的，所以当 val 加入时，一定要用它更新答案。2. 对于更新答案时，还要额外检查 a[u]<=val && a[v]<=val，这是因为外层循环只限制了中转点的点权大小，而答案更新的 i 和 j 是只使用这些点更新的任意点对，换句话说，端点的点权并不会受到限制。

## 最小生成树相关

生成树相关题目识别：给定一个图，用最小代价使得所有点联通/拆除最多的使所有点联通，即为保留一组最优的 n-1 个边，考虑 MST。
一般 Kruskal 适合处理多个连通块逐步联通的过程，有点是在中间可以获得边权限制下的最小生成森林

1. 【P1550】给定一个图有边权与点权，代表路费和打井费。要让每个点要么自己有井，要么和有井的点联通，求最小花费。
即：**每个点要么通过边权被联通，要么选自己的点权把自己联通**
做法：建立**虚拟源点**（这是一个图论中很重要的技巧！）。这里虚拟源点与每个点的边权是每个点的点权，那么选中这条边就代表这个点被打井了。在这个图上求 MST 会给出正确答案：由于是生成树，虚拟
点必定被选中，因此必定有一个点打井；并且，每个点都会联通在树中，要么是自己被打井，要么是和另一个有井点联通

另一个相似的建模是【ABC270F】每个点可以修港口/机场/与别的点修路。两个有机场的点可以互相到达，有港口的可以互相到达，走公路的可以互相到达。求所有点联通最小代价，给定边权，修建机场费，以及修建港口费。这也是每个点要么连到别的，要么自己修港口and/or机场，不同之处在于即使修建港口/机场，整个连通块还应该有一个边连回走公路的
建模：建立两个虚拟源点，一个对于所有点连边，边权为港口费；另一个对于所有点连边，边权为机场费。考虑这个图的 MST，每个点要么连到源点（建立机场或港口），要么有一端是原图边端点（修路出去），又因为 MST 覆盖所有顶点且联通，因此所有点都可达。
实现上注意要分类讨论，可能出现完全不使用其中一个/都不使用虚拟源点的情况。

2.**【重要】** 对于同时需要考虑点权的 MST：
    - 需要找生成树，最小化经过的边权和与点权和：由于 MST 一定取到所有顶点，因此点权和固定，求一个普通 MST 即可
    - 需要找生成树，最小化经过的边权和与点权的加权和，其中权为点在树中的度：令 **`nw = w + val[u] + val[v]`**，用新权跑 MST。这样找到的 MST 贡献总和即为边权的和加上每个点的点权被选了 deg 次
    - 需要找生成树，最小化这个颗树上 DFS tour 时 经过边的次数x边权 加上 经过点的次数x点权：注意到这个 DFS tour 会让每条边经过两次，除根外每个点经过 deg 次，根经过 deg+1 次，因此令 **`nw = 2*w + val[u] + val[v]`**，用新权跑 MST，得到的值加上最小的点权即为答案（根可任选，就选点权最小的那个）

3. 有些与 MST + 最小化最大边权有关的题目，除了可以想到二分答案，还应该联想到 Kruskal 的过程：并查集逐渐添加，保证了每次都加入尽量小的，那么最后一个加的就是最大的，这个过程即类似最小化最大边权

4. 对于 Kruskal，适合处理按照要求逐步按照连通块联通的题目，并且此算法**对于边集合的排序可以根据题目的要求来自定义，不只局限于按照边权小到大排序**。例：【P2573】，给定有点权与边权的图，u 可以走到 v 当且仅当 h[u]>=h[v]，代价为 w[u][v]. 要求从 0 点开始走一棵树，满足节点尽可能多的前提下最小代价。
首先从 0 开始进行 DFS，每次只走满足高度要求的边，那拓展的树节点个数即为第一问的条件。关键是在这个前提下，如何同时最小化边。对于边权进行如下排序：按照终点的高度作为第一维从大到小排序，按照边权大小作为第二维从小到大排序 得到的边数组按顺序进行 Kruskal 算法。
原因：感性思考，要保证这个树中首先所有点都要选到，更新的过程一定是按照高度从大到小扩散的。扩散的同时再去最小化选出来的边权。这里用终点高度从大到小排序而不是起点从大到小排序是因为：如果按照起点从大到小排序，一个起点会更新许多个不同高度的终点（例如高度最低的），那么会导致权值最小的中间点无法更新。而用终点高度从大到小更新，可以保证当前比终点高的点都被考虑过，从而可以做出到当前层的最优决策（按照高度层级稳步向前扩散，而不是越级更新导致决策不充分；重点：一个点可以做出最优选择当且仅当比他高的点都做好最优选择；由于这个选择在并查集中无法被反悔更新了，因此在做决策的时候要保证前面的都被更新过了）。

## 差分约束相关

题型：有多对不等式差值关系，判断是否有满足所有限制的解或求出最小非负解集。用差分约束更新出使每个点满足的最小下界。

1. 对于区间 [s,t] 中有 x 个值，可以用差分数组表示为 dif[s]+=x,dif[t]-=x。但若条件是**给定很多区间 [s,t] 有至少 x 值，求最少一共选多少个点**呢？转为差分约束建模：
令 **pre[i] = 选中点中 <=i 的个数**；
那么区间 [s,t] 至少选 x 个就是：**`pre[t] - pre[s-1] >= x`**；并且有基础约束 **`0<=pre[i]-pre[i-1]<=1`**（同理至多就是 <=x）】
最后跑完差分约束的 pre[n] 就是答案（这里不要转成 0-based，否则差分会到-1. 0是个dummynode）

## 图连通性/连通块问题

1. 经典模型：给定保险箱，每个箱子里又装着别的箱子的钥匙，问最多要破坏多少保险箱。用并查集，答案显然是连通块个数

2. 给无向边图，一个合法路径 {v1,v2,...,vn} 是满足 v1=s，对于奇数 vi < vi+1，否则 vi > vi+1 的路径（路径编号小大交错）。求对于每个点作为 s 时，有多少点是无论如何不可达的。
定义 up[u] 为从 u 出发下一步要走编号更大的点，down[u] 为从 u 出发下一步要走编号更小的点进行拆点，是二元状态可以在扩展域并查集中表示：up[u]=u, down[u]=u+n
那么对于一个边 i-j (i < j)，up[i] 和 down[j] 就可以连边。
对于每个点，他所在连通块里的所有点就是它出发可以到达的点（链式激活）

3. **【重要】** 对于一类只有对于**点/边的删除操作以及离线询问**的问题，用**时间倒流+并查集**处理。
具体的，将询问离线下来然后反向，先从全部删掉的状态开始，读到删边就转化为加边。这样把所有删除转为加入，并查集维护的是图上可达性连通块。
在**只有一种操作类型**情况下，应该考虑**时间倒流**（并查集适合添加，不适合删除）！
如果是删边 (u,v)，反向时将 (u,v) 联通即可。如果是删点 u，在反向时加入 u，先把 u 设为 alive，再加入所有临边 (u,v)，其中 v 也需要是 alive 的点

- 模板见“图连通性-时光倒流”
- 【P2189】对于一个无向无权图，选 k 个点为特殊点，第一次经过特殊点时会发送一个信号，之后再经过就不会了。给定一个 k 个特殊点的排列表示他们发送信号的先后顺序，判断是否存在一条路径满足产生这样的顺序。
考虑排列为 {p[0],...,p[k-1]}，对于路径 p[i-1] 到 p[i]，他们合法当且仅当存在一个路径上不经过未来的特殊点（p[i+1],...,p[k-1]）。考虑将这个建模为已经解锁的点和还没有解锁的点，用并查集处理图上连通块。
首先把所有满足边两端都不是特殊点的边的两端点加入并查集。依次处理 k 个特殊点，每次新到一个特殊点，就把他解锁，并将它的合法临边两端在并查集中联通。
这样，如果并查集中 p[i-1] 与 p[i] 在同一个连通块，就代表存在一个路径从 p[i-1] 开始只经过已经解锁的特殊点或者普通点到达 p[i]，反之不存在一个合法方案。这是因为未来特殊点现在还不能用，所以相关的边都不能使用。

这类题目不仅可以时间倒流（倒序操作排序），有些题目还可以改进为**离线查询+排序**把他变成需要的顺序。
例如 【P4185】给定一个有权树，Q 个询问 [k,u] 问有多少个节点 v 满足 u-v 路径上最小边权 >=k。
将边权从大到小排序，将询问按照 k 从大到小排序，对于一个询问的 k，使用单调指针维护边权 >=k 的边并将两端加入并查集。那么对于 node 的答案即为 node 所在连通块点数-1.

类似的离线排序，并查集依次检查的思想还出现在 Kruskal 算法中。另外，还有题目：给定一个排列 i->pos[i] 的数组 pos[i]，以及 m 条交换条件 {u,v,w}，表示 u 到 v 花费 w 交换。求把数组变成排序的排列所需要 w 最大的最小值。
考虑离线并从大到小排序 {w,u,v}，每次合并 u,v，检查是否每个 i 都与 pos[i] 联通。如果是，当前 w 就是答案，否则继续下一个边。对于检查，维护一个单调指针即可，复杂度 O(n+m)

有时候倒序添加的题目还会使用**DFS染答案**，例如【P8059】：给定一个图，有删边操作，问每个点第一次与 0 联通的时间。由于只有删除，倒序做，变为加边，考虑当前加边 (u,v)：如果 u 和 v 都已经和 0 联通了，这条边没有任何作用，忽略（重要思想，见下题）；否则如果 u 和 v 都没有和 0 联通，只在并查集中 unite 他们但不更新答案；否则考虑有一边与 0 联通，另一边没有，那加上这条边后，另一边的所有点在这个时刻第一次与 0 联通，需要维护一个真实图 g，并使用 DFS 进行整个连通块内的答案更新。
在这里，如果 u 和 v 都联通的情况下，他们的连通块已经更新答案了，后续如果有别的答案更新 DFS 是无论如何不会经过这条边，所以他即不用在 UFS 中 unite，又不会为后续更新所用到，所以是一个可以忽略的操作！

**！【重要】！**有些题目，甚至还可以在有加边事件时依旧可以倒序考虑。【P8097】给定 n 个点的图，每个点一开始都是激活状态。三种操作：D x 代表把 x 调整为不激活；A x y 代表加 x 到 y 的边，保证 x 和 y 都在激活状态；R e 代表删除第 e 次加的边。定义一个点是相关的当且仅当这个点被激活或他和一个被激活点联通，对于每个点求最大的 i 使得在 i 次操作后依旧是相关的。
- 关键观察：对于操作 1 和 3，可以很容易的进行倒序操作，但是操作 2 的反操作加边怎么办？题意中说加边当且仅当两个端点都在激活状态，因此在倒序操作时，删除这条边后两端点一定是激活的，说明一定被更新过答案，并且之后更新时不会用到这条边，因此这个操作是没有用的，在倒序中直接忽略即可！
- 完整做法：先建立所有操作之后的图：维护 live[x] 代表是否被激活，以及所有没有被撤销的加边都加上。这时遍历一下看激活点和所在连通块所有答案更新为 Q。然后倒序处理操作，对于激活一个点，激活他，如果没有更新过答案，就在这里进行 dfs 来染色答案；对于加边，检查如果一边是相关另一边不相关，把另一边 dfs 染色答案。对于删边操作，注意到删除前后连接的两端都是激活，即被更新过答案，并且之后 dfs 时也不会用到这条边，因此这个操作忽略即可。

## 拓扑序相关

题目常见模型：给定任务/选课，有先后关系（一个任务有别的任务作为前置条件）；即为一个**有向无环图**
常见处理方法是按照拓扑顺序，对于节点进行刷表法 DP；
最短路 DP：求最小花费 / 只要有一个前置完成就能解锁下一项
最长路 DP：求最大花费 / 所有前置都需要完成才能开启下一项

1. 拓扑序 DP 常见模型与公式：
边权图：
- 起点到每个点的最短路：dp[v] = min(dp[v], dp[u] + w)，初始化 dp[s]=0
- 起点到每个点的路径计数：dp[v] += dp[u]，初始化 dp[s]=1
- 起点到每个点的所有路径边权总和：
    路径条数：cnt[v] += cnt[u]，初始化 cnt[s]=1
    边权总和：sum[v] += sum[u] + cnt[u] * w，初始化 sum[s]=0
- 最短路条数计数：
```CPP
int nd = dis[u] + w;
if (nd < dis[v]) {
    dis[v] = nd;
    cnt[v] = cnt[u];
} else if (nd == dis[v]) {
    cnt[v] += cnt[u]
}
```
如果需要完整路径信息，用 pre 数组在被更新距离时记录前驱即可

点权图：
- 起点到每个点的最短路：dp[v] = min(dp[v], dp[u] + val[v])，初始化 dp[s]=val[s]
- 起点到每个点的路径计数：dp[v] += dp[u]
- 起点到每个点的所有路径点权总和：
    路径条数：cnt[v] += cnt[u]
    边权总和：sum[v] += sum[u] + cnt[u] * val[v]


2. 拓扑序解决**字典序排序问题**：给定一组按照字典序排列的单词，恢复出字母的字典序。
首先，对于相邻两单词 word[i], word[i+1]，用双指针找到第一个两单词字母不一样的位置。假设指针位置 p1 与 p2，那么就从 word[i][p1] 到 word[i+1][p2] 连边，代表前一个字符的字典序更小。如果发现 p1 < n, p2 == m，说明 word[i+1] 是 word[i] 的严格前缀，不符合，直接输出无解。由于不等号以及 DAG 的传递性，只需要考虑相邻单词。
注意连边是从字典序小的连到字典序大的，这样得到的 seq 就是按照字典序小到大的顺序
建图结束后，**如果有解，必定是 DAG 关系，并且如果有唯一解，每一层入度为 0 的节点必定只有一个**（如果有两个点在同一层入度为0，那么无法确定他们的相对关系）。
因此进行拓扑排序，维护一个顺序数组 seq 以及布尔标记 unique。在过程中，每次先检查 q.size() 是否为 1，若不是则将 unique 更新为 0。再取出队头放入 seq。最后，如果 seq.size() 和出现字符数量不相等，说明有环。否则如果 unique 为 0，说明编排方式不唯一。否则，按照 seq 的顺序即为字符按照字典序从小到大的顺序。

3. 在 DAG 中，general 的图论技巧也需要灵活使用。例如**分层图**，关键是利用 DAG 的性质来设计维度。一个很重要的性质是：路径上**最多 n 个点，最多 n-1 个边**
例：【P3116】：给定一个 DAG，每个边有两个边权，a 走的时间和 b 走的时间。求从起点 0 到终点 n-1，是否存在一个路径使两人同时到达，n<=100, c,d<=100。注意到**一个路径最多有 n-1 条边，因此边权总和最多只有 1e4**，可以开出第二维度：令分层图状态 dp1[u][t] 为 a 从起点到 u，时间为 t，是否可行，dp2[u][t] 为 b 从起点到 u，时间为 t，是否可行。按照拓扑序转移 u 经过 w 到 v，内层枚举所有时间 t，刷表 dp1[v][t+c] |= dp1[u][t], dp2[v][t+d] |= dp2[u][t]. 最后找到最小 t 使得 dp1[n-1][t] && dp2[n-1][t] 即可。

还是要牢记，**当一个东西不好直接表示但值域不大时，直接作为第二个维度加入状态中**

4. DAG 中还适合做传递闭包问题：令 reach[u][v] 代表能否从 u 走到 v。在拓扑序完成得到顺序数组 seq 后，做如下传递闭包（拓扑序在自己之后可达的点，自身也都可达）：
```CPP
vector<bitset<MX>> reach(n);
for (int i = n - 1; ~i; --i) {
    int u = seq[i];
    for (auto& v : g[u]) {
        reach[u][v] = 1;
        reach[u] |= reach[v];
    }
}
```
例【P2419】：给 n 个人和 m 对胜负关系（保证没有矛盾），求有多少个人是可以确定最终排名的。
有一个人能确定最终排名，当且仅当**可以确定比他排名高的人数加上可以确定比他排名第的人数为 n-1**。
按照套路，如果 u 打赢 v，就对 u->v 连边，保证拓扑序是按照排名从小到大。按照拓扑序求出 seq 数组后，对 seq 进行传递闭包。那么 reach[u][v] 就代表 u 可以打赢 v。对于 u，统计有多少 v 满足 reach[u][v]||reach[v][u]，如果 cnt==n-1 那就说明 u 的排名可被唯一确定。
如果这题换个问法，问存在性和唯一性，那么就变成了第二类问题。如果 seq.size()!=n，无解，否则如果有一层中 q.size()!=1，无唯一解。否则 seq 的排序就是唯一排名排序

## 连通分量相关

有向图想强连通分量缩点得到 DAG；无向图想双连通分量缩点得到树

当题目出现必经点/必经边的秒数时，想割点/割边

当题目中是有向图且出现环的特征（从一个点开始要回到这个点）想 SCC；缩点后每个 SCC 分别处理，再考虑全局拓扑序 DP

在处理时，还要灵活的使用 Tarjan 算法来应对各种变体。关键是记住两个数组的含义：
dfn[u] 表示 u 的 DFS 时间戳
low[u] 表示 u 的整颗子树通过树边和最多一条返祖边能到达的最小 dfn（注意 dfs 树中树边 u->v 不会拿来更新 low[v]）

以及更新时的关键代码：
```CPP
auto dfs = [&](this auto&& dfs, int u, int fa) -> void {
    dfn[u] = low[u] = timer++;
    for (auto& v : g[u]) {
        if (v == fa) continue;
        if (dfn[v] == -1) {                 // u-v 是树边，先 dfs 下去再继承子树信息
            dfs(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) {}        // v 子树最多也只能绕到 u
        } else {
            low[u] = min(low[u], dfn[v]);   // u-v 是返祖边，u 可以走到 dfn[v] 的位置
        }
    }
};
```

### 无向图割点/割边/SCC
**【注意】在缩点后，图用 dag，不要写 g ！！！**

题目中有选择某一个，这个**点可以沿有向边不断传播/扩散的一类题，或从某地开始最多经过多少/获得多少价值，想 SCC**. 常见考虑：ind/outd 为 0 的 scc，拓扑序 DP。

**在一个 SCC 内部，总是可以把里面的点权/边权拿满**（若不限制 scc 内部的步数）

注意拿到 dag 后枚举 cnt 从小到大是从右到左的顺序，从大到小是从左到右的顺序（传统queue出队顺序）

例1：消息扩散【P2002】，求最少投放多少消息源，那么对于入度为 0 的 SCC，每个都需要投放一个，否则这里无法达到。其他后面的点按照 DAG 顺序都会被扩散到

例2：间谍收买【P1262】，注意到每个 dag 中入度为 0 的 scc 里都需要选一个来收买（按最优性，选点权最小的），否则这个 scc 永远不可达。其他入度不为 0 的，会被之前收买的传播解锁

例3：明星奶牛【P2341】，注意到只有当出度为 0 的 scc 唯一是，这其中的每个牛都是明星牛

例4：校园网络【P2812】求最少投放几个使得所有都被扩散，以及最少添加几个，使得投放一个可以扩散到所有人（即最少添加多少条边使得图变成强连通）。如果 scc=1，那么显然答案是 {1,0}。否则记 cnt1 为 dag 中 ind 为 0 的 scc 数，cnt2 为 dag 中 outd 为 0 的 scc 数，第一问为 cnt1，第二问为 max(cnt1,cnt2)（每次加一个边可以解决一个源一个汇，而每个源每个汇都需要一个额外边）

1. 考虑求无向图固定起点 s 与终点 t 的必经点，在 Tarjan 的基础上增加数组 has[u] 代表 u 子树内是否能够到达 t. 那么割点的判断即为 has[v] && low[v] >= dfn[u]：考虑边 u-v，v 子树内能够到达 t 但 v 子树没有边连到 u 以上，因此删去 u 后起点终点分开为两个连通块

2. 常见 SCC + DAG DP 模型（注意缩点后按照 cnt 开始倒序才是按照 queue 建出来的拓扑序）：
- 统计每个 SCC 大小作为点权：`for (int i = 0; i < n; ++i) ++sz[comp[i]]`
- 合并原图点权：`for (int i = 0; i < n; ++i) val[comp[i]] += w[i]`
- 统计 DAG 入度/出度：`for (int u = 0; u < cnt; ++u) for (auto& v : dag[u]) ++out[u], ++ind[v];`
- 缩点后最大点权路径：`for (int u = cnt - 1; ~u; --u) for (auto& v : dag[u]) dp[v] = max(dp[v], dp[u] + w[v])`
- 消息扩散最少起点数：`ind[u]==0` 的 scc 数
- 被全图所有点都可达的点：当且仅当只有一个 `out[u]==0` 的 scc 时，这个 scc 中的所有点被全图点可达
- 加最少的边使有向图强化和联通：如果只有一个 scc，答案为 0；否则答案 = max(入度为0的scc个数，出度为0的scc个数)

### 有向图割点/割边/DCC

条边，可以把桥树上两个叶子连接起来消掉路径上的桥

## 二分图相关

### 棋盘上的二分图建模

棋盘上的格子/行列对角段 = 图上的点
能否同时放、能被一块骨牌覆盖 = 图上的边

常见算法：
最大匹配
最小点覆盖 = 最大匹配
最大独立集 = 点数 - 最小点覆盖 = 点数 - 最大匹配
最小边覆盖 = 点数 - 最大匹配
完美匹配：匹配数 * 2 == 点数

1. 棋盘二染色：按照 (i+j)%2 染黑白；如果一个操作总是黑格连到白格，那么为二分图。例如：多米诺骨牌 1x2，覆盖相邻两个格子，颜色必然相反；骑士走 (1,2) 或 (2,1)，i+j 奇偶性改变，攻击边连接黑白格。

2. 多米诺骨牌类：能否用 1x2 多米诺完全覆盖所有可用格子？建图点为所有可用各自，边为两个可用格子上下左右相邻。判断可用格子数为偶数，黑格数==白格数，最大匹配==cnt/2，若成立就存在完美匹配；若问最多放多少多米诺，即为最大匹配数，每条匹配边代表一块多米诺，匹配保证没有格子被重复覆盖

3. 骑士最大不冲突放置：在棋盘上放最多骑士，两两不攻击。建图点为可选格子，边为两个格子互相冲突。那么即为选最多点，使得没有边的两个端点同时被选，即为最大独立集 = 总点数- 最大匹配数

4. 车攻击同行列，按照横向连续空格段=左边点，纵向连续空格段=右边点，可放棋子的空格=一条边连接横段与竖段。最大不互相攻击车数=最大匹配

### 最大匹配

1. 给定 n 排座位，每排最多坐两个人。给 2n 个人，每个人各自给出两个心仪的座位，求最多能满足几个人的要求。
首先左部点可以变成人，边为座位，每个人最多做一个座位。但是对于排，每排可以接受两个人，这就不满足二分图匹配的一要素了。因此进行**拆点**：一个点 u 拆为 u 和 u+n，如果人 i 的心仪座位是 u, v，那么就连边 i-u, i-(u+n), i-v, i-(v+n)。这样每个点都最多只有一个边相连，并且每排都能接受两个人。对于这个图求最大匹配即为答案。一般的，如果右部点容量不大，可以拆点，否则要上网络流

## 其他

1. 给定图中一些障碍物，会有多次查询任意位置到最近一个障碍物的距离，这时只需要多源 BFS 更新距离即可

2. 考虑固定起点 s，有两个目标点 t1, t2；要求一个图，删去尽可能多边后最短路满足一个限制。关键结论：任何这样的图都形如“Y”字，即**存在一个分岔路口 i 使得 s 到 i 后分叉，i 一条去 t1，一条去 t2**。因此首先对于 s, t1, t2 为源点分别求出最短路数组 dis, dis1, dis2，再看是否满足 dis[i] + dis1[i] <= lim1 && dis[i] + dis2[i] <= lim2

3. 在分层图最短路中设计状态时，尽量把第二维度的操作设计成对自己**有利的**：比如，一个图，需要在**全图上指定 K 个边**限速（而不是在路径上），求最短路。如果维度设计成恰好走了 t 个限速边，这样会使得 t 不能取得完整的 [0,K]，这是由于如果取 0 个，剩下的边全限速也填不上 K 这个坑。然而，正难则反，全图需要 m - K 个边原速走，那么设计成恰好走了 t 个原速边，这样的操作是有利的，也就是尽量会倾向于多的使用。这样，即使一些小 t 不能取到，但是他们算出来的 dis 值一定会比大 t 小，从而变成不合法但更劣的不会对答案有影响的状态

4. 如何建图：【LC815】求最少坐几个公交车从起点到终点。可以用**二分图优化建图**：把所有站台看作左部点，公交线路编号看作右部点，左部点和右部点连边当且仅当站台所属公交线。从起点到终点最短路边的数量即为需要公交车数量的两倍（一辆车需要上车下车两条边）

5. **刷油漆建模**【LC1591】给定二维矩阵上标注的颜色信息；每次刷油漆可以给一个矩形刷上一种颜色（覆盖之前格子中颜色），但是每种颜色只能刷一次。给定最终图，判断是否能被刷出来。
首先可以求出每个颜色的bounding box [x1,y1]x[x2,y2]；这种颜色只能被刷一次且是矩形，那么刷的一定就是这个区域内（不妨把其他区域但全被覆盖的当作没刷）。枚举每种颜色x，在他的框内，如果出现了别的颜色y，那y一定在x之后被刷上。建边 x->y 表示先x后y。最后跑拓扑序来检查不存在环即可。

6. 给定一个两两距离矩阵 d[i][j]，判断它能否作为某种图结构中的最短路距离，并尝试还原结构。
对于一般图，把 d 看成完全图边权，做 Floyd；如果出现 d[i][j] > d[i][k] + d[k][j]，说明原距离还能被松弛，因此矩阵非法。
对于树，把 d 看成完全图边权，先求一棵 MST 作为候选树，再计算这棵树中所有点对距离；若全部等于原来的 d[i][j]，则存在这样的树，否则不存在。
    证明：首先矩阵中一定有 n 个边构成树边（边距离就是最短距离）；其次如果有符合矩阵的树一定是MST：若不是，有更小树，树中存在更小边权，这条边对应的两点在树中距离一定更大，矛盾。
核心思想都是：**先用距离矩阵构造一个候选结构，再验证该结构诱导出的距离是否与原矩阵完全一致**。是否能继续松弛是一个判定标准

7. **分层图不仅有最短路，还有判环等考法**：【abc456e】给定无向图，每个点有长为w（w<=10）的字符串表示一个礼拜中的每天是工作日还是假期。问从任意起点开始，每天要么停留不动要么去隔壁城市，是否可以做到有一条路线使得每一天都在假期中

由于涉及到额外信息（w），考虑分层图。一个朴素的想法是定义 dfs(u,t) 为在点 u，从每周第 t 天开始，是否满足要求。这里比较tricky的是没有显然的basecase，但感性上理解，可以无限的让每天都在假期，说明有一个 dfs(u,t) 继续向外搜到 dfs(v,t+1) 是之前搜过的状态，那么这就形成了一个环，因此这个路线永远都可行。
但注意，这里节点 (u,t) 走到 (v,(t+1)%w) 是有向的，因此要在这个分层图上使用 DFS 三色判环。由于 w 很小，复杂度依然是线性的。

8. **有多个特殊节点的处理方法**
对于图论中一类给定一组特殊顶点的题目，有如下一个思考/处理方案：
    - **分层图**最短路：开一个维度，记录经过/使用了多少个特殊节点；当特殊点数量很小时，要联想到**状压**：节点维护一个bitmask代表哪些特殊点被走过
    - **多源**最短路：考虑将特殊顶点全都放到队列/堆中同时更新；可引申到**虚拟源点**并按照题意来设置边权（多源更新为虚拟源点到点边权为0的特殊情况）
        例：给定一些点为危险点（D），其余为安全点（S）。对于每个 D 点，求从一个 S 出发，经过这个 D，再到另一个 S 的最短长度。【ABC429e】
        显然不是分层图，这里考虑对于每个D，要有两段距离加起来：到**某个**S的最短距离和到一个不同S的最短距离。显然需要把所有S放进队列更新，这样求最短路到D的dis即为最近的S到D的距离。
        对于次进的，不仅要维护 dis1,dis2 两个最短路次短路；由于有不同S的限制，因此还要维护 src1[i],src2[i] 代表最短路和次短路的源点。
