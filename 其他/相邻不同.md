设 n 为数组 a 的长度，m 为出现次数最多的元素的出现次数

1. 给定数组 a，是否能重排元素，使得所有相邻元素均不同？

若 m <= n - m + 1，则可以做到，否则无法做到


2. 给定数组 a，每次操作删除 a 中的两个不同元素，至多能操作多少次？

最多操作 min(n / 2, n - m) 次


3. 给定数组 a，每次操作删除 a 中的至多两个不同元素。要删除所有元素，最少要操作多少次？

最少操作 max((n + 1) / 2, m) 次


1 考虑隔空摆放出现次数最多的元素；2 与 3 考虑分类讨论 m 与 n / 2 的关系；

m >= n / 2 的情况是显然的；否则，按照 1 那样按顺序隔空摆放（先放偶数下标，再放奇数下标），即可构造出一个合法删除组合（相邻配对）
