# 思考清单

需要使用从特殊到一般的思考方式来探索性质

1. 寻找不变量：在操作题的反复操作中，寻找不变量：sum / 奇偶性 / gcd / 同余下的值 / 不同值数量

2. 小型数组：nums 只有 1 个数？只有 2 个数？

3. 万里挑一：所有数都相同？只有一个数不一样？某个数特别大？通过极端/特殊值进行不断操作？

4. 黑白世界：只有两种数？例如 01 或 ab

5. 反向思考：如果确定了答案，输入会是什么样的？

6. 枚举归纳：小范围打表，找规律

7. 信息压缩：真正有用的信息可能只取决于最值 / 奇偶性 / gcd / 不同值数量 / 排序后的相邻关系 / 前缀和的正负

8. 有时看上去显然的上/下界是充要的（有极端构造情况满足它）

9. 对于网格图组合操作问题，尝试对其黑白交替染色


# Tricks 积累

1. 从原点到 target，第 i 次可以选 +/- i，最少多少次走到 target：考虑一开始全是 +，然后选一些数 flip

2. 选数凑连续区间问题：排序后维护 [l,r]，加入数 x 若大于 r + 1，就需要补一个 r + 1 使得 r 扩展到 2r + 1 来保证值域连续

3. 对于二进制串 01/10/00/11 互相转化，找到核心观察，即操作到最后 0 / 1 是否不存在 / 只有一个 / 没有相邻，数字是**如何换位**的

4. 对于翻转字符的问题，优先考虑**相邻两数差值 / 相邻位置不等的数量**（例如统计 s[i] != s[i - 1] 的 cnt）。如果相邻不同，要么翻转前缀，要么翻转后缀，否则这对相邻字符无法相等。而由于范围翻转，别的位置该相等的还是相等，不相等的还是不相等，不会改变判断

5. 在只需要相对大小关系时，思考等价转化；例如给 n - 1 个数同时 +1 相当于给一个数 -1

6. 从 start 到 target，每次操作可以 +1 或 x2：逆向考虑，从 target 到 start，如果当前奇数则 -1，否则贪心的 /2。每次 -1 或 x2 一样，逆向每次奇数 +1，偶数 /2. 对于每次操作可以 +1 或 -1 或 x2，就要使用记忆化搜索，如果当前偶数，dfs(x) = 1 + dfs(x/2)，否则 dfs(x) = 1 + min(dfs(x+1), dfs(x-1))

7. 从 (sx,sy) 到 (tx,ty)，每次操作是：(x,y) -> (x+y,y) 或 (x,y) -> (x,y+x)：首先**不变量是 gcd(x,y)**，这启发从 (tx,ty) 使用辗转相除倒推：若当前为 (x,y)，且 x>y，那么前一步一定是在 (x-y,y)，否则 x<=y，前一步在 (x,y-x). 使用取模加速减法的过程，最后按照同余分析进行调整即可

8. 按照时间顺序修改，找到最小时间使得满足某条件；首先满足单调性可二分，但还有一种**正难则反**的思考方法：考虑从最终态开始恢复，一直到不满足条件

9. 二进制字符串任意交换直到变为交替：**与最终态匹配**；最终要么是 0101...，要么是 1010..，统计讨论即可。注意最后返回的是 mismatch sum / 2，由于一次交换同时修复了两个位置。

    如果是相邻交换呢？注意到最优策略下交换不改变所有 0 以及所有 1 的内部相对顺序，因此还是首先选取目标为 0101... 或 1010...，修改只需要将原串中第 i 个 0/1 移动到目标串第 i 个 0/1 的位置，返回这样的距离和即可（但是不能 /2 了）

10. 加油站问题：圆周上有加油站，每个站点有油量，两点间有路程耗油，求出发点使每段路都有充足油量经过。
结论：对 gas[i] - cost[i] 做前缀和，前缀和最小位置的下一个位置为出发点。
建模：折线图，gas[i] 相当于一个上升，-cost[i] 是一个下降，那么把前缀和最低的地方作为 0 线基点，从下一个加油站的 gas[i]-cost[i] 开始爬升，保证路上前缀和都 >=0

11. 给定两个长 n 的数组（n 偶），每个数组需要删除 n/2 个数。求删完后两数组并集最多元素个数：记 m = n/2，删完后每个数组最多剩 min(m, unique_cnt) 个元素种类被保留；另一方面，两数组并的总不同元素个数不会超过 tot_unique_cnt。有上界 min(tot_unique_cnt, min(m, unique_cnt1) + min(m, unique_cnt2)). 这是可以取到的

12. 给两个二进制串，每次可以交换 s1[i] 与 s2[j]，求两者相等最小次数；首先忽略 s1[i] == s2[i] 的位置，只考虑不相等的地方。
记 cnt0 为 s1[i]=0,s2[i]=1 的位置个数，cnt1 同理。那么 x 与 y 的总数就都为 cnt0 + cnt1。如果这是奇数，无法分配使得 s1=s2，无解；否则如果 cnt0 与 cnt1 为偶数，考虑一组 [x x] [y y] 的斜向配对，需要 (cnt0+cnt1)/2 次。否则都为奇数，先把一组 [x] [y] 对换调整到偶数情况即可，答案比前者多 1

另一个类似的建模：给两个二进制串，有三种不同代价的操作：1. 将任意一个位置 flip；2. 串内 swap 两个字符；3. 串间 swap s[i] 与 t[i]。求使 s == t 的最小代价（LC3800）：
还是不考虑 s[i] == t[i] 的位置；假设有 a 个 (s[i] == 0, t[i] == 1) 与 b 个 (s[i] == 1, t[i] == 0)
 - 进行翻转，需要 a + b 个，总代价 (a + b) * flipCost
 - 考虑加入串内交换，每次交换省去两个 flip，因此如果 swapCost < 2 * flipCost，应该做尽可能多的交换
   最多做 min(a, b) 次交换，剩下 max(a, b) - min(a, b) 需要 flip
 - 考虑加入串间交换，应该尽量使 min(a, b) 更大，否则相当于把便宜操作减少，已经被情况 1 考虑. 记 targ = (a + b) / 2
   这一情况下做 targ - min(a, b) 次串间交换，targ 次串内交换，以及剩下的 (a + b) % 2 次 flip

13. 煎饼排序，每次选择一个前缀 reverse，构造使得排列排好序的翻转顺序：将元素从大到小考虑，假设当前没排好最大值在 id，排好的右端在 r，先翻转 [0,id]，再翻转 [0,r]，将当前最大值的位置排正确。reverse 的公式为 pos[i] = r - pos[i]，如果需要更快的方式可以使用文艺平衡树

14. 身高重建队列：给定一组打乱的 {h,k}，表示身高为 h 的人前面有 k 个身高 >=h 的人，求恢复排列。用**树状数组维护空位：初始化 n 个 1**，代表空位，如果被占领则单点 -1 变成 0（这方便了二分前缀和）。对于打乱的数组，按照如下方式排序：
对于身高不同，按照身高升序排序；身高相同的，按照对应的 k 降序排序
那么按顺序取出每个人，当前树中记录的身高（即值为 0 的位置）一定全都 <=此身高，故树状数组二分找到第一个 >=k+1 的位置，即可保证前面有 k 个 1，这 k 个空位是为之后会 >= 自己身高的数预留的位置。

15. **两次操作的抵消性** 这个概念比较抽象，通过几个具体例子理解：
例1. 一个网格中可以把相邻两格同时变号，这可以推出可以通过操作把任意两个格子变号：假设是 a 和 b，考虑 a 到 b 的最简单 L 型路径，在沿途每次给 2x1 的格子 flip，这样首尾操作一次，中间没有操作，因此可以把两端变号而不影响别的。

例2. 一个数组，每个元素给定一个 type，0 或 1；每次只能 swap type 不同的元素，问能否将其变为 sorted。如果本身已经 sorted，可以；否则，如果 type 只有一种类型，不行。除此之外都可以，这是因为如果 b 又有 0 又有 1，我们可以 swap 任意元素：如果 type 本身不同不用管，否则，对于 a[i] 和 a[j]，必定存在 a[k] 使得 type[i]==type[j]!=type[k]，因此交换 (i,k), (k,j), (k,i) 后就相当于交换了 (i,j).

例3. 给定一棵树和 k，每次可以选择一对邻点 (u, fa[u]) 操作变为 (u xor k, f[u] xor k)；求最后树上最大点权和。注意到，对于任意两点 (u,v)，选择它们的路径一路执行操作，中间点被操作两次抵消掉，只有 u 和 v 被操作。因此，树结构是无用的，可以任意对于两个点同时进行 xor 操作。然而，这样操作还会带来不变量：总共只会有偶数个元素被操作；因此对于点权数组做一个状态机 DP 即可。

16. **【重要！！！】置换环的奇偶性**以及相关题目：
    - 一个排列，如果可以通过**奇数次 swap 变的有序**，则称为奇置换；否则称为偶置换
    - **排列奇偶性 == 逆序对个数的奇偶性**；对于奇偶性的操作，可以看成 mod2 加法
    - **相邻交换一次，逆序对个数要么+1要么-1，奇偶性被翻转**
    - **普通swap一次，奇偶性被翻转**：swap(i,j)=2(j-i)-1次相邻交换；一次swap（2-cycle）一定是奇置换
    - 对于一个 k-cycle：(a1 a2...ak)，可以拆成 k-1 次 swap：(a1 ak),(a1 a(k-1)),...,(a1 a2)，因此 **k-cycle 的奇偶性即为 (k-1) 的奇偶性**
    - 例题：一个数组，每次可以任选一对两两不同的下标 i,j,k，并对数组进行 i->j->k->i 循环；求任意数量操作后能否将数组变的有序。这个操作即为一个 3-cycle。一个 3-cycle 等价于 2 次 swap；若数组中有相同元素，那么以这个相同元素为跳板可以达成任意两元素的swap。否则，可以看作一个长 n 的置换，一次 3-cycle 不改变置换奇偶性，因此初始逆序对个数为偶数是充分条件。这同时也是充分条件：**任意一个偶置换都可以拆成若干 3-cycle**.

结论：对于一个排列 p：
只允许**交换相邻元素：最少交换次数 = 逆序对个数**
允许**任意两个位置交换：最少交换次数 = n - 置换环个数**

例：给定一个排列 p，每次可以交换 p[x],p[y] 当且仅当 |p[x]-p[y]|=1，求最少交换次数。定义逆排列pos为：pos[p[i]]=i，那么在 p 中交换 k,k+1 即为在 pos 中交换 pos[k],pos[k+1]，是相邻交换。而逆排列和排列的逆序对相同，所以最小交换次数也即 p 的逆序对个数

17. 给定一个 01 数组，每次可以选择一个间隔，把前后缀分别反转；例如，01|0010-->10|0100。求任意次操作后交替段的最大长度。考虑把数组放到环上环形考虑，操作后任何一个数组可以看作换上选择一个数和一个方向后的一周。因此只需要复制二倍数组，在上面求出最大的交替段长度，再与数组长度取 min 即可得到答案

18. 一个序列，最少划分为多少个单调递增序列：答案为**众数个数**

19. 给定一个 01 序列，求最少划分为多少个下标相对顺序不改变的交替子串：考虑这个序列任意一个区间的 0个数与 1个数的绝对差为 k；那么至少要有 k 个子串来覆盖他们。因此，对所有区间求上界得到的就是最小值：**所有区间01个数绝对差的最大值**。
这可以使用前缀和：**将 1 值记为 1，0 值记为 -1**，求前缀和数组 pre[i] 表示 [0..i] 中 1个数 - 0个数。那么对于任意区间 [l,r] 的上界就是 abs(pre[r]-pre[l-1])。
求最大值等价于这个序列中最大的 pre 减去这个序列中最小的 pre，即为答案：**max_i pre[i] - min_i pre[i]**. 注意要包含空前缀和 pre[-1]=0。
拓展：给定 Q 个询问，每次询问区间中能划分多少：首先对于 pre 数组建立 ST 表。对于询问 [l,r]，有：
ans = max(0, v[l], v[l]+v[l+1],..., v[l]+v[r]) - min(0, v[l], v[l]+v[l+1],..., v[l]+v[r])
    = max(pre[l-1]-pre[l-1], pre[l]-pre[l-1], pre[l+1]-pre[l-1], ..., pre[r]-pre[l-1]) - min(pre[l-1]-pre[l-1], pre[l]-pre[l-1],..., pre[r]-pre[l-1])
    = max(pre[l-1],pre[l],...,pre[r]) - min(pre[l-1],pre[l],...,pre[r])，用 [l-1,r] 的 ST 表值求答案即可（这是由于 [l,r] 的空前缀值为 pre[l-1]）

20. 给定 n 个数字，按照任意顺序首尾相接拼起来，求能拼出的最大数
把数字按照字符串读入，并按照次规则排序：**return x + y > y + x**。在拼接的语境下，A 比 B 优当且仅当 A + B > B + A

21. A和B 博弈，有一个数组，每次可以取出其中一个。如果当前人取出的数使得所有取出石子总数mod3=0，那么输。否则进行到所有数都拿空，就 B 赢。
首先观察到可以给所有数%3，然后记录 cnt[0],cnt[1],cnt[2].
当前s若为1，只能拿0或1；当前s若为2，只能拿0或2.
一开始s=0，第一个要么拿1要么拿2，不妨假设拿了1；不考虑0的话，拿出的数一定是这个序列：1->1->2->1->2...；由于拿出0不改变和的值，可以插入任意不为一开始的位置而不改变。
这样的序列最长可以进行 len = 1 + min(cnt[1],cnt[2])*2 + (cnt[1]>cnt[2]) 项（最后一个部分是由于最后1->2之后还可以再跟一个->1）。
剩下的数有 rem = n - len 项，那么如果 rem!=0，且 len 为奇数，下一个是 B 拿，但不得不拿出一个使得和为 0 的，因此输掉。
对于 2 开始也是 2->2->1->2->1->...->2->1(->2)，判断 rem&&len&1，如果成立就 B 输
其他的情况都是 A 输。

22. 对于一个数组h，h[0]=0；定义 d[i]=h[i]-h[i-1]，有 0<=d[i]<=1.
给定 d 数组，其中 d[i]=0or1or-1，-1代表填哪个都行。再给定 n 组 [l[i],r[i]] 代表 l[i]<=h[i]<=r[i]. 恢复 h 数组。
这种题型需要**从后向前传播更新[l,r]的界**：最后一组 [l[n],r[n]] 是固定的。考虑知道 [l[i],r[i]] 以及 d[i] 时，如何得到 [l[i-1],r[i-1]] 的关系：
l[i]<=h[i]=h[i-1]+d[i]<=r[i] ==> l[i]-d[i]<=h[i]<=r[i]-d[i]；d[i]=0or1 时是明确的，考虑 d[i]=-1 时，0<=d[i]<=1, l[i]-d[i]>=l[i]-1, r[i]-d[i]<=r[i]
因此：**l[i-1] = max(l[i-1], l[i]-(d[i]!=0)), r[i-1] = min(r[i-1], r[i]-(d[i]==1))**
得到这个关系后贪心填写即可。

24. **【重要】**给定一个长为 2n 的数组，有 1~n 中每个数和 n 个 0. 每次可以查询 (a[i],a[j])，如果相等返回 1，否则返回 0. 求在 n+1 次查询或以内求出一个 0 的下标位置
首先，如果一次查询返回 0，一定是两个 0，直接输出其中一个下标即可。下文讨论最坏情况（所有查询都返回了0）
考虑一次查询最多可以确定两个数相对关系，所以一开始可以把 2n 分成 n 段，每段 (2i,2i+1) 进行一个查询。这样可以查 n 次，如果返回都是 0，说明每段内都有一个 x 和一个 0（1<=x<=n）。
然而，最后还剩一次机会，无论用在哪里，考虑相关两端四个数中两个零和两个非零数的关系，总存在一种无法确定下来的情况。
重新考虑，问题到这一步被归约到了：4个位置有2个零，要用3次查询查出这两个零的位置。
但是另一方面：三次查询只能完全确定三个位置上的关系（有相等就是0，否则至多一个0），那么不管一个点，先确定三个点中有几个零，最后就能推出四个位置的关系：
记 m=n*2，不妨把 m 变成孤立点，查询只做到 (m-3,m-2). 然后查一个三角形关系：(m-2,m-1),(m-3,m-1)。
如果都没有1，那么说明 m-3,m-2,m-1 对应的三个数两两不同，至多只能有一个零。前面n-2段，有n-2个零，因此剩下一个只能在 m 上。这就查出来了。

25. 【2055c】给定一个 nxm 的二维网格，有一个长 n+m-1 的 RD 路径的值未知，要求恢复这个路径的值，使得每行每列的和都相等。
假设相等值是 X，那么行和总和是 nX，列和总和是 mX，考虑这两者都计算了网格中所有数的和，必定有 nX=mX，直接固定 X=0.
假设当前在 (x,y)，下一步要走 'R'：那么这是**当且列最后一个能变化的位置**，取 a[x][y]=-col_sum[y]，并将 row_sum += a[x][y].
类似的如果下一步是 'D'，那么这就是当前行最后一个可以变化的位置，取 a[x][y]=-row_sum[x], col_sum[y]+=a[x][y] 即可。

26. 【1838E】**重要** 给定一个长为 n 的数组 a 以及整数 m>=n，问有多少**不同**的长为 m 的数组 b 满足 a 是 b 的一个子序列？前提是 a 和 b 都满足元素在 [1,k] 之间（k给定）
考虑没有子序列限制，这样的 b 单纯有 k^m 个。
要求 a 是 b 的子序列，考虑在总数中减去满足 a 不是 b 的子序列的 b 的个数。如果 a 是 b 的子序列，那么 a 和 b 的 LCS==n，所以如果 a 不是 b 的子序列，**匹配长度一定小于n**。
枚举当前匹配长度为 i，考虑计数：长 m 的序列 b，和 a 的最长匹配长为 i 的个数。

回顾求两序列最长匹配的贪心算法：当前 a[i] 能匹配 b[j]，就++i,++j，否则就一直++j，a[i]处于等待匹配的状态。
当前要求两者匹配恰好长为i，那么说明：首先，可以在 m 个位置中选出 i 个位置作为恰好匹配到的位置；剩下的位置，一定要满足：**当前在等待匹配的a[t]一定不能和当前尝试的b[j]相等**，否则贪心的匹配上这个位置，但却不是钦定的i个位置之一。因此，除了钦定位置之外，每个位置不能取当前在等待的值，只有 k-1 种选择。
因此，匹配上 i 个的 b 的计数为：C(m,i)*(k-1)^{m-i}。
因此，答案为：k^m - sum_{i=0,..,n-1} C(m,i)*(k-1)^{m-i}.
实现当中 C(m,i) 的 m 是定值，可以使用递推：C(m,i)=C(m,i-1)*(m-i+1)/i

对于这类**集合运算封闭性题目，先找出集合中元素的封闭式**：这题中，x->ax 与 x->b+x，因此封闭式为：**x=a^p+qb，其中 p,q 为正整数**
x=a^p+bq，ax=a^{p+1}+bq, b+x=a^p+(q+1)b，都仍然被封闭。初始元素 1=a^{0}+0*b，符合。因此任意元素 x∈S，一定存在 p,q 使得 x=a^p+qb.
另一方面，如果一个数可以写为 x=a^p+qb，那么从 1 开始先执行 x->ax p 次，再执行 x->x+b q 次，即可得到。
因此这一题可以枚举指数 p 来判断 x-a^p 是否为 b 的倍数，复杂度 O(sqrt(n)). 【注意特判a=1时不要无限循环】

对于一个括号序列，当且仅当所有左括号都与右边的一个右括号一一完美配对才合法。
定义 "(" 的权值为 +1，")" 的权值为 -1，那么一个括号序列**合法当且仅当任意位置的前缀和都>=0且全部和==0**。

题目1：给定长均为 n 的括号序列 a 与 b，可以进行如下操作任意次：选择下标i，并交换 a[i] 与 b[i]。求是否可以通过若干次操作来将 a 和 b 均变为合法括号序列。
使得 a 与 b 均为合法，要任意位置处前缀和>=0。对于 a[i]==b[i] 的位置，交换显然没用，直接累加前缀和。
否则如果 a[i]!=b[i]，这个位置即为将一个 1 和一个 -1 分配给 a 与 b；如果 preA>preB，贪心的将-1给A，1给B 更好。给完后如果还是有一方前缀和<0，就无解。
一直进行到最后，再检查是否有 preA==preB==0.

题目2：给定一个括号序列和 k；可以删除最多 k 个括号下，求一个删除方案使得剩下的括号序列的最大合法括号子序列最小：
先考虑如何求出原串的最大合法括号子序列（记最多的匹配括号对数为 P）：
定义 pre[i] 为前缀 [0..i] 中 "(" 的个数，suf[i] 为后缀 [i+1..n-1] 中 ")" 的个数。
那么对于任意一个匹配的括号对，如果左括号位置<=i，就将左侧计数器 cntl 增加，否则左括号位置 >i，增加右侧计数器 cntr。
对于每对匹配括号，要么属于左侧（最多容纳pre[i]对），要么属于右侧（最多容纳suf[i]对），因此 P=cntl+cntr<=pre[i]+suf[i].
对于所有可能的分界点 i 取界的交集，有 P<=min_i (pre[i]+suf[i])。
现在证明这个界是可达的：将 pre[i]+suf[i] 最小的i处作为分界点位置，记为id。将两侧可以匹配的括号对删除后，一定形如：)))id((( 的形式（都是不能匹配的括号对）
那么左侧所有的 "(" 一定被匹配，右侧所有的 ")" 一定被匹配，即 P=pre[id]+suf[id].
现在考虑怎么删 k 个括号：对于 pre[id] 中的 "("，能删就删掉，减少匹配数。如果还有剩余，再把 suf[id] 中的 ")" 删去即可。

34. **倍投法**：考虑一个经典问题，每次投注，有一半概率失败，一半概率获得成倍返还，如何投注？如果是第一次投或者上一次赢了，本次投入1元；否则上一次输了，投入上一次的两倍。这是因为：假设已经投了 k 次都失败了，损失 1+2+...+2^{k-1}=2^k-1 元；第 k+1 次成功了，获得 2^{k+1} 个硬币，这样就把亏损全部赚回来了。
【1929C】给定初始资金 a，赔率 k，以及保证不会连续输超过 x 轮，求是否可以让资金无限增加。
按照倍投法的相同思路，关键就是前面全输，当前赢，是否可以全赚回来：假设前面输了 lost 元，当前投注 y 元，那么要是赢了，可以赚：(k-1)*y 的净利润
因此需要：(k-1)*y>lost ==> y>lost/(k-1) ==> y>=floor(lost/(k-1))+1.
由于不会输连续 x+1 轮，因此从一开始lost=0,y=1开始模拟，一直到x+1轮，lost维护前面轮总输，当前轮保证 y>=floor(lost/(k-1))+1 即可。记得 lost<-y 模拟这次也输了继续进行

37. **配对操作**【重要 LC1927】给定 n 个数，n 为偶数；每个数为 0-9 整数或 "?"；A 先手操作，每次操作可以选择一个 "?" 变成 0-9 的数字。操作结束后若前一半的和等于后一半的和，先手失败，否则获胜。求两者最优操作下先手是否必胜。
    类似这样的博弈题，往往 1) 配对操作；2) 从特殊到一般 是很好的切入点。
首先没有问号显然；若只有一个"?"，那么若 s1==s2，A 填9，否则 A 填0，都会使得最后 s1!=s2；推广到任意计数个问号，最后一定是 A 来操作，因此一定可以必胜。

考虑只有偶数个问号的情况。这里要使用一个 trick：**将每个"?"先虚拟填写入它的一个期望值，再考虑每次真实操作在带来的变化量**：对于 0-9，即为 4.5。
那么有：`SL=sum1+cnt1*4.5, SR=sum2+cnt2*4.5`。考虑差值 `D=sum1+cnt1*4.5-sum2-cnt2*4.5`；
若 D==0，那么 A 一开始假设填写了 x，对于 D 的变化量是 x-4.5。由于是偶数个问号，每次A操作后B一定可以再进行一次操作；如果前半边，B 可以选 9-x。那么变化量 9-x-4.5=4.5-x；如果后半边，B 可以选 x。那么变化量 -(x-4.5)=4.5-x。因此无论如何，B 可以通过配对操作消除变化量，使得最后的 D 为 0。
反之，若 D>0，那么 A 一开始填写 x，B 在前面填写 y，变化量 x-4.5+y-4.5=x+y-9，那么 A 将 x 都取 9，B 的局面是 y\in [0,9]，无法减少 D；B 在后面填写 y，变化量 x-4.5-(y-4.5)=x-y，A 取 x=9，B 局面为 9-y。类似的分析可以看出，只要 A 在前半段填写9或者后半段填写0，B最多可以做的就是把这个操作带来的变化量抵消掉，因此如果初始态 D 不是0，最后 B 也一定无法将其变为0.


# 不变量积累
题目识别：**给定初始状态和可以进行（任意次）的操作，问最后是否能到达目标状态**。检查充要不变量是否满足即可。

0. 需要留意的一些不变量：
    - **差分数组**：对于一些操作，留意 b[i] = a[i] - a[i - 1] 或 b[i] = a[i] != a[i - 1] 这一差分数组会很有效
        - 例1：见下文 3，4 题
        - 例2：给定数组 c，每次对于内部点，将 c[i] 变成 c[i + 1] + c[i - 1] - c[i]，判断能否通过操作到数组 t。注意到每次操作相当于将差分数组 b 做了一个相邻 swap：(c[i]-c[i-1],c[i+1]-c[i]) -> (c[i+1]-c[i],c[i]-c[i-1])，因此只需要检查 c 和 t 首尾元素相同且差分数组是互相的 perm 即可

    - **奇偶性**：在一些操作中，考虑一些简单量的奇偶性是很关键的
        - 例：给定一个 nxm 方格，每次操作可以把相邻格同时 x(-1)；求最后所有格最大和；注意负数的奇偶性是不变的，如果初始有偶数个负数，所有数都可以调整为正数，如果有奇数个，最后只会剩下一个负数，让绝对值最小的当，答案为 sum(abs(x)) - 2*abs_mn

    - **涂色**：用两种或多种颜色对网格中的方格涂色
        - 例：将方格的一组对角挖去，无法用 2x1 的多米诺覆盖：黑格数量和白格数量不等，但 2x1 永远覆盖一黑一白
    
    - **代数式**：留意差，和，平方，积，以及 mod 某个数 n 的结果
        - 例1：有一个只含有 1, -1 的序列，每次拿出两个数，如果相等放回 1，不等放回 -1；所有数的积是不变量，最后的数和初始全体积相等
        - 例2：有一个卡片序列，正反面一面白W，一面黑B。一开始均为 W 面朝上。每次操作选取一个不在两端的 W 朝上的卡，拿走他，并 flip 它两旁的卡。证明当且仅当 3 不整除 n - 1 时，才能到达剩下两张牌的情景。下记 x 为被拿走的卡；有：
            WWW... -> BxBWW... -> BxWxBW... -> WxxxWW...；因此可以从 n 个 W 卡到 n - 3 个 W 卡。如果 n=0(mod3)，可以从初始态到 WWW，再拿出一个到 BxB 即可；如果 n=2(mod3)，剩下 WW 即可。考虑 n=1(mod3) 的场景：
            对于每个 W 卡，给一个权重 w = 左侧有偶数个个黑卡 ? 1 : -1；初始总权重为 3m + 1。一次翻转，中间的卡权重从 w 变为 0；左侧的卡如果 W 到 B，那么从 w 到 0，如果从 B 到 W，那么从 0 到 -w（相比中间少了个 B 卡）；右侧的卡同理从 W 到 B 会从 w 到 0，而从 B 到 W 会从 0 到 -w：反转后的权重与反转前中间卡的权重相同，这是因为左侧卡翻转一次会让左侧 B 卡奇偶性被反转。因此每次减少 3w 的权重，最后的权重 mod3 = 1. 而如果要剩下两张牌，要么是两白，要么是两黑，权重和为偶数，矛盾。
    
    - **角和棱**：对于网格问题，考虑形状边界的棱角
        - 例：一个 nxn 网格（n>=2），初始有 n 个 1，剩下全为 0，其中每行，每列恰有一个 1. 每次操作选一个格子将数字 -1，同行同列除了自己的其他格子 +1. 证明无论如何操作不能使所有格子数字相同。关键观察：一定存在一组 {a[x0][y0], a[x1][y0], a[x1][y1], a[x0][y1]} 使得其中**恰好一个 1，三个 0**. 考虑它们的**交错和**（主对角线-副对角线）作为不变量：a[x0][y0] + a[x1][y1] - a[x1][y0] - a[x0][y1]；每次操作，要么没有碰到，要么被减数在外部，交错和不变；要么被减数在内部，变化为 1+1-(-1)=3，因此这个和 mod3 一直为 1. 若所有数相同，这个和 mod3 应该为 0，矛盾。
    
    - **倒置**：对于排列题，考虑 flip, swap 与逆序对数量或奇偶性等；也见 Tricks 积累的第 16 条
        - 例：将 1,2,...,n 写在纸上，n 是偶数。在 n - 1 次任选 swap 后：不可能恢复到 sorted 顺序。
            观察 1：相距 k 的 swap 相当于 **2k - 1 次相邻交换**；
            观察 2：每次 swap 要么让总逆序对计数 +1，要么 -1，因此**逆序对计数的奇偶性被翻转**；
            因此，一次 swap 做了奇数次相邻交换，让逆序对奇偶性翻转奇数次，而 n - 1 为奇数，所以总翻转奇数次，不可能到 sorted（sorted 时逆序对为 0，是偶数）。
    
    - **半不变量**：某个总是不递增或不递减的值
        - 在要论证不可能回到一开始状态且数据感性上是趋于离散时，考虑一个形如平方和的半不变量。例：把有限个球随机放入有限个盒子里。只要有大于1个盒子有球，就把一个盒子中的其中一个球放到另一个盒子中，前提是另一个盒子中球数>=当前球数。最后所有球一定都在同一个盒子中。令每个盒子中球数为 ci，考虑 C = sum ci^2. 假设 m <= n，一次操作后 C 的变化量为 (n + 1)^2 + (m - 1)^2 - n^2 - m^2 = 2n - 2m + 2 >= 2，因此 C 不减。而状态有限，因此 C 的值不可能永远增加；最后一定落入到一个箱子中。
    
    - **对称性不变**
        - 例：给定一个序列，每次可以选择 k<=[n/2]，交换长为 k 的前缀和长为 k 的后缀。求任意操作后，初始序列能否变成目标序列。考虑无序对 {a[i], a[n-1-i]}，每次前后缀交换不改变对子，因此只需要统计是否 n/2 个无序对的 multiset 相等；另外的，在奇数长度时还应该比较中间元素是相等的

1. 将 x, y 擦去替换为 |x - y|，和的奇偶性不变

2. 对于一个序列，取连续的两个数，同时 +1 或 -1，a[0] - a[1] + a[2] - a[3]... 这个交替和大小不变

3. 一个二进制串，定义边差分数组 b[i] = a[i] != a[i - 1]; 
    - 每次可选择一个严格内部点 a[i] 并 flip：那么 b[i] 和 b[i + 1] 会同时被 toggle（即被 ^1），因此 sum(b) % 2 不变；
    - 每次可以选择一对严格内部相邻点 a[i] 与 a[i+1] 并 flip：那么 b[i], b[i+2] 会被 toggle 一次，b[i+1] 被 toggle 两次抵消，因此仍有 sum(b) % 2 不变

4. 一个数组，每次 +x，不变量为 gcd(|a[i]-a[0]|)：由于同时 +x，每对相邻差分值不变，且所有差分的 gcd 不变：gcd(a[1]-a[0],a[2]-a[1]...)，又由于 gcd 的差分性质，这个 gcd 即为 gcd(a[1]-a[0], a[2]-a[0], ..)

5. 一个01串，每次可以**擦掉两个连续的0或连续的1，并替换成相反数**(00->1,11->0)。求有多少子串满足在一定步数下可以通过这样的操作把长度减为1.
考虑00->1,11->0 这样操作的不变量。假设**把01赋值为一对相反数，那么什么情况下有 x+x=-x？即为在 mod3 下**。
因此将0赋值为2，1赋值为1，那么每次操作后都不会改变这个串在mod3下的值。因此，如果一个串可以把长度变为1，它一开始的和mod3一定不为0.
另一方面，如果mod3不为0的串，却不一定可以变成长度为1：考虑 010，mod3=1，却没有第一次操作然后消消乐的机会。因此，还需要减去所有这样的子串：长度为奇数的交替子数组。

因此做法如下：
记录前缀和，用前缀和哈希表的思想统计mod3不为0的子数组数量。（pre+=w(s[i]),res+=cnt[0]+cnt[1]+cnt[2]-cnt[pre],++cnt[pre]）
接着使用分组循环找出每个极大长度的交替串，假设长为x，那么长3的交替串有x-2个，长5的有x-4个，以此类推，有 sum_{i=1,..,x>>1} (x-2i)=(x/2)*(x-x/2-1) 个，从答案中减去即可

6. 一个数组，每次可以把 (a[i],a[j]) 变成 (gcd(a[i],a[j]),a[j])，求所有数都相等的最小次数
有 gcd(a[i],a[j])=gcd(gcd(a[i],a[j]),a[j])，因此每次操作**不会改变gcd，是个不变量。因此，所有数的gcd在每次操作后也不改变**。假设最后变成的数是x，根据不变量，x=gcd(x,x,...,x)=gcd(a[1],a[2],..,a[n])，因此最后变成的数一定是 g=gcd(a[1],..,a[n]).

如果数组中有 g 存在且出现cnt次，那么还需要n-cnt次操作把其他数变成gcd
否则，数组中没有gcd，不妨把所有数除掉gcd，那么就是一个数组操作最少多少次可以把其中一个数变成1.
用一个类似**背包dp**的动态规划：定义 dp[i][g]=考虑前i个数，选若干数使得gcd为g的最小元素个数；那么答案即为 g[1]-1+n-1=g[1]+n-2（g[1]要减一是因为可以固定一个数一直操作）
```CPP
vi dp(mx + 1, INF); dp[0] = 0;
for (int i = 0; i < n; ++i) {
    vi ndp = dp;  // 允许这个数不被选
    for (int g = 0; g <= mx; ++g) {
        if (dp[g] == INF) continue;
        int ng = gcd(g, a[i]);
        ndp[ng] = min(ndp[ng], dp[g] + 1);
    }
}
cout << dp[1] + n - 2 << endl;
```


# 构造积累

1. 有一个 0~n 的排列，不知道具体数，只知道相邻大小关系，恢复排列。双指针维护当前最小值（0开始向右）与最大值（n开始向左）；若当前 perm[i] < perm[i+1]，贪心的应该填写 res[i] = l，否则 perm[i] > perm[i+1]，填写 res[i] = r

    改编：一个长 n（n<9）的串，位置 i 是 I 或 D，代表原串 a[i] 与 a[i+1] 之间关系是上升还是下降；求恢复原串，要求 1~9 每个数字只能用一次，且结果字典序最小。
核心观察：
    - 连续 I / D 段对应连续值域，且如果连续段从下标 i 开始，那么连续段值域的最小值是 i+1
    - 如果 pattern[l..i-1] 是一段连续的 D，那对应数字位置是 [l..i]，一共 **i - l + 1** 个数字，所以直接倒序填: i+1, i, ..., l+1
比如：pattern = "IIIDIDDD"
处理结果：1 | 2 | 3 | 5 4 | 9 8 7 6

2. 给定 1~n 的排列，取出三个数 xor，求最后能够得到的不同值个数。首先，通过选取 a,a,a，其中 1<=a<=n，可以把 1~n 中的数都得到。记 L = [log2(n)] + 1，那么对于 [n+1, 2^L-1] 中的数 a，可以通过如下操作得到：2^{L-1} ^ (a ^ 2^{L-1} ^ 1) ^ 1. 对于更大的数，由于二进制长度已经超出当前长度，不可能得到。 特判 n=1 时只有一种可能，n=2 时只有两种可能，其余为 `1 << bit_width((unsigned)n)`.

3. 对于一个无权无向图，构造一个生成树并对生成树二染色，使得对于任意一个非树边，都存在一条树上路径是颜色交替的。考虑对于图进行 DFS 的到一个 DFS 树作为生成树，那么所有非树边一定是返祖边。因此题目等价于让树上从下到上的任何路径都是交替的。这很简单，只要按照父节点深度%2的结果来染色即可。
